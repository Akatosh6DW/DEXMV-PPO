## 方法与既有证据

用户记得的是“基于 STL 的碰撞代理拟合（primitive fitting）”：以 STL 为形状依据，
用定向包围盒（OBB）、胶囊体和椭球等低复杂度几何体组合近似接触面。
Aero-Hand 的 `urdf_collison_decompose.py` 有 PCA 主轴拟合、分段胶囊/椭球、CoACD
凸分解实现；`show_v2_collision_overlay.py` 叠加显示外观与真正参与接触的几何。
CoACD 是其中一种凸分解方式，并不等于所有基元拟合。

这里要区分三层：STL 是外观网格；碰撞代理决定哪里会产生接触力；策略决定关节目标。
提高视频分辨率或转动相机，只影响看见的画面，不会修正接触物理。
当前 PPO 读取关节与物体状态，不直接读取渲染图像；视频通过离线提取和重定向的参考动作参与控制。
观测用的旧指尖锚点保留为无碰撞、零质量的小标记，防止重构同时改变观测语义和网络尺寸。
OBB 指沿部件方向旋转的盒子；PCA 用点云主要伸展方向确定盒子的轴；胶囊体是圆柱加圆端；
凸分解把复杂轮廓分成多个凸块，适合掌部这种少量规则几何难以拟合的结构。
本次没有照搬 Aero 的椭球：当前 MJX 碰撞实现不支持任务所需的椭球-方块组合。

当前 Orca 的旧构建器 `scripts/build_orca_mjx_grasp_model.py` 使用手工尺寸，
并明确将掌心缩小以使手指接触占主导。没有基于 STL 的定量误差门槛。
因此需要审核几何，但还不能断定上一轮训练退化由几何误差单独造成。
旧数值与轨迹不覆盖：`artifacts/orca_guidance_long/` 的报告仅增加历史任务范围提示，原成绩保持不变。

## 顺序与交付门槛

1. G01：STL 单位、坐标变换、外观/碰撞叠加、逐部件双向表面误差审计。
2. G02：生成独立碰撞模型，检查覆盖、突出、接触连续性及姿态变化。
   保持质量/惯量、关节、执行器、摩擦和物体参数，避免同时改变动力学因素。
   拟合脚本产物初始仅标记候选，不能直接当作验证通过。
3. 完成重构验证后，先用相同控制与模型检查点比较新旧几何，再训练新模型基线。
   不能只把旧状态换外观渲染后称作新物理实验。
4. 从实际日志定位失败，单独调整奖励项，记录 first/last/max/best_step、接触、
   连续抓持、掉落和修正幅度。每轮先分析和记日志，再开展下一次受控实验。
5. 保留纯 PPO、BC + PPO、视频基础动作 + 残差 PPO 的比较，记录示范迁移兼容性；
   开发集调参后，用独立状态/种子验证，不用测试集筛选奖励。
6. 导出手心侧视频（原方位 45 度，首先检查 225 度），包括外观、碰撞与叠加图，
   单回合展示不能替代完整成功率。

任务成功定义保持既有连续有效抓持至少 30 秒且末帧有效，拇指加另一指、无非法接触。
不预设哪种方法胜出；本任务要求几何核验与基于证据的奖励迭代，而非为了反转旧结论改评分标准。

### R01 完成；R02 奖励单变量迭代

R01 成功率 first=0%、last=max=56.25%、best_step=327680；依次为
0 / 0 / 6.25 / 12.5 / 56.25%。末次平均最长连续抓持 35.87 秒，16 回合都曾达到 30 秒，
但仅 9 回合最后有效。末次释放后非法接触帧占比 0.017%，低于高度门槛的干净接触帧
占比 1.56%；稳定阶段速度中位数 0.697 mm/s、p95 2.25 mm/s。
修正 RMS 0.0154 rad，未触及 +/-0.08 rad 饱和。耗时约 765.8 秒（含编译/评估）。
结论：训练可适应新几何，主要剩余问题仍是累积滑移，而非明显脏接触或修正界限不足。

下一轮选择 **reward 结构**，增加一个有接触门控的滑速项；不修改环境或 PPO 参数。
R02 每控制步奖励为：

`(15*stable - 50*done - 2*paired_clean_released*min((speed/0.005)^2, 4))*0.05`

speed 为物体线速度（m/s），0.005 即 5 mm/s；按 R01 观测量级设置，非从测试集搜索。
只有释放后、拇指和另一指抓住且无非法接触才惩罚速度，避免给正常接近动作施加静止要求。
惩罚最多 8/秒，低于有效抓持 15/秒，不把“立即掉落结束”设计成比稳定抓住更划算。
预期减少缓慢滑移；这是待检验假设，不预写成已改善。

命令沿用 R01，只增加 `--weights artifacts/orca_collision_refit/weights_slip.json --speed-scale .005`，
输出改为 `artifacts/orca_collision_refit/R02_residual_slip`；仍 seed101、327680 步、5 次评估。
从相同零均值参数重新训练，不加载 R01 检查点，避免训练预算/优化器状态混淆。
