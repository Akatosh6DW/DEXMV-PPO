# S09奖励迭代预案：与固定对比分开

状态：已按下列预案完成6次配对续训和20项/480回合新测试，详见[实际结果](../../../artifacts/orca_benchmark_suite/S09/reward_iteration/report/results.md)。保留下列设计便于核对；执行证据为`reward_iteration`下的summary、日志及verification.json。

## 为什么改

冻结R0开发日志显示：纯PPO和BC后PPO部分回合穿透过大，BC种子9103的初始回放峰值超过500 N；残差也不是每例都满足穿透阈值。R0成功判据会拒绝这些回合，但即时奖励没有对穿透深度直接处罚，因此考虑增加一个接触质量惩罚。此依据来自开发监测，不是根据最终测试挑方向。

## 只改一个因素

R1奖励为：

`R1 = R0 - 0.05 * 5 * clip((本控制周期最大穿透米 - 0.0015) / 0.0015, 0, 4)`。

1.5 mm以内不罚，超过后逐渐扣分，上限每个控制步1分。成功标准依旧是释放后最大穿透不超过3 mm，不通过改标准制造成功。物理、圆柱质量、摩擦、绳力、观测、动作范围都不改。

## 排除“只是多训了”的混淆

- 对每种学习方法，均从R0训练种子9101的末步163840权重出发。
- 两个分支：保持R0奖励继续训练；改为R1奖励继续训练。
- 每分支额外40960步，统一新训练种子10101；优化器均重新初始化，均不重新BC，沿用该方法原定学习率和标准差参数。
- 每种方法两个分支共6次续训。参考回放不需要也不能“调整PPO奖励”。
- 开发监测仍使用92000至92007，记录first/last/max/best_step；继续训练分支固定取末步，不根据最终测试挑检查点。
- 正式R0四组比较必须先完成。本探索阶段不覆盖或混入R0表。

## 单独的探索性保留测试

计划使用新的随机朝向种子100000至100031，虎口方向种子100200至100215。比较原R0、同奖励续训、R1续训三个版本的三种学习方法，另加参考回放，共480回合。

只有一个续训种子，样本数也较少，所以只能回答“这次惩罚是否值得继续研究”，不能替代R0三种子的正式比较。即使R1变差，也保留结果，不因分数不好丢弃分支。最终候选可以按开发集末步表现选择，但新的测试成绩必须如实报告所有分支。

每种方法的候选选择顺序预先固定：开发集末步success30较高优先；并列时最大释放后穿透较小优先；再并列时平均最长保持较大优先；仍并列则优先原R0，避免无收益增加训练。选择不能访问新的测试成绩，且候选仍只代表仿真策略，不代表已经适用于任意方向或真实硬件。

这里的“候选”限定在seed9101的原模型及其两个续训分支，目的是比较同一出发点的奖励变化，不是声称找到了全工程最优权重。R0另外两个种子的模型和成绩照常保留。本阶段没有单独复测X/Y/Z三个固定轴，不能据此声称已修复竖直方向的失败。
