# S07数据目录与复查方法

主目录：[`artifacts/orca_benchmark_suite/S07/`](../../../artifacts/orca_benchmark_suite/S07/)。历史S05/S06没有被这次结果覆盖。

## 汇报先看什么

1. [结果说明](结果说明.md)：完整实验的正常条件、扰动、消融、配对得失和解释边界。
2. [aggregate.csv](../../../artifacts/orca_benchmark_suite/S07/report/aggregate.csv)：各方法按训练种子聚合，适合制作汇报总表。
3. [policy_summary.csv](../../../artifacts/orca_benchmark_suite/S07/report/policy_summary.csv)：每个具体权重的成功数、回合数、Wilson区间、保持时间、力和穿透。
4. [episodes.csv](../../../artifacts/orca_benchmark_suite/S07/report/episodes.csv)：每一测试回合的原始指标，不是只留成功案例。
5. [paired_changes.csv](../../../artifacts/orca_benchmark_suite/S07/report/paired_changes.csv)：相同初态下哪些回合救回、哪些变差。

这些CSV可以用Excel或Python读取。报告数据不需要加载策略权重；`.pkl`是重跑策略时才需要的网络参数，不是统计表。

## 核心文件的意义

| 路径 | 内容 | 用来检查什么 |
|---|---|---|
| `protocol.json`、本目录实验约定 | 测试前确定的任务与预算 | 防止看测试结果后更换规则 |
| `inputs_manifest.json` | 输入文件SHA256 | 场景、参考、BC数据是否被改动 |
| `inputs/model.xml` | 物理场景 | 手、圆柱、碰撞、执行器与数值设置 |
| `inputs/reference.npz` | 校正后的随时间变化关节目标 | 残差的基准，不是网络权重 |
| `inputs_uncorrected/reference.npz` | 离线仿真校正前参考 | 校正步骤是否必要 |
| `inputs_linear/reference.npz` | 同起点终点的线性闭合 | 中间时序是否额外有用 |
| `train/<方法>_s<种子>/metrics.csv` | 全部开发检查点指标 | 初值、末值、最好值和退化 |
| `train/.../ppo_metrics.jsonl` | 优化过程日志 | KL、损失等训练诊断，不能替代成功率 |
| `train/.../bc_loss.json` | BC拟合误差 | 是否学会标签，不等于实际抓持成功 |
| `selection.json` | 独立测试前选定的权重与哈希 | 测试期间有没有重新挑选 |
| `eval/<条件>/<策略>/run_config.json` | 权重来源、公共参数、源码哈希 | 本次到底评估了谁 |
| `eval/.../env_config.json` | 环境配置，其中`s07`是最终干预 | B3/B4是否真的改到最终圆柱模型 |
| `eval/.../step_000000000/episodes.json` | 每个测试初态的结果 | 全量原始指标来源 |
| `eval/.../step_000000000/initial_states.npz` | 初始关节/物体位姿和随机种子 | 不同方法是否同起点比较 |
| `eval/.../step_000000000/preview_trajectories.npz` | 保存的逐步状态、动作与审计 | 复算保持、验证残差、渲染视频 |
| `report/verification.json` | 复算和配对检查摘要 | 哪些检查实际完成 |

`eval`下名字里的`step_000000000`表示这次只评估、不更新网络。它不表示源策略没训练；实际训练步数看`selection.json`和`checkpoint`路径。

## 逐回合字段怎么理解

| 字段 | 含义 |
|---|---|
| `benchmark` | B0正常、B1位置、B2旋转、B3摩擦、B4质量、B5推力；A开头为执行时消融 |
| `run` / `train_seed` | 具体策略和训练随机种子；参考没有训练种子，表中用-1占位 |
| `seed` | 测试初始状态的种子，不是训练种子 |
| `success30` | 是否通过完整严格30秒标准 |
| `success15` | 同样其它约束下15秒标准，不能和30秒混用 |
| `pad_hold_sec` | 最长连续严格指腹保持秒数 |
| `broad_hold_sec` | 较宽松的普通保持秒数，不保证指定三指指腹 |
| `final_valid` | 40秒末端是否仍在严格有效保持 |
| `penetration_m` | 撤托后有效执行区间的最大穿透，单位米 |
| `forbidden` | 撤托后有效执行区间是否曾有禁止接触 |
| `peak_force_n` | 有效执行区间的单指组累计法向载荷峰值，单位N，包括撤托前；不是总抓取力，也不是电机力矩 |
| `pad_pair_fraction` | 撤托后合格指定指腹接触比例；沿用`pair`字段，但圆柱代表拇指且食指且中指 |
| `residual_rms_rad` | 请求修正的均方根，单位弧度；不是实际关节相对视频误差 |

力峰值在失败/数值不可信轨迹中可能极大，不能当成实物手可承受的力。穿透、禁止接触、掉落等失败原因可能同时出现；把它们分别计数时总数可超过失败回合数。

S08包覆小验证记录的`peak_force_n`是单个接触的法向力峰值，而S07是按指组汇总后的峰值；两个版本的这项数值不能直接放在同一列当统一力指标比较。

## NPZ里到底装了什么

NPZ是多个数组的压缩包，文件后缀相同不代表用途相同。

- 参考包：`time`、`ctrl`、初始控制、物体位姿、三指目标等，规定随时间怎么闭合。
- BC数据：`obs`、`action`、`active`，用于学“看到某个状态该给什么动作”。来自参考在Orca中的有效执行，不是人手角直接当Orca角。
- 评估轨迹：`qpos/qvel`为实际物理状态，`ctrl`为实际发送的目标，`action`为网络归一化输出，`video_base`为当步基准，`requested_residual`为请求修正，`effective_residual`为限幅限速后的目标减基准。
- `pad_audit`、`substep_penetration`等是每50 ms内10个5 ms物理子步的汇总，不是保存了每个子步的完整物理状态。可以据此复算严格保持，但不能声称NPZ含全部5 ms接触点细节。
- `active`表示这一步是否仍执行物理；终止后的占位重复帧不应被算成继续拿稳。

正常条件和消融保存每个回合的轨迹；扰动条件只保留前4条示例，但全部回合的指标和初态都保存。不能把“没有保存完整轨迹”说成“没有评估”。

## 其它分析数据

- `report/style_samples.csv`：采样时刻的三指位置误差、朝向、重建接触力。诊断采样不替代运行时成功判据。
- `report/style_by_episode.csv`：先每回合、每阶段平均，避免长回合占更多权重；只看合格保持仍有选择偏差。
- `report/reference_geometry.csv`：静态终态目标的几何误差，不是动力学抓持成功率。
- `report/residual_stats.csv`：请求/有效修正RMS、最大值、上限饱和比例、动作重组误差。
- `report/zero_gain_replay_checks.json`：关闭残差与参考回放的浮点路径差异。
- `bc_diagnosis_7102/`、`bc_cube_diagnosis/`：固定BC验证观测的动作漂移，分别对应圆柱和方块，不是相同输入数据。
- `bc_noise_std01/`、`bc_noise_std001/`、`cube_bc_noise_std01/`：冻结BC、只改采样噪声的开发诊断；没有重新训练，不混入独立主表。
- `cross_task_diagnosis/`：跨任务配置和曲线对照，不是只改变形状的因果消融。

## 如何复查

```bash
conda activate aero_rl
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
export XLA_PYTHON_CLIENT_PREALLOCATE=false MPLCONFIGDIR=/tmp/s07-matplotlib
python scripts/analyze_s07_study.py
python scripts/write_s07_report.py
```

分析重新读取原始结果、验证输入/权重哈希、初态配对、保存轨迹的严格保持和残差合成，再生成图表与报告。它不训练、不更换权重。重跑测试用`run_s07_study.py evaluate --workers 3`；完成目录跳过，部分目录拒绝自动覆盖，避免把历史结果悄悄替换。

图表英文标签是为了避免字体缺字，表头含义与本文一致。汇报引用时请带上任务版本S07、严格30秒标准、3个训练种子、正常64/扰动32个初态，不只摘一个百分比。
