# S10 零修正对照补充

在最终测试开始前补充这一检查，原冻结预案不覆盖、不改写。

`reference` 组把参考关节目标归一化成完整动作，再转换回关节目标；残差组直接执行 `clip(参考 + 0.08 * 修正)`。零修正时二者数学上相等，但浮点运算次序可能产生约1e-7量级差异。接触临界状态可以放大这些差异，不能把它们误归因于学习。

因此新增 `reference_exact_s0`，用残差环境和均值严格为零的未训练网络，在相同128个最终初态上评估。它不是额外学习方法，只是与残差执行算术完全一致的基础动作对照。残差是否带来净收益，优先与该组配对比较；原归一化参考回放结果仍然全部报告。

命令：

```bash
python scripts/run_s10_job.py --output artifacts/orca_benchmark_suite/S10/eval/reference_exact_s0 --method residual --steps 0 --seed 0 --eval-start 220000 --eval-count 128
```

程序初始化残差均值头的权重和偏置为零，确定性评估输出严格零修正；还应核验报告中 `residual_rms_rad=0`，不能仅凭命令名称声称零修正。

不根据该对照结果修改参考、训练配方或检查点选择规则。
