# 从头理解 S10：先把手转过去，再抓圆柱

## 这次到底改了什么

以前基座固定，物体朝向变了，只能让手指改变抓法。这次释放整手基座的三个平移、三个旋转自由度，先把手移动到熟悉的相对抓取位置，再闭合手指。

不是旋转摄像机，也不是开始时把手瞬移到成功姿态。正式策略评估中，所有朝向从同一个远处起点出发；前两秒能看见手实际移动、旋转。预先摆好手的情况只是额外的诊断对照。

任务仍沿用初始悬挂圆柱、之后撤支撑的抓持设置，不是从桌面拿起再搬运。手到达后保持基座目标，主要检验能否在无物体支撑时长期握住。

## 位姿矩阵具体负责什么

位姿包含位置和朝向。令 `T_world_object_demo` 表示示范中物体在世界中的位姿，`T_world_hand_demo` 表示示范中手基座的位姿，则：

```text
T_object_hand = inverse(T_world_object_demo) @ T_world_hand_demo
T_world_hand_target = T_world_object_now @ T_object_hand
```

第一行记住“手相对于物体应该在哪里”，第二行把这个关系搬到新物体位姿下。圆柱还有绕轴旋转和两端对调的几何对称性，代码利用这些对称性选择较小的整手转动，再加上开发集选定的绕轴调整。

这个矩阵改变的是整只手的基座位姿，不是把17维手部关节角直接拿来乘矩阵。手内部的动作仍由参考或网络给出。

## 谁决定手往哪里走

目前是确定性的对准器，不是PPO，也不是每回合搜索所有抓法。它读取开局物体位姿，用已经固定的参考关系算出目标，再在两秒内平滑接近。

这里有两个必须说明的限制：物体位姿来自仿真真值，并没有在线摄像头识别；整手使用理想六自由度位姿执行平台，没有真实机械臂关节、工作空间或力矩上限。模型中的手是动态刚体，并非逐帧直接赋值位置，但这不等于已验证真实机械臂。

## “最适合的角度”怎样选

先在开发初态上比较参考模板、轴对准规则和绕轴偏转。最终方案是参考0、最小轴转动、额外绕轴转动负0.5弧度（约负28.6度）。选择依据依次是成功率、保持时间和峰值接触力。

开发集中另一个不加偏转的方案同样成功，但接触力峰值更高。因此选了当前方案。这里的“最适合”只指已测候选中的选择，不是证明全球最优，也不是用最终测试结果反过来挑角度。

## 四种主方法分别控制什么

| 方法 | 整手移动 | 每一步手部关节目标 |
|---|---|---|
| 从零手指PPO | 相同的对准器 | PPO独立输出完整动作 |
| BC后PPO | 相同的对准器 | 先模仿，再由训练后的单网络输出完整动作 |
| 参考回放 | 相同的对准器 | 按时间播放固定参考，不学习修正 |
| 参考加残差PPO | 相同的对准器 | 固定参考加PPO的小修正 |

另外评估“仅BC”，用于判断接上PPO后究竟改善还是退化。它不是替换四组中的参考回放。

特别注意，从零PPO只表示手部网络从零训练。它仍共享这个由参考几何关系建立的整手对准器，因此不能称为整个系统完全没有先验。

## BC在这次学了什么

收集64个训练初态的参考回放，其中59条通过完整抓持标准，才拿来教BC。BC是行为克隆，即给网络看“观测对应什么动作”，让网络模仿。

本轮只有一个参考模板，BC预训练只使用时间/阶段输入，基本是在把参考动作随时间的变化学进网络。这一点很重要：不能说它已经学会根据滑落主动救物体。PPO接上以后才允许全部观测参与学习。

BC后PPO的执行方式不是“两个人每一步投票”。训练结束后，是一个网络独立给完整动作，原参考不再直接相加。BC提供的是这个网络的起点。

## 残差为什么不一样

残差执行时始终保留参考：

```text
目标关节角 = 参考关节角 + 0.08 * PPO输出
```

PPO输出限制在负1到正1，每个关节请求修正最多0.08弧度，约4.6度；随后还有关节限位和每个控制周期的变化速度限制。因此“实际执行目标减参考”不完全等于网络修正，要分别看日志中的 requested_residual 和 effective_residual。

大动作来自参考，小修正来自PPO，这才是执行时的残差结构。不过“小修正”不保证一定更好：临界接触可能被轻微改动破坏，必须与零修正回放比较。

## 一回合怎么进行

1. 随机生成圆柱朝向、正负2毫米位置扰动和小初速度，手从统一起点开始。
2. 前2秒整手接近、对准；参考动作延后2秒开始。
3. 第5秒撤掉圆柱支撑。撤支撑前的托住不计为成功抓持。
4. 最长运行到42秒。释放后需要连续合格保持至少30秒，且结束时仍合格。

“合格”不是只看物体还在画面里：需要拇指与至少一根对向手指的掌侧承力接触，不能依赖非法支撑，初始穿透和释放后穿透均有门槛，释放后绳力必须为零。

具体门槛是：初始穿透不超过1毫米、释放后穿透不超过3毫米，拇指与对向手指各承受超过0.02牛的合格接触法向力，物体相对出生高度下降小于15毫米。下降达到55毫米或离出生位置达到120毫米时提前终止。因此“还没掉出手”也可能已经不合格。接触条件按一个控制周期内的物理子步检查，不是只挑某个接触瞬间。

成功视频只截取从开始到释放后稳定4秒，但文件中的成功标签来自完整42秒评估。失败视频保留到首次失去合格抓持或掉落。目录标明来源，不用短视频替代长时统计。

原始逐例数据里的 `hold_sec` 是本回合最长的一段连续合格保持，汇总的 `mean_hold_sec` 是它的平均值。即使曾保持超过30秒，只要结束时不合格，仍会失败。因此平均保持时间很长，不代表成功率一定高。

## 为什么还要训练和测试三次

网络初始化和训练采样有随机性。每种在线方法用三个训练种子分别训练，每次163840次环境交互，然后用相同的128个保留初态测试末步权重。

163840不是回合数。32个仿真环境各执行一次动作，就累计32次交互。每次动作对应0.05秒模拟时间，底层物理还会做更细的积分。

测试中不改奖励，不挑最好的中间权重，也不因结果不好就换初态。参考回放不需要三个随机网络，所以只测一批128例。三次训练使用同一批测试初态，不能把它们当作384个完全独立的新场景。

## PPO的奖励到底是什么

本轮代码中的每步奖励保持不变：

```text
奖励 = 0.05 * (15 * 当前合格保持
              - 50 * 已掉落或越界
              + 2 * 拇指与对向手指的接触覆盖分
              + 2 * 释放前的指尖接近分)
```

“当前合格保持”和“已掉落或越界”是0或1；接触覆盖和接近分在0到1之间。释放后不再给接近分。末尾的0.05来自一个动作持续0.05秒。

这不是直接拿最终成功率当奖励。PPO优化累计奖励，最终统计还要求长时连续保持、结束有效以及历史穿透/非法支撑门槛。例如接触中断后重新握住可以继续得分，却可能不足以完成连续30秒。因此不能只看reward判断进步，也不能把全部退化简单归结为某个学习率。

本轮奖励没有直接惩罚峰值接触力。文档会单独报告力峰值，但不能声称训练已经优化了低力抓取或硬件安全。不同方法学习率和探索幅度也不同，相同在线步数只控制了一部分实验成本。

## 这次能回答什么，不能回答什么

能够检查：释放固定基座后，是否能连续移动到合适角度并抓稳；同一对准器下，四种手部控制方法有什么差异；BC接PPO是否改善；残差是否优于不修正。

不能仅凭这个实验断言：任意物体都可抓、真实机械臂可达、安全限力已满足、视觉误差已解决，或者PPO已经学会所有滑落恢复。重力不会随坐标变换消失；手心朝上和朝下的受力仍不同。

原前臂外壳是外观网格，不是完整实体碰撞模型。额外的几何距离核验只针对保存的预览帧，因此不能冒称完整机械臂避障已验证。
