# Orca 正式实验：预先冻结的执行协议

日期：2026-10-06（Asia/Singapore）。状态：协议与实现验证中，正式成绩尚未生成。
目标是完成整个对比实验，不是再次证明某个策略能抓住。预实验、开发调参和正式测试分开。
负结果是有效实验结果；不得为了让某方法胜出而修改成功标准或删除失败种子。

## 交付清单

- [ ] 主对比：BC、PPO、BC 初始化后 PPO、视频参考加残差 PPO，各触觉开/关，5 个训练种子，共 40 次。
- [ ] 视频贡献：残差基础动作为固定起手目标、平滑到视频末帧，两种各触觉开/关、5 种子，另 20 次。
- [ ] 探索幅度敏感性：BC+PPO 初始 std=0.03，触觉开/关、5 种子；与主表 std=0.7 分开。
- [ ] 零修正控制：视频、末帧、起手三个基础动作，在同一独立测试集直接闭环执行，不算 PPO 训练。
- [ ] 独立测试及位置、朝向、质量、摩擦、触觉噪声、推力敏感性，所有主表条件都测，不能只测赢家。
- [ ] 按训练种子统计均值、标准差、区间和配对差值，输出学习效率、接触力、穿透、掉落阶段。
- [ ] 原始输入、模型、源码、命令、检查点与评分独立审计，掌心视频包括成功与失败。
- [ ] 更复杂任务：固定瓶身单手拧盖，先取得同任务/同物体视频及可追溯几何，验证后单列正式比较。
- [ ] 最终中文 MD，包括术语、局限、方法优劣及可复现命令。所有清单验收后才称整个实验完成。

## 主实验冻结项

使用 O20 的 53 mm HIC20 同源物体、G08 手部碰撞拟合、O21 物理验证。
模型、源参考与数据文件哈希写入机器可读协议。沿用视频跟踪拟合，不冒称重新运行 RGB 提取。
原生 MuJoCo 物理回调 + Brax PPO；固定手腕，40 秒回合，t=3 秒完全撤支撑。
自碰撞未完整启用、35 g 质量与摩擦不是实测，因此这是该仿真任务的受限结论，不是硬件验证。

主比较训练种子为 301、302、303、304、305。旧 seed201/202 不纳入主统计。
开发监测初态为 JAX 11000-11015；最终独立测试为 NumPy 25000-25063，不能用测试结果再调参。
所有有 PPO 条件：655360 交互步，9 个等间隔检查点，128 并行环境，学习率 0.0003，
初始 std=0.7，其他参数使用冻结训练入口原配置。最终固定末尾检查点，最佳检查点仅描述曲线。
残差范围统一 +/-0.15 rad；纯 PPO 输出完整动作，不能假装两者控制权限相同。
BC 使用同源参考回放的 32 条轨迹（种子 8100-8131）、2000 次监督更新；75/25 按回合划分。
这是一个视频、非成功专家的示范集，不是 32 个独立示范视频。BC 的数据量与训练时间单列。
BC 与 BC+PPO 在每个种子/触觉条件下使用完全相同的初始化检查点。
主表不进行按方法的后验调参，估计的是统一训练配方下的效果，不宣称每种算法最佳性能。
触觉 critic 信息量、奖励、初态、网络尺寸保持一致，仅改变 actor 的传感输入。

视频消融只改变每步基础控制：video 保留原序列；endpoint 从共同起手目标限速直达视频末帧；
initial 始终保持共同起手目标。三者 reset 不变。纯 PPO 提供无在线参考的对照，但共享视频推导
的环境摆位；因此尚不能由这组实验声称完全排除环境设计先验。
小 std 的 BC+PPO 额外从同种子 BC 训练配方生成对应 std 检查点，不静默改动主表权重。

## 预定义测试条件

全部固定最终检查点；各条件共享 64 个初态种子与可配对的随机数，单次只改一个因素。
名义条件物体 xy 均匀扰动 +/-2 mm、关节初态标准差 0.002 rad。
额外条件为 xy +/-5/10 mm，世界竖直轴朝向 +/-10/20 度，质量 x0.5/1.5，
物体摩擦系数 x0.7/1.3，触觉噪声标准差 0.2 N，横向推力 0.1/0.2 N。
推力在 12/24 秒沿世界 x 正/负向各持续 0.2 秒。质量变化同时缩放该物体惯量。
改变姿态后支撑高度按实际最低顶点重新计算，必须审计初始穿透，而非把掉穿支撑当泛化失败。
变化是对视频同源物体的敏感性测试，不声称视频里出现这些参数或外力。
传感器断开与额外延迟属于扩展诊断，若实现须在运行对应测试前写入版本化协议。

主成功指标为连续有效无支撑保持至少 30 秒且末帧有效；同时记录 15 秒、最长保持、最终留存。
不能把支撑期计为成功，也不能把中途曾成功而最后掉落的回合算最终成功。
训练种子是统计重复单位；64 个初态是每个策略的重复测试，不伪装成 64 个独立训练。
输出五个种子的原始成绩、均值/标准差、按种子 bootstrap 95% 区间及配对差值区间。
五个种子的区间仍不稳定；双侧精确符号翻转检验最小 p=0.0625，不作虚假的 p<0.05 声称。
泛化与消融属于预定义次要分析；不在多个结果中挑一个显著结果作为主结论。

## 验证与更复杂任务

任何新参考模式先做 off/on/off 相同动作物理配对、限幅/限速、有限数值及碰撞核验。
固定起手负对照允许抓取失败；失败不得绕过物理数值或动作限制检查。
正式批处理每次运行后读取 metrics、生成 first/last/max/best_step、接触诊断，再开始下一次。
协议冻结后不在同一个主表里更换奖励。实现错误必须版本化，作废受影响条件并完整重跑。
进程中断只依据真实进程/退出状态处理，不凭日志暂时不更新就重复启动。

旧拧盖 C01-C18 使用的是跨任务抓握先验，不具备视频同源拧盖示范，不能纳入正式视频拧盖主表。
复杂任务的示范来源、物体尺寸、接触与螺纹约束须另外核查，不能用程序 IK 冒充视频。
这项尚未完成时，方块主表即使完成也不标记整个目标完成。
