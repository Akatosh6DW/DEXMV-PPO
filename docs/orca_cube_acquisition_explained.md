# 开放起手方块实验：视频引导、残差与 PPO

日期：2026-10-07。状态：已完成。9次PPO训练、3次配对BC、26批/1664回合主评估，另有长预算PPO的128回合验证。
本轮只抓方块，不做开瓶盖。它是新任务版本，不替换旧 F01 的结论。

## 一句话说在做什么

以前的手一开始已经接近夹住，纯 PPO 很容易把成绩做满，视频的作用不容易看出来。
现在让食指和拇指先张开一些，要求它们自己合拢、建立抓握，再把下面的托板撤走，继续拿稳。
这样同时考“会不会开始抓”和“抓住后能不能保持”。

不是让物体尺寸、碰撞模型或成功标准偏向某种方法。三种方法面对同一个 53 mm 方块、同一只精细 Orca 手、
相同随机初态和评分。重点比较有限练习次数下的学习速度与可靠性，不预设无限训练后的胜负。

## 三种方法有什么区别

| 方法 | 训练前得到什么 | 运行时谁发动作 |
|---|---|---|
| 纯 PPO | 没有示范 | PPO 直接决定全部关节目标 |
| BC 后 PPO（引导） | 先模仿成功示范，再用环境得分改进 | 只有训练后的网络直接决定全部关节目标；不是每步加法 |
| 视频基底 + 残差 PPO | 保留视频重定向及物理校正后的参考动作 | 每一步都执行“参考动作 + PPO 的小修正” |

BC 是行为克隆，也就是“看状态，照着示范动作练习”。它不是强化学习；接上 PPO 后才会根据试抓得分继续改进。
PPO 是通过试错更新动作网络的方法。残差不是另外一种强化学习算法，而是规定这个网络只输出小修正。

本轮残差公式：`目标角 = clip(参考角 + 0.08 * PPO输出, 关节上下限)`，PPO 输出限制在 `[-1,1]`。
随后三种方法都经过相同的速度限制：每个 0.05 秒控制周期，各关节最多改变 0.1 rad。
0.08 rad 约为 4.58 度。残差组不是先摆个起手就扔掉视频，而是每一步保留参考角。

这里的视频基底是带时间的关节参考，不是部署时实时看摄像头的视觉网络。
它提供约 1.5 秒的合拢过程，之后保持末姿态；剩下的动态调整由 PPO 根据当前状态完成。
不能把这说成完整复现视频里的人手搬运，也不能把末姿态维持包装成40秒新的视频动作。

## 视频和示范从哪里来

考察了公开 HIC20、HIC21 两段单手方块视频及作者发布的手/物体跟踪结果。
两个物体模型都是 53 x 53 x 53 mm；视频均为30帧/秒，跟踪有效帧数分别186/237，与视频对应。
本次读取公开跟踪结果，没有重新运行一个从 RGB 像素估计手姿态的模型。
同源匹配主要针对物体几何和相对坐标。35 g质量、摩擦系数和执行器接触参数仍是仿真假设，
不是从视频可靠量出的真实值；当前也没有复现魔方内部转动层。

在本次固定手腕和物体朝向下，HIC20 的拇指/食指目标更可达；HIC21 在相同对齐下误差大，因此没有混入训练。
这不说明 HIC21 天生不好，只说明它需要另外的物体朝向/夹持对齐，不适合直接加入当前固定场景。
筛选数据和源画面见 [source_screen](../artifacts/orca_cube_acquisition/source_screen/report.json)。

实际训练使用 **1 个源视频，HIC20 的30..95帧**。链路是：

1. 视频对应的公开跟踪结果给出人手关键点和方块姿态。
2. 原有 DexMV 适配结果提供物体坐标下的手指轨迹；继承 O15/O20 的 Orca 重定向。
3. IK（逆运动学）把指尖目标换算成 Orca 关节角，同时约束关节范围和穿透。
4. E01 对参考增加最大0.12 rad的有限关节偏置，并做真实接触仿真检查。这一步是仿真校正，不是假装来自新视频。
5. 用改进参考在64个扰动初态回放，筛出40条真正完成30秒且最终有效的轨迹。30条训练BC、10条验证BC。
6. 引导组学习这些状态/动作样本；残差组每步保留同一改进参考，再学习自己的修正。

40条是同一个视频在仿真里的40次成功回放，不是40个不同视频。未成功的24条没有消失，结果保留在D01报告里。
示范筛选还检查整条回放的活跃状态穿透，40条的最大值约1.606 mm。
这比旧实验直接拿失败回放训练BC更符合本轮目的，但不能证明跨视频泛化。

准备成本单列：参考搜索24条回放，实际14820个控制步；质量采集64x800=51200个控制步；
另有8条参考验证及几何筛选。BC还有4000次离线参数更新。不能把这些额外信息和计算说成免费获得。

## 任务和指标

- 起手：只适当打开食指与拇指的部分关节，保留拇指根部朝向；64个初态无明显手物穿透。
- 时序：2秒开始下移托板，3秒完全撤支撑，每个评估回合40秒。
- 接触：必须有拇指和至少另一根手指接触；不能靠掌部、托板或地面等禁接触部位托住。
- 高度：方块中心不能比初始位置低超过10 mm；下落55 mm直接终止。
- 主成功率：连续满足有效保持条件至少30秒，且40秒末仍然有效。
- 辅助指标：15秒成功率、最长连续保持、建立抓握比例、逐指法向力峰值、禁接触、穿透。
- 学习效率：从未训练开始的完整成功率曲线，不只展示最好检查点。

“曾经保持了30秒，后来掉了”不算主指标成功。
另报告更严格的清洁成功率：主指标成功之外，整个撤支撑后回合都无禁接触，保存状态穿透不超过3 mm。
不把“相似于视频的姿态”当作成功，更不把总奖励高直接说成抓得好。

## 实验步骤与预算

先做开发探测，再固定版本，换3个新训练种子901/902/903。种子可以理解为“从不同随机起点重新教三次”。
每种方法每次163840个PPO环境步，网络、任务、奖励和控制周期相同。
纯PPO的探索标准差0.7/学习率0.0003；引导为0.3/0.00003；残差为0.3/0.0003。
这些是经开发探测选择的各方法配方，不是完全相同超参数实验。

最后用20000..20063这64个没有参与示范和调参的初态测试，分别测XY各±2 mm与各±4 mm范围。
追加“只有BC”和“只播放参考、不给PPO修正”两种对照，分清收益来自示范、强化学习还是动作边界。
已完成26个评估批次、1664个回合，所有成功与失败均纳入统计，使用最终检查点。
只做3个训练种子，结果适合分析机制和指导下一轮，不足以宣称统计显著或普遍优于所有PPO。

## 精细手模型怎么验收

你记得的做法叫 **基于STL的碰撞代理拟合**：外观用原始三角网格，物理接触用胶囊、盒子及局部凸体组合，
再测它们与STL表面的偏差。这不是单纯把渲染画面变高清。

当前沿用G08局部重构、O20接触配置。指部仍有毫米级近似误差，不是硬件级精度认证；
不要只看整体外观，要重点看拇指/食指接触部位。旧几何审计见 [碰撞重构记录](orca_collision_refit_iteration.md)。

## 结果

下面是固定163840步PPO预算、3次独立训练后的结果，不是开发探测成绩。

| 方法 | 正常位置30秒成功率 | 位置偏差扩大后 | 正常位置平均最长保持 | 正常位置逐指峰值均值 |
|---|---:|---:|---:|---:|
| 纯PPO | 3/192，1.56% | 3/192，1.56% | 8.53 s | 29.66 N |
| BC后PPO | 105/192，54.69% | 104/192，54.17% | 31.43 s | 34.81 N |
| 视频基底+残差PPO | 140/192，72.92% | 123/192，64.06% | 35.32 s | 9.89 N |
| 仅BC | 110/192，57.29% | 76/192，39.58% | 30.30 s | 9.11 N |
| 只播放改进参考，零修正 | 42/64，65.63% | 38/64，59.38% | 34.69 s | 9.43 N |

人话解释：

1. **这个任务确实体现出了区别。** 同样的在线练习次数，视频相关的方法比从头摸索更容易拿稳方块。
2. **不能把所有收益都说成PPO带来的。** 改进参考自己已有65.63%的成功率，残差把它提高到72.92%，额外约7.29个百分点；扩大位置偏差后额外约4.69个百分点。
3. **BC之后接PPO不保证更好。** 正常位置的BC后PPO平均反而略低于仅BC；三个训练种子为0%、75%、89.06%，有一轮发生明显退化。
4. **残差更符合“大动作保留，小动作微调”。** 参考一直留在执行链里，PPO不容易把整套手型完全改坏；但它也不是100%成功，仍会慢滑或接触失效。
5. **纯PPO不是学不会。** 补充长预算实验中，第286720步的开发最佳检查点在独立测试达到64/64原始成功；但手物穿透全部超过3 mm，严格清洁成功为0/64。训练到655360步最终只剩8/64成功，不能拿中途最好的一帧替代最终结果。

长预算纯PPO的最佳/最终逐指峰值均值为61.13/105.33 N，最大穿透3.449/3.551 mm。
它说明延长训练能学到保持动作，也暴露了过大用力、接触质量和训练退化问题，不是硬件上安全完成任务的证据。

几何质量也没有隐藏：正常范围内各主方法的最大手物穿透都小于3 mm。
偏差扩大后，引导组8/192、残差组2/192、零修正1/64回合超过3 mm；最大分别4.843/3.048/3.056 mm。
按更严格的清洁成功定义，残差为72.40%/63.54%，引导为54.69%/53.65%。
置信区间按训练种子计算，只有3个种子，不能宣称统计显著；尤其引导组的不确定性很大。

## 下一轮该优化什么

优先顺序应是：保持当前任务作基准，逐项加接触质量/过大力约束，再检查训练后期是否退化；
不要只加训练步数。BC引导需要避免遗忘，例如更保守更新或持续示范约束，这与执行时残差是两回事。
残差仍需要更好的物体相对基底和更多可达的真实视频片段，不能把本次单视频结果外推到任意物体。

当前参考主要让拇指和食指参与，其他手指只有很小的残差活动范围。
若要利用更多自由度，应先让基底给出多指可达抓型，再让PPO微调；单纯增大残差范围会逐渐失去“小修正”的保护。
这些是下一轮建议，本次没有在独立测试结果出来后暗改任务、奖励或成功标准。
