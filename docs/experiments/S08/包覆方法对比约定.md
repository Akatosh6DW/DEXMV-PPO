# S08：修复摆位后的纵向包覆方法对比

本约定在训练与独立测试之前冻结。P03只改位置的26/32是几何开发证据，不复用83200系列种子作为独立测试。

## 任务与来源

场景使用`S08_wrap_position/model.xml`，参考使用同目录`reference.npz`：纵向53 mm直径、53 mm高、35 g圆柱，初始位置抬高12 mm。手从张开闭合，2秒开始撤托，3秒后独立保持，回合40秒。

本轮参考来自S08几何求解及摆位筛选，不是重新提取的人类视频。主要回答同一个可行参考下，BC初始化、在线PPO与执行时残差的区别；不能冒称验证视频先验不可替代。历史S05～S07视频/示范来源分别保留。

## 方法与预算

- 纯PPO：输出完整17维关节目标；不读取参考控制序列作为输入或奖励。
- BC+PPO：新场景参考回放生成成功状态动作对，BC预训练后输出完整动作，再训练PPO。
- 残差PPO：每步参考目标加17维修正，每维最大0.08 rad，不累加；关节范围裁剪与50 ms内0.1 rad变化限制相同。
- 仅BC：BC+PPO训练前零在线步检查点，单独评估。
- 参考回放：执行参考角度，无学习策略网络。

三种在线训练方法各3种子8501/8502/8503，每次163840在线交互步，32并行环境、20步rollout、4 minibatches、每批4次更新，学习率1e-4、初始标准差0.1、熵系数0.0001、折扣0.99。BC额外20000梯度更新，成本另列。不是相同总计算成本。

奖励全程固定、三方法相同：`0.05*(15*有效包覆 -50*掉落终止 +2*接触覆盖 +5*高度保持)`。接触覆盖由掌面、拇指、其余手指的曲面载荷形成，不读取示范关节角；高度保持沿用5 mm尺度指数项。本轮没有依据测试日志循环调奖励。

有效包覆遵循P03：掌面与拇指各>0.02 N，另外至少两指各>0.02 N，均需合格掌侧曲面接触；禁止非手物体承托，撤托后手物穿透<=3 mm、高度损失<15 mm，初态穿透<=1 mm。连续有效至少30秒且40秒结束仍有效。每5 ms检查载荷/穿透，50 ms末检查高度和累计保持。

相对P03，训练接口采用与S07一致的JAX随机初态生成与float32策略接口，不能预期同数字种子复现NumPy开发回放；接触判定函数和最终物理模型不变。动作和物理状态的双精度积分由原生MuJoCo保留。

## 数据分割与选择

- 示范采集86000～86031，筛选合格30秒轨迹；这些是同一几何参考的不同仿真执行，不是独立视频。少于4条则停止，诊断，不偷用测试集。
- 开发85000～85007，每20480步评估一次，包含0步和163840步，共9次。
- 正步数检查点按开发成功率、平均保持时间、较晚步数依次选取；BC零步单列。
- 全部9个训练结束后冻结选择哈希，才开始87000系列独立评估。不根据独立测试改奖励或重新挑权重。

## 测试和消融

沿用S07流程：正常条件13个策略实例（3纯PPO、3BC+PPO、3残差、3仅BC、1参考），每个64个初态87000～87063；5个扰动条件各32个初态87000～87031。

扰动：位置由±2扩大至±6 mm；世界Z偏航±10度；摩擦乘0.6；质量和惯性乘2；10秒施加水平0.15 N推力0.2秒。纵向轴对称圆柱的Z偏航主要是对称性检查，不能视作大姿态泛化证明；不偷偷改成倾斜后与旧S07混称同一条件。

三个残差各做增益0和0.5干预，正常增益1，每个64个相同初态。零增益应退化到参考回放。

额外参考消融各64次：`linear`目录实际是相同终点的快速限速闭合（P03原参考已经是1.5秒线性闭合，重复生成同一条没有意义）；`uncorrected`目录使用P01拇指方向校正前的几何控制轨迹，物体初态仍使用P03位置。这两项都不是未校正视频消融。

合计86个评估任务、3424个回合。正常和消融保存全部轨迹；扰动保留每任务前4条轨迹，其余保留初态和逐回合原始统计。保留所有失败和训练退化。

## 审计与交付

开始训练前检查新环境参考回放、初态穿透、手部控制范围、零残差恒等、质量/摩擦对最终模型生效、包覆判据不把掌面判为禁止接触。明确记录与P03计数和观测接口的关系。

最终报告每训练种子成功率、均值与离散、配对得失、保持、穿透、力峰值、残差幅度、BC误差与训练曲线。接触峰值沿用训练框架的按手指分组口径并兼顾单点峰值，不与P03单点峰值直接排名。参考跟随误差可以报告，但不是人类视频相似度。

交付一个集中资料目录，分别放S05/S06/S07/S08：说明、方案、原理、图表、原始CSV/JSON/日志、参考和必要评估NPZ、主要策略手心视频（外观/碰撞体）。不拷贝权重PKL和无关checkpoint；原工程结果不移动破坏路径。提供总目录、各实验目录、文件来源与SHA256，以及可移动压缩包。视频成功剪至连续拿稳4秒，掉落失败剪至终止；未掉落但失败的情况明确标注，不伪装成功。
