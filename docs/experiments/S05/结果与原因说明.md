# 实验5：为什么原来用食指侧面，以及怎样修复

本文只讨论本次方块抓取姿势修复。圆柱的旧展示也发现侧面接触，但本次方块结果不能自动推广到圆柱。S02、S04 和圆柱 S02 的旧模型、统计不被覆盖。

任务沿用固定手的抓持设置：方块最初放在可撤下托台上，手先合拢，约2秒开始撤托，3秒起考核无托持的抓持。这不是机械臂从桌面主动捡起并搬运物体，也没有复现人类源视频完整的两支柱之间搬运过程；本次使用其中的两指夹持先验。

## 1. 先回答最初的问题

你的怀疑有依据：旧视频里确实不是理想的食指指腹夹持，不只是摄像机角度导致的错觉。

人类样本 HIC20 的几张关键帧显示，拇指和食指末端在方块两侧夹住物体，另外三指伸在外面。它不像旧机器人展示那样明显依靠食指侧面。但是单目视频有遮挡，不能把看不见的皮肤接触区说成已经精确测量。

![原人类视频关键帧](../../../artifacts/orca_collision_refit/O01_hic53_source_object/source_frames_0_45_95_140.png)

样本清单确认这是序列20，虽然旧资料目录名保留了`hic53`字样。视频186帧、30FPS，约6.2秒；对应物体外形边长53mm。仿真把它作为单个刚体，不模拟魔方内部转动。35g质量和摩擦参数属于原仿真假设，并不是从视频测出来的。[原始来源清单](../../../artifacts/orca_collision_refit/O01_hic53_source_object/manifest.json)

机器人这边有额外证据：从九个已交付展示案例保存的状态重建接触，六个方块案例的食指末节接触均主要沿局部侧向法线承力。旧残差案例的食指平均法线约为 `[0.261,-0.939,0.223]`，即大部分朝向侧面负Y，而不是指腹负X。

数据：[接触诊断JSON](../../../artifacts/orca_benchmark_suite/S05/diagnosis/report.json)、[接触明细CSV](../../../artifacts/orca_benchmark_suite/S05/diagnosis/contacts.csv)。这是展示案例的检查，不是对整个旧实验所有回合的重新评估。

## 2. 为什么位置看着差不多，抓法却不一样

可以把原来的重定向理解为：“让机器人指尖的某个标记点，尽量走到人手指尖对应的位置。”

问题是，**点的位置对上，不代表手指的朝向对上**。拿一支笔，笔尖放在同一个地方，笔身仍然可以朝不同方向。机械手的手指长度、关节轴和人手又不同，所以它可能把指尖侧边转向物体来完成这个位置要求。

原来的奖励主要在问“有没有抓住、掉没掉、有没有违规接触”，没有问“食指究竟用哪一面抓”。球形或胶囊形的碰撞代理允许整个表面承力，名字叫 `tip` 也不能保证是在指腹。

因此不能指望 PPO 自动知道你更想要指腹抓取。对于原奖励，侧面抓住也是合法答案。BC 还可能把示范映射中的侧面抓法继续学下来。

## 3. 本次不是只换镜头，实际改了什么

1. 从已有的人类三维跟踪结果重新做物体相对坐标重定向，保留拇指/食指在方块两侧夹持的关系。没有声称重新运行整套原始视频视觉提取网络。
2. 逆运动学不再只匹配点，还要求末节指腹朝向物体。
3. 允许腕关节参加重定向。最终主线保留原来的整手安装位置和方向，不采用早期整体旋转安装的候选。
4. 加入非目标指节的2mm几何净空约束，避免食指近节偷偷托住物体。
5. 参考先做有界仿真校正。这一步搜索参考控制，不是 PPO，也不是未经处理的纯视频动作。主线 P17 的校正范围为每个选中关节±0.24rad，实际量保存在 `reference.npz` 中。
6. 改训练判据：两指必须由末节指腹承力，不能靠两指侧面或近节同时撑住。
7. 重新初始化并训练 PPO 残差策略，不接着旧侧面抓法权重训练。

主线物理模型保留原来的STL、碰撞代理、物体尺寸、质量、惯性、摩擦系数、关节范围及执行器增益。物体初始工作区、腕姿态和参考动作发生了改变。

另有一个必须单独披露的变化：MuJoCo 的 `impratio` 从1改为2.2。它调节摩擦约束相对法向约束的阻抗，不是把摩擦系数改大。在本模型里，原软接触设置即使夹紧力较大，也会产生慢滑。官方文档也介绍了这类现象及对应数值设置。[MuJoCo 慢滑说明](https://mujoco.readthedocs.io/en/stable/modeling.html#preventing-slip)

**这项改变的收益属于仿真求解设置，不能记在 PPO 头上。** NoSlip后处理及更高impratio曾出现过穿透或不稳定，未采用。最终仍是5ms物理步长、50ms控制步长、NoSlip=0。取消手物接触后物体会掉落，成功不是靠隐藏固定约束。

## 4. 新的“抓对了”是什么意思

本实验把指腹定义为末节靠近尖端、朝屈曲侧的接触区域，而不是要求接触恰好落在手指最尖的一个数学点。

| 要求 | 具体标准 |
|---|---|
| 部位 | 拇指和食指都在末节，不是近节 |
| 沿指长度 | 拇指局部Z至少15mm，食指至少24mm |
| 朝向 | 指向物体的法线满足 `-nx>=0.7` 且 `abs(ny)<=0.5` |
| 真正承力 | 两个合格区域的法向承力各大于0.02N |
| 排除其他部位 | 两指非合格区域承力不能超过0.02N |
| 物体仍拿住 | 高度不低于初始高度10mm以上，仍满足旧任务接触与终止条件 |
| 接触干净 | 撤托后无禁止接触，最大穿透不超过3mm |
| 时间 | 一个40秒回合中连续合格保持至少30秒，回合末仍有效 |

每个50ms动作包含10个5ms物理子步；全部子步合格，这个动作步才累计保持时间。不是只从视频抽一帧看着像就算成功。

这些阈值是工程定义，不代表已经从单目视频精确恢复了人类皮肤的接触法线。其他三根手指依然存在碰撞，没有删掉实体让物体“穿过去”。

## 5. 视频参考和 PPO 如何共同决定动作

每次控制都执行：

```text
基础目标 = 视频重定向并经仿真校正的参考关节角 q_ref(t)
PPO修正 = 0.08 * clip(PPO输出, -1, 1)              # 单位：弧度
最终目标 = clip(基础目标 + PPO修正, 各关节控制范围)
实际发送 = 再限制本步关节目标的最大变化量
```

PPO 使用当前关节状态、物体相对状态、触觉及参考等观测；它不是重新看RGB视频。参考在执行时一直存在，不是只设置一个起手姿势。

BC+PPO 是另一个分支：先用 `(观测, 参考动作)` 示例训练网络模仿，再由 PPO 在线训练完整动作输出。它执行时没有显式“基础动作加修正量”的结构。两种方法不能混称。

本次BC用24个新回合，按回合划分18个训练、6个离线验证，训练4000次梯度更新。验证集动作拟合损失由约1.027降到2.88e-5，但开发初态的闭环成功仍只有1/4。这个结果直接说明：离线模仿误差很小，不保证真正连续控制时能成功。误差累积、偏离示范覆盖的状态和接触敏感性都是可能因素，本次没有把这些因素逐一做因果消融。

本次保存了 `video_base`、`requested_residual`、`effective_residual`、`ctrl`，可以复算最终控制。T07中期复算最大误差约1.79e-7rad，证明执行链路确实是残差组合。

两种PPO主线的最终奖励相同，单次训练内部不动态改奖励：

```text
每步奖励 = 0.05 * (15*合格指腹抓持 - 50*掉落终止
                   + 2*靠近且指腹朝向物体的程度 + 5*高度保持程度)
```

其中高度保持项只在撤托、接触合格且未终止时启用。开发中曾在不同训练轮之间修改奖励或求解设置，每次都有独立目录和记录；最终T08/T10内部没有大模型一边读取日志一边偷偷更换奖励。

163840步是32个并行环境累计的控制交互次数，不是163840回合，也不是每个手各训练这么多步。一个控制步50ms，一个完整评估回合800步即40秒。PPO基于这些交互中的观测、动作和奖励，分批更新网络。

## 6. 为什么不能只展示最好的一次

目前开发结果说明：修正接触方式后，首先要让参考在物理上可行，然后才能检验策略是否稳定。原始“抓到就行”的成功率不能与新指腹标准直接比较。

| 开发阶段 | 实际发现 |
|---|---|
| 原侧面展示 | 旧标准能成功，但食指侧向承力 |
| 只匹配指腹姿态 | 静态位置误差可很小，动态仍会掉落 |
| 允许腕参与，但不留非目标净空 | 有的回合实际上靠食指近节托住，必须拒绝 |
| P17：新参考、原impratio=1 | 指腹保持约18.4～19.0秒，随后慢滑 |
| T05：impratio=2，PPO 40960步 | 平均保持36.29秒，但4个末次评估均在最后失去高度标准 |
| T06：只提高学习率 | 没有解决末段慢滑，未作为最终方向 |
| T07：impratio=2.2，PPO 40960步 | 开发4/4成功，连续合格保持37.05秒，穿透最大1.705mm |

T07 零步参考也为4/4。因此这时的正确结论是“修复后的指腹参考可执行，真实残差PPO训练后保持了它”，不是“PPO把成功率从0提高到100%”。

## 7. 最终验证结果

已完成。两个PPO分支均从新初始化训练163840步，按开发结果冻结权重，再用同一组32个未用于调试的初态测试。初态种子为52000～52031，XY各±2mm扰动；四种方法初始关节和物体位置逐元素一致。没有根据这组测试结果再调参。

| 方法 | 合格成功数 | 成功率 | 平均最长合格保持 | 最大穿透 | 峰值接触力 |
|---|---:|---:|---:|---:|---:|
| 仅校正参考回放 | 32/32 | 100% | 37.05s | 1.700mm | 23.40N |
| 视频参考+残差PPO | 32/32 | 100% | 37.05s | 1.714mm | 23.51N |
| 仅BC | 8/32 | 25% | 9.26s | 1.711mm | 31.32N |
| BC+PPO | 32/32 | 100% | 37.05s | 2.208mm | 32.18N |

全部方法撤托后禁止接触回合数为0。两个训练策略的指腹对接触比例均为100%。仅BC失败24回合，不能因为有成功片就包装成已经可靠。

32/32的Wilson 95%区间约为89.28%～100%；8/32约为13.25%～42.11%。区间提示测试样本有限，不是声称真实成功率已确定为100%。这里只有一个训练种子，区间没有覆盖不同训练随机种子的波动。

![独立测试和开发训练曲线](../../../artifacts/orca_benchmark_suite/S05/E01_independent/success_and_training.png)

图中`reference`为参考回放，`residual`为残差PPO，`bc_only`为仅BC，`guided`为BC+PPO。右图是4个开发初态的训练曲线，左图才是32个新初态的最终测试，两者不能混用。

**可以得出的结论：** 方块任务的侧面接触问题已通过参考构造、接触判据和重新训练得到修复；两个策略在本次独立测试中都用合格指腹持续拿住方块。BC+PPO在同一批测试中从BC的25%提升到100%。

**不能得出的结论：** 残差PPO比校正参考成功率更高。本次二者都是100%，主要成功来源包括更合适的参考和接触求解设置；PPO确实训练并参与每步控制，但此测试没有证明它带来额外成功率收益。也不能宣称比旧纯PPO更优，因为本次没有在新条件下重新训练纯PPO。

残差实际输出RMS约0.003014rad，最大约0.00813rad，远小于0.08rad的允许上界。全部32回合按“参考+修正、再限幅限速”复算控制的最大误差为1.79e-7rad，确认不是只在训练时使用视频。

原始数据：[128回合CSV](../../../artifacts/orca_benchmark_suite/S05/E01_independent/all_episodes.csv)、[完整统计JSON](../../../artifacts/orca_benchmark_suite/S05/E01_independent/summary.json)、[冻结权重及哈希](../../../artifacts/orca_benchmark_suite/S05/E01_independent/selection.json)、[几何不变性核对](../../../artifacts/orca_benchmark_suite/S05/E01_independent/geometry_invariants.json)。

残差策略32条独立轨迹的接触重建中，拇指和食指各有11872条采样接触记录，均位于定义的指腹区域。食指平均法线约为 `[-0.987,0.100,0.124]`，主要朝向指腹负X，而不再主要朝侧面负Y。接触重建用于解释空间位置，成功统计仍以仿真运行时的5ms子步审计为准。

## 8. 仍然有哪些不足

- 本次先解决接触部位，不等于完整复制了人类姿势。人手与Orca的比例、关节轴、安装方式不同。
- 当前夹持力偏大。T08开发轨迹重建中，两指法向承力中位数各约21.76N，远不能凭“物体不掉”就称为轻柔、节能或适合硬件的捏取；后续应增加执行器力矩/接触力限制并重新验证。
- STL是外观，接触仍由拟合的球/胶囊等代理承担。本次没有证明碰撞模型对真实硬件接触的毫米级精度。
- 参考需要仿真校正和数值设置校准，不是任何视频拿来就能直接部署。
- 没有实机实验，也没有本次圆柱重训、全扰动测试或多训练种子统计。

这些边界不改变“旧抓法确有侧面接触，需要显式约束接触区域”的诊断，但限制了可以宣称的修复效果。
