# S03 实验设计

2026-10-08，开发开始前记录。正式测试命令矩阵须在开发结束后封存，之后不因结果调整。

## 研究问题

1. 视频参考+残差能否优于经过相同受控开发预算调试的PPO，而不仅是旧固定配方？
2. 给到更长预算后，方法的最终能力、样本效率和训练退化如何变化？
3. 残差的作用来自随状态调整，还是接近固定的参考偏置？
4. 在未参与训练的长方体和球体上，哪些方法可以迁移，哪些失败？

## 开发阶段

三个独立开发分支：ppo、guided（BC后PPO）、residual。每分支四轮，每轮两个种子
20001/20002，从头训练163840步，开发初态61000..61015，检查点0/81920/163840。
每分支8次训练，合计24次。BC仍使用同一份既有D01数据，每次4000次更新，额外成本单列。

每轮候选相对当前保留配方只改一个量：

| 轮次 | 改动 | 动机 |
|---|---|---|
| R0 | 原S02配方 | 建立开发基线 |
| R1 | 探索std：ppo从0.7到0.3，其他从0.3到0.7 | 检查探索范围是否妨碍学习 |
| R2 | 当前保留配方学习率除以4 | 检查更新过激和训练退化 |
| R3 | 当前保留配方接近奖励倍率改为0 | 检查接近塑形依赖，做奖励减法 |

按两个开发种子的平均清洁成功率曲线面积选优，其次最终清洁成功率，再其次较小末次指力；
完全并列保留更早候选。每轮写first/last/max/best_step、所有失败、保留理由和下一轮参数。
清洁验收按5ms子步执行，不用穿透抓握的高原始成功率选优。完整保留失败候选及其成本。
这是一条有限预算、日志驱动的坐标搜索，不等于找到全球最优PPO，也不是完整复现Aero历史开发。

## 确认训练与最终能力

四组：旧固定配方PPO、开发选出的PPO、开发选出的BC后PPO、开发选出的残差。
配方冻结后各用十个新种子21001..21010，从头训练655360步，保留163840与655360步
作为预定短/长预算检查点，两者是同一次训练的相关检查点，不伪装成独立训练。
不能从开发最好权重继续训练，也不能用正式测试择优检查点。
额外对照：匹配BC初始策略、零修正视频参考。

评分沿用S02：40秒回合、撤托后连续有效保持至少30秒且末状态有效，清洁指标另外要求
撤托后全部物理子步无禁接触且穿透不超过3mm。整段穿透补充与原始成功率同时报告。
训练可按各组开发配方改奖励，测试成功定义、手型、几何、起手、传感接口和限幅全部共享。
旧Aero C157仅作工程背景，不能将它的36.65秒保持指标塞进Orca成功率表。

主要测试初态71000..71199，各方法配对。采用B0..B5六个既有条件但使用新初态，
同时保留曲线、未达到目标阈值、峰值力和穿透；不只展示最好视频。

## 闭环机制

同一残差模型，先在无外力条件记录每个初态的完整修正序列，再在配对外力条件固定回放，
与实时读取状态的闭环修正比较。基底、初态、外力、关节限幅与执行器完全一致。
固定序列来自无扰动回合，不可从受扰动回合提取后再声称是开环对照。
先核对零外力时两种执行路径逐步匹配；施力前也应匹配。终止后的序列不当作有效控制证据。
具体执行规则：无扰动源回合一旦终止，之后的回放修正量置零；相同轨迹核验只比较
源回合仍活跃的步骤。该规则不根据受扰动回合结果改变。

扰动幅度仅用开发初态62000..62015，按0.15/0.3/0.6/1.2N的固定阶梯做可辨识度检查；
选择零参考有效回合中11.2秒有效率最接近50%的最小力，平局取较小力，并完整保留阶梯结果。
不得按“残差赢得最多”的幅度选择。正式机制测试72000..72199。
无论是否有收益，都报告无条件成功率、施力前有效分母、11.2秒有效率及长期保持。

## 新物体

计划两个留出形状：53x42x60mm长方体、直径53mm球体，质量均35g。
尺寸按物体局部坐标给出，沿用来源方块四元数；长方体世界竖直厚度为42mm。
只在方块上训练，不在新形状上调策略、重做示范或挑成功初态，正式初态73000..73199。
准备阶段只检查几何、初始穿透、惯量、支撑高度与渲染，不按策略成绩筛对象。
新形状需要独立编译模型并验证native后端，不能绕过旧HIC53的源物体绑定检查。
若有初态几何问题，应在正式测试前记录修复并让所有方法共享；不能删掉困难回合。

## 成本与统计

分别报告固定配方训练、受控开发搜索、确认训练、视频/参考准备、示范收集、BC更新的成本。
当前已有参考/数据的历史准备成本沿用可核实记录；无法恢复的人力/大模型费用标未知，不能填零。
相同在线步数不等于相同总成本，最多能声称受控候选训练预算一致。

预定三项主要比较：B0长预算残差减调试后PPO、残差减BC后PPO、机制外力条件闭环减固定回放。
十个训练种子配对检验，主要三项Holm校正，训练种子/共同测试初态交叉bootstrap区间。
其他预算、条件、形状和固定PPO对照为描述性扩展，全部报告，不在看到结果后升为主比较。
不通过显著性门槛不等于证明等效，不追加种子直到显著。

### 接触质量补充（开发日志驱动，不属于主检验）

确认训练种子21006在开发评估集上出现原始成功16/16、清洁成功0/16，而穿透仅3.201..3.447mm。
据此增加一个明确标记的描述性敏感性分析：最终全部回合统一计算2/3/4/5mm下的成功率，
并报告连续穿透量和全部/原始成功/清洁成功条件下的指力峰值及分母。
这是原协议后的补充，不伪装成最初预定主假设；3mm官方指标与三项Holm主比较完全不变。
不再训练、不更换物体、初态或检查点，不添加新的显著性检验。
脚本为`supplement_orca_s03_quality.py`，在完整主统计之后单独执行。

## 固定矩阵规模

40项确认训练，各保留9个检查点；正式使用163840和655360步两档。
每个普通条件包含4组x2预算x10训练种子、10个BC初始策略和1个零参考，合计91项。
6个方块条件加2个新物体共728项普通评估，每项200回合。
另有10项机制评估，每项4条执行路径x200回合，正式测试合计153600回合。
扰动标定4项x16回合仅属开发集，不混入正式样本。

视频预定采用训练种子21001及各条件第一个测试初态，展示长预算四组、BC和零参考，
机制展示有外力闭环/回放两条路径；均保留STL和碰撞体手心视角。
固定案例中成功与失败均保留，不根据效果更换种子。终止后只作带标识的诊断尾段。
