# 当前BC+PPO改进主线：任务、证据和边界

本页是阅读入口，不替代原始实验记录。先读这里，再按链接查看逐例数据。历史失败不删除，测试集不用于回头重选模型。

## 1. 现在究竟在抓什么

是固定基座Orca右手抓圆柱，不是开瓶盖。圆柱直径53mm、高53mm、质量35g；在手的可达区域内随机三维朝向，位置仅有正负2mm扰动。“任意方向”指这个采样域，不是任意空间位置，也不是已经证明所有朝向都能抓。

起初有理想化悬吊支撑，合力通过物体质心，3秒撤去；它不是会产生端部悬吊转矩的真实绳结。手有17维执行器，基座不动。40秒回合中须连续合格30秒，并在结束时仍合格：拇指和至少一根对向手指的合格掌侧接触承力、无非法支撑、释放后无绳力、高度和穿透符合原阈值。接触条件每个物理子步检查。没有降低门槛制造提升。

## 2. 视频、BC、PPO各做什么

当前训练使用已有DexMV处理后的示范，经Orca重定向和接触校正形成参考与成功仿真示范。本轮没有换新视频，没有从原始RGB重新运行手部估计器，不能把新训练称作“新视频提取成果”。

BC（行为克隆）用示范里的观测和动作训练网络。此阶段型版本先学“初始朝向、时间阶段对应什么手型”，不是天然会补救的控制器。随后PPO通过仿真探索、奖励和价值估计更新网络；全部实时观测连接可训练，执行时由网络输出完整关节目标。

真实祖先路径如下，三条来源均按此结构：

```text
固定示范集 → BC监督40000次更新
          → 单网络PPO 163840次交互
          → 单网络PPO再491520次交互：累计655360
          → 动作网络复制为六个按初始朝向选择的专家
          → 专家PPO再655360次交互：累计1310720
```

BC更新次数不是仿真交互次数。续训配置里可能仍有默认`bc_updates=4000`字段，但这些续训加载checkpoint、没有dataset，不会因此重新做4000次BC。数据和源码见各run_config及sources快照。

本条主线保持R0奖励不变，actor学习率3e-6、critic学习率3e-4。actor是决定动作的网络，critic是估计未来回报的网络。此前穿透惩罚、连续保持奖励、探索和约束等试验另有记录，并不是运行中由大模型悄悄改写这次冻结训练。

## 3. 三种最终动作不能混淆

| 路线 | 每一步怎样决定动作 | 是否新增训练 |
|---|---|---|
| 普通BC后PPO | 一个可更新网络输出完整目标 | PPO会更新这个网络 |
| 分专家BC后PPO | 初始朝向选择一个专家，该专家读取当前状态并输出完整目标 | 各专家经PPO训练，actor容量六倍 |
| 历史检查点组合 | 每类保留BC/中期PPO/末期PPO中旧开发表现较好的完整actor | 拼接阶段新增0步PPO，仍继承原训练成本 |
| 执行级残差 | 基础动作 + PPO修正量 | 训练修正分支；基础可以是参考或冻结学习策略 |

历史组合不是把两个动作相加，不是残差。分专家也不等于每个具体测试姿态单独训练：六个粗类别覆盖连续朝向域，类别由开局观测决定，不使用未来成功信息。

## 4. 已完成的长训确认说明了什么

在事先冻结的190000--190255新256初态上，三个训练来源全部纳入；每组768策略-初态对，但只有三个训练来源。

| 方法 | 平均严格成功率 | 三来源分别 |
|---|---:|---|
| 原BC | 38.02% | 36.72% / 39.06% / 38.28% |
| 累计655360步的阶段起点 | 42.19% | 40.23% / 44.53% / 41.80% |
| 同预算单网络长训末步 | 27.60% | 30.47% / 30.08% / 22.27% |
| 专家长训末步 | 39.71% | 36.72% / 50.78% / 31.64% |

专家比单网络长训平均高12.11个百分点，配对描述性95%区间[4.56,21.09]；但比原BC只高1.69，区间[-8.59,11.98]。所以它缓解了长训退化，却没有证明跨来源稳定超过BC。不能只展示第二个正来源，也不能把原有单来源正结果当所有来源的保证。

开发集曾显示专家46.88%、BC38.02%，但在新集差距明显缩小。这也是为何不能继续在同64开发初态上反复试，最后只挑高点来证明有效。

[三来源长训解释、原始数据与全部核验](专家长阶段多来源验证_2026-10-21.md)。同预算指在线交互步数相同，不代表参数量、算力或调参总成本相同。

## 5. 为什么继续检查历史组合

长训可能学会某些新抓法，同时改坏旧抓法。历史组合保留每类不同阶段的强项，检验“选对保留什么”是否比“全部用最后一次权重”更实用。它不能解决所有反馈学习问题，也不能冒充单网络优化已经稳定。

三来源各自只用旧64开发初态，从BC、阶段、专家真正末步选择；平局保留更早来源。选择规则、权重和200000--200255新初态在执行前固定。本项包含原BC、阶段、专家、组合四组，全部来源都保留。

该独立确认已全部完成，结果如下：

| 方法 | 同批新初态平均成功率 | 三来源分别 |
|---|---:|---|
| 原BC | 45.18% | 44.14% / 45.31% / 46.09% |
| 阶段BC+PPO | 41.41% | 41.02% / 42.58% / 40.62% |
| 专家末步 | 40.89% | 41.02% / 52.34% / 29.30% |
| 历史组合 | 57.42% | 58.98% / 64.06% / 49.22% |

组合比同批BC平均高12.24个百分点，配对描述性95%区间[2.73,20.44]，三个来源均有净增，但第三来源只多8/256例。它支持“保留不同阶段强项”作为实用改进，不证明所有训练来源都能获得同样收益，也不证明普通单网络长训已修好。[完整规则、数据与限制](历史组合多来源验证_2026-10-21.md)。

典型例子：第4类三份BC都0/33，组合利用PPO能力达到33/33、20/33、29/33；第0类则保留BC的63/63。第三来源仍新增35、丢失27例，旧开发集的一例优势不足以可靠选择，不能说遗忘已完全消失。

第4节与本节是不同测试批次。必须比较本批45.18%与57.42%，不能拿上一批38.02%当本批基线夸大提升。

## 6. 残差与反馈BC现在怎样

不能由专家或组合的成绩推出残差成功。已有参考残差的多来源确认未稳定超过参考；冻结学习基础再加残差，长训或换种子后也未保持净收益。新反馈BC接完整动作PPO17→13/64、接残差18→15/64，仍是负结果。[学习基础加残差记录](学习基础策略加残差_2026-10-19.md)、[反馈BC记录](反馈BC分专家_2026-10-21.md)。

BC并非天生不能纠错。当前可靠的研究方向包括DAgger式学生状态查询、DART式恢复示范及闭环稳定性约束，但老师找到一条能救的轨迹不代表学生学会。已经做过的补数据、重采样、冻结参数等负结果必须保留，不把这些建议重复包装成已解决。[论文、具体假说与实验](论文启发的反馈BC与残差改进_2026-10-19.md)。

## 7. 质量与报告要求

成功率之外还要看失去哪些旧成功、穿透、峰值力、保持时长和新增成功的接触形态。E105末步在开发初态130027出现14.764mm穿透、224.094N力峰值，已原批次重现并独立核验；不能称它安全部署可用。[失败曲线与逐周期数据](../../../artifacts/orca_benchmark_suite/S09/bc_repair/ppo_improvement_20261018/D55_E105_failure_replay/report/results.md)。

所有结果首先是该固定仿真任务的证据，不等于实机鲁棒性。主成功判据只约束释放后的最大穿透，另列全回合3mm条件；只有三个来源，统计区间不能替代更多独立重复。原始数据、计划哈希和审计都保留，没有把权重打包混入说明材料。

最新组合主成功441/768；若额外要求全回合穿透不超过3mm，为439/768（57.16%）。成功案例仍存在44.30N峰值，不能据“成功”直接上硬件。开发和确认中的全部失败均保留。

## 8. 本轮完成范围

已完成两条补充长训、三个来源的末步确认、三个来源的历史组合确认、一个高风险失败重放，以及222项回归与保存预览审计。实用提升来自用户允许的独立组合策略，主实验的普通BC+PPO和残差负结果没有被覆盖。

尚未证明或未实现的能力包括：普通单网络稳定不退化、反馈BC普遍救回滑落、残差跨来源稳定超过基础、任意空间位置抓取、实机安全和新的原始视频提取。它们不能由本轮正结果推导。有关奖励迭代的正负对照见[奖励预案及完成结果](奖励迭代预案.md)，不是把本轮固定R0说成大模型在训练中不断改奖励。
