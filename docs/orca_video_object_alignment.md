# 视频、物体与 Orca 动作的对应检查

更新：2026-10-05。本文对应已完成初步比较和残差复验的同源物体实验，不替换旧实验成绩。

较短的现状、八组结果和视频入口：[同源物体当前结果](orca_hic53_matched_results.md)。

## 已纠正的物体不一致

当前使用 HIC 第 20 段视频，原视频在
`artifacts/cube20/hic20/videos/20/input_rgb.mp4`，186 帧、30 FPS。
画面中是有倒角的魔方，不是此前训练的任意小方块。
同序列提供的 `models_motion/20/Model_Object_Cube.OFF` 三轴尺寸均为 53 mm。

旧实验用 36 mm 方块，并把参考按 36/53 缩放。因此旧成绩只能描述旧的缩放迁移任务，
不能当作“严格按视频物体”的效果。新的同源任务禁止该缩放，也不复用旧 BC 数据集。

| 项目 | 新实验的处理 | 仍需注意 |
| --- | --- | --- |
| 物体身份与形状 | HIC20 同序列原始 OFF 网格 | 魔方作为整体刚体，不模拟各层转动 |
| 尺寸 | 53 mm，示范空间比例为 1 | 不为提高成功率悄悄缩小 |
| 外观 | 保留原始形状用于显示 | 数据未提供贴纸纹理，统一着色不是彩色复原 |
| 接触几何 | 原网格拟合为 36 顶点、68 三角面凸代理 | 双向采样及顶点最大误差约 0.911 mm，不是完整数学误差上界 |
| 物体坐标 | 从同序列物体姿态恢复手指的物体局部坐标 | 骨架原点不直接当作物体中心 |
| 手型 | 在 Orca 关节约束内拟合主要夹持指 | 不同于人手，不能复制人手关节角就声称准确 |
| 质量与摩擦 | 显式沿用 35 g、已记录摩擦参数 | 未由视频测量，仍须敏感性验证及实物标定 |

原始高顶点碰撞网格曾在没有手的 MJX 静置测试中掉穿支撑，因此不能认为“原 STL/OFF
直接拿来做碰撞”必然更准确。新代理需同时满足形状误差和物理稳定门槛。

以后换物体时也遵循这个规则：先选包含该物体的示范序列，绑定同序列的视频、跟踪数据、
物体网格、单位与帧索引，再进行重定向和训练。魔方示范不能直接标成瓶盖示范；
若做固定瓶身拧盖，需要真正的拧盖数据与螺纹任务，不能只把当前方块外观换成瓶盖。
同一物体增加摆位扰动则可作为泛化测试，但必须标明偏离原始示范的范围。

## 手势如何与物体对上

1. 使用该视频公开的跟踪拟合及 DexMV 重定向产物，不声称本轮重新运行了 RGB 姿态估计。
2. 将每帧手指位置转到同一帧物体坐标系，保存相对物体的抓握位置。
3. 选取视频第 30-95 帧的接近/夹持阶段，源时长约 2.17 秒，重放为 1.5 秒。
4. 对物体和全部目标使用同一个刚体变换。刚体变换只改变位置和朝向，不改变尺寸。
5. 用逆运动学求 Orca 可执行关节角。逆运动学即从“指尖应该到哪里”反求关节角度。
6. 当前主要匹配拇指和食指；视频中未参与夹持的其他指保持张开，不强行折叠第三指。
7. 每步残差控制为 `视频基础关节角 + PPO 小修正`，之后经过关节范围与速度限制。

O15 参考的末帧拇指/食指目标误差约 1.79/0.86 mm，不能把该末帧误差当作整段误差，
也不能把它当作夹持力或接触稳定性的证明。两根不同手型的指尖位置接近，不代表整个手型相同。

### 整条重定向链的误差

D11 把实际使用的第 30-95 帧放回同一物体坐标系，对三段分别测量：

| 段落 | 拇指平均 / 末帧 | 食指平均 / 末帧 |
| --- | --- | --- |
| 人手跟踪点 -> Adroit | 4.08 / 2.19 mm | 11.47 / 7.04 mm |
| Adroit -> Orca | 4.05 / 1.79 mm | 7.79 / 0.86 mm |
| 人手跟踪点 -> Orca 总偏差 | 7.10 / 1.88 mm | 11.48 / 7.15 mm |

因此此前末帧约 1 mm **不能代表从视频开始的总精度**。误差是三维向量的偏差，
不能把前两行距离直接相加。中指当前未拟合，完整报告单列，不混入夹持指平均数掩盖问题。
上述是关节/指尖代理中心的运动学误差，不是表面接触误差，也未包含原视频跟踪本身的误差。
证据在 `artifacts/orca_collision_refit/D11_hic53_retarget_chain/`。
接下来单列“直接使用人手跟踪点”候选以检查中间手型是否引入可避免偏差；它不替换旧参考，
也不能仅凭距离更小就宣布抓取更稳。

O28 / D12 的直接跟踪点对照已经完成原生检查：食指整段平均总偏差降为 3.88 mm，
末帧 1.34 mm，但三个初态分别仅保持 8.50、6.90、10.50 秒，最终都掉落。
所以不能把姿态拟合更准直接等同于抓握更好；该候选尚未替换已验证基线。

## 对齐不等于完整复现

当前机器人腕部固定，任务是同物体的夹持与无支撑保持，未复现视频中的整个搬运路径。
原安装下接触点相对重力的位置也与视频不同；整体翻转安装已做独立验证，保持反而更差，
所以不能为了画面相似而宣布物理对齐已经解决。后续要区分接触迁移、安装姿态和全轨迹复现。

同样，质量、表面材料、手指软垫、相机标定误差不是凭视频外观即可完全确定。
目前策略读的是状态而不是渲染 RGB，补贴纸颜色不会修正抓握物理；若以后训练图像策略，
纹理、光照和相机才会同时成为观测匹配的重要因素。

## 术语速查

| 术语 | 通俗解释 |
| --- | --- |
| STL/OFF 网格 | 用许多三角形描述外形的模型文件，画出来像不等于碰撞一定正确 |
| 碰撞代理 / 碰撞箱 | 仿真真正用来算接触的形状；可以是盒子、胶囊体或凸块，不必只有一个箱子 |
| 重定向 | 把人手或另一种机械手的动作，转换为当前机械手能做到的关节动作 |
| 物体局部坐标 | 把物体当作坐标原点描述手指位置，使移动手和物体时仍能检查指头落在哪个面 |
| BC / 行为克隆 | 用示范的动作作答案训练网络；本身不进行 PPO 的探索更新 |
| PPO | 根据与仿真交互得到的奖励更新策略网络的强化学习算法 |
| 基础动作 / 先验 | 从视频重定向得到的参考关节角；当前按时间播放，末帧之后保持，不是实时视觉网络 |
| 残差 | 加在基础动作上的小修正；八组初步比较上界 +/-0.08 弧度，后续 R14/R15 为经验证的 +/-0.15 弧度（约 +/-8.6 度），不同版本不能混用 |
| actor / 执行网络 | 运行时输出完整动作或修正量的网络 |
| critic / 价值网络 | 训练时帮助估计动作长期收益的网络，部署时通常不需要它 |
| 法向力 | 垂直接触表面的挤压力；当前触觉由仿真约束力得到，不是从视频直接测量 |
| 原生 MuJoCo / MJX | 两种物理执行路径；现在原生 CPU 物理也可通过回调配合 GPU/JAX 上的 Brax PPO 训练，结果须分别报告 |
| 摩擦锥 | 接触力允许范围的数学表示，不是把物体改成锥形；改变表示会影响数值滑移 |
| 阻抗比 impratio | 摩擦约束相对法向约束的阻抗设置，不等同于物体摩擦系数，也不是视频测出的量 |
| 确定性回放 | 在核验过的同一运行配置中，相同输入重复执行得到相同结果，便于做配对实验 |
| gate / 验证门槛 | 先通过来源、几何、物理和接口检查，才允许该模型进入训练；通过不等于抓取成功 |
