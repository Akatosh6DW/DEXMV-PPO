## 问题定义

固定腕座安装位置的Orca右手、17个关节目标控制通道，抓取53 mm方块。
其中动作0是腕部转动关节，其余16个用于手指；“固定手腕”不应误解成该腕关节也锁死。
方块默认35 g；托板先承托方块，2 s开始下移、3 s撤离，回合总长40 s。
初态不是已经抓住，也不是所有手指完全张开：食指、拇指部分关节打开，保留根部朝向。
这是一项“建立抓握并在撤托后保持”的任务，不含机械臂接近、自由腕座搬运或开瓶盖。

每50 ms发一次目标角，每5 ms积分一次物理，即每次控制10个物理子步。
控制量是位置执行器的目标角，不是直接命令力矩，更不是视频像素。
不同物体和真机部署需要重新检查状态估计、执行器与接触模型。

## 视频信息如何进入策略

1. 使用HIC20公开视频对应的跟踪结果，选择30..95帧；本轮没有重新运行RGB姿态识别器。
2. DexMV相关适配与跨手型IK重定向，把人手关键点变成Orca可执行关节轨迹。
3. E01在仿真中搜索有限偏置（不超过0.12 rad）并检查接触，得到校正参考。
4. 将参考安排为约1.5 s的合拢过程，之后保持参考末姿态。
5. 残差策略执行时始终把参考和自己的修正相加，不是在起手后丢弃参考。

`目标角 = clip(参考角 + 0.08 * PPO动作, 关节下限, 关节上限)`。
PPO动作范围[-1,1]；请求修正上限0.08 rad，约4.58度。
再经过所有方法共用的每控制周期0.1 rad目标变化限制。

这叫残差控制：参考负责主要动作，PPO依据当时的状态补小改动。
基础参考是时间轨迹，不是会根据新图像自适应的视觉策略，也不是已训练的DexMV/TRPO网络。
本轮没有把DAPG或TRPO作为中间策略训练阶段。

## 方法、训练和准备成本

| 方法标识 | 运行时动作 | 训练 |
|---|---|---|
| ppo | 网络直接给全部目标角 | 从初始网络做PPO |
| guided | 网络直接给全部目标角 | BC后继续PPO |
| bc | 网络直接给全部目标角 | 只BC，与guided用同一份BC权重 |
| residual | 校正视频参考+小修正 | 只训练修正网络 |
| linear | 起手到同一末姿态的1.5 s直线插值+小修正 | 移除视频中间动作后重新训练 |
| unrefined | 未经E01校正的参考+小修正 | 移除仿真校正后重新训练 |
| zero_video/linear/unrefined | 对应参考，没有修正 | 无强化学习 |
| half_residual | 完整残差策略的修正乘0.5 | 不重新训练，执行时干预 |

PPO各组163840个在线控制步，10个独立训练种子1001..1010。
网络actor和critic各两层128单元；actor输入123维，critic输入140维，动作17维。
所有组同一物理任务、奖励和控制周期，但残差组得到额外参考信息并限制动作范围，
这正是被研究的先验，不应声称各方法获得完全相同信息。

PPO公共参数：128并行环境，batch_size=128，4个minibatch，unroll_length=20，
每批4次更新，discounting=0.99，entropy_cost=0.001，reward_scaling=1，
不做观测归一化，训练使用完整reset，5次开发集评估。
学习率：ppo/residual/linear/unrefined为3e-4，guided为3e-5。
初始探索标准差：ppo为0.7，其他训练方法为0.3。
这是沿用M01的固定配方，不是本轮在最终测试集搜索超参数后的成绩。

当前安装的Brax 0.14.1中，未覆盖的实际默认值还包括：PPO clipping_epsilon=0.3、
gae_lambda=0.95、vf_loss_coefficient=0.5、normalize_advantage=True、max_grad_norm=None、
bootstrap_on_timeout=False；不是凭常见教程假设clip=0.2。
网络默认激活为SiLU，动作分布为tanh_normal。程序使用自定义确定性评估回调，
不能把Brax训练函数的deterministic_eval默认值误当成本轮正式评估方式。

BC使用同一视频的64次扰动回放中筛选出的40条成功示范，30条训练、10条验证。
每条800步，因此完整有效数据对应32000个状态-动作样本；不同回放不是不同源视频。
4000次Adam更新，学习率1e-3，每批128个早期样本+128个后期样本。
早期指前30个控制步，即合拢阶段；后期为其余保持阶段。
损失是网络动作分布均值和示范动作经arctanh变换后的均方误差。
BC-only权重直接取guided的BC初始化，避免另训一份造成不可配对。

准备成本必须单列：参考校正24次探测、14820个实际控制步；示范采集64x800=51200步；
另有参考验证及几何筛选，以及BC更新计算。不能仅用在线163840步声称总成本完全相等。
模型检查点、BC损失和运行时间见各训练目录；总开发调参成本不只这些固定准备步骤。

## 奖励、观测和成功

本轮有效奖励为：`(15*有效保持 - 50*失败 + 前3秒的获取奖励)*0.05`。
获取奖励为 `3*接近程度 + 2*拇指接触 + 2*拇指与其他手指配对接触`。
奖励不直接惩罚偏离视频；残差的先验通过动作结构实现，而不是靠“姿态相似分”冒充任务成功。

注意：`env_config.json`保留了基类的旧 `reward_config.scales`。
实际运行的覆盖逻辑在 `orca_refit_env.py` 的BASE_WEIGHTS以及 `orca_acquisition_env.py`，
分析本轮奖励时应以上面的有效公式和源代码为准，不能把未使用的继承权重相加。

actor获得关节状态、控制历史、物体相对位置/姿态/速度、指尖关系、阶段和模拟触觉等。
触觉有一控制周期延迟、噪声和滤波；累计有效保持计数通道被置零以避免特权信息泄露。
物体状态直接来自仿真，不是实时RGB视觉估计；critic另有训练用特权状态。
纯PPO对应参考通道为零，残差组包含下一步参考和相同的阶段信息。

原始成功必须同时满足：撤托后无支撑；有拇指和另一指接触；无掌部、托板、地面等禁接触；
物体中心下降不超过10 mm；连续有效保持至少30 s；40 s末仍有效。
下落55 mm终止。曾握住30 s但随后掉落，不算主成功。

清洁成功在此基础上还要求：撤托后全部活跃物理子步无禁接触、手物穿透不超过3 mm。
采用MuJoCo每个5 ms子步的求解接触记录，不是仅检查视频帧。
3 mm是当前仿真验收标准，不是硬件安全阈值；手部自碰撞未启用，应作为局限公开。

## 测试集与表格

开发集32000..32007用于5个固定检查点的记录，不按开发最好点导出最终测试模型。
最终测试40000..40199，共200个相同初态种子，各方法在同条件下逐一配对。
B0为XY各±2 mm；B1为±6 mm；B2为绕世界Z轴±10度；B3滑动摩擦乘0.6；
B4质量及惯量乘2；B5在10.0..10.2 s施加0.15 N横向力，方向由种子固定。
B3缩放所有contype非零碰撞几何体的滑动摩擦分量，包括手、方块及支撑，扭转/滚动分量不变；
不是只替换方块材料，也不保证该条件对所有方法都更难。
只在B0训练，其余条件不重训。不把六个条件随意混成一个“总成功率”。

| 文件 | 一行代表什么 | 用途 |
|---|---|---|
| episodes.csv | 一个方法、训练种子、条件、测试初态的回合 | 原始统计和失败分析 |
| per_seed.csv | 一个模型在200初态上的结果 | 比较训练稳定性 |
| aggregate.csv | 一个方法在一个条件下的全部模型 | 成功率、置信区间、力和穿透 |
| paired.csv | 完整残差减一个预定对照 | 增益及其不确定性 |
| learning_curves.csv | 某训练种子的某开发检查点 | 学习速度与退化 |
| statistics.json | 全部汇总和统计方法/哈希 | 判断是否完成及复算 |
| contact_quality_supplement.csv | 一个方法在一个条件下的整段穿透补充验收 | 比较撤托前接触问题，不替换主指标 |
| feedback_diagnostic/cases.csv | 同一模型同一初态在B0/B5的一对保存轨迹 | 检查外力前匹配、外力后动作是否响应；仅前4个固定案例 |

零修正组在冻结作业及主CSV中沿用seed/train_seed=1001作为控制器作业编号，不表示训练过网络。
它们每个条件只有一个控制器、200个测试回合；视频清单的train_seed为null，明确没有训练种子。
两个补充表属于描述性诊断，不新增主要假设检验；尚未完成时会明确标记状态。

关键逐回合字段：

| 字段 | 单位/解释 |
|---|---|
| train_seed / seed | 训练随机种子 / 测试初态种子，不要混淆 |
| success30 / clean_success30 | 原始 / 子步审计清洁成功，布尔值 |
| longest_hold_sec | 最长连续有效保持秒数，不是累计多段时间 |
| acquisition_sec | 首次有效抓握时刻，未获得为null |
| final_valid | 回合末是否仍有效 |
| max_penetration_m | 所有活跃子步的最大手物穿透，米 |
| post_release_penetration_m | 撤托后最大穿透，清洁判据实际使用此值 |
| substep_forbidden | 撤托后是否出现禁接触 |
| finger_peak_n | 20 Hz记录的逐指法向合力峰值，牛顿 |
| substep_force_peak_n | 全部活跃物理子步的逐指法向合力峰值，牛顿 |
| residual_rms_rad | 活跃控制步请求修正的均方根，弧度 |
| valid_before_push | 10.0 s时、施力前是否有效抓握 |
| valid_one_second_after_push | 11.2 s时、施力结束1 s后是否有效 |

最后两个字段只有B5按抗扰动指标解读。条件恢复比例的分母应是施力前已有效抓握的回合；
它不能替代全部回合的无条件主成功率，也不等于详细的恢复耗时分布。
峰值力均值包含失败回合，不能仅因某方法早掉落、接触时间短而说它更安全。
首次有效抓握时刻的判据包含撤托，因此不用于推断撤托前谁更早闭合手指。
所有方法共享同一参考元数据定义的任务起手和物体摆放；纯PPO没有示范训练或参考动作通道，
但整个任务的开发和初态设计并非与视频完全无关。这限制了对一般从零抓取任务的外推。

## 统计解读

每组10个独立训练策略；每个策略200次测试，不能当2000个独立训练结果。
零修正只有一个确定控制器，不复制成10个“训练种子”。
差值使用共同初态配对，bootstrap分别重采样训练种子和测试初态两个交叉维度。
95%区间是逐项区间，不自动保证几十项比较同时正确。
精确符号翻转检验以训练种子差值为单位，依赖零假设下差值对称，并条件于固定测试集。
B0五项主比较用Holm校正；另保留全部30项的全局校正，见统计协议。
10种子时全局Holm-30无法达到0.05，不得把扩展测试的描述性收益写成全局显著优势。

只有3个旧训练种子、或者只有一个演示视频成功，都不能替代本轮重复验证。
若某消融没有下降，应写“该部分在当前任务下未体现必要性”，不能换一个有利指标后隐藏主结果。

## 术语

- benchmark：固定任务、初态、预算和评分方式组成的比较标准，不只是一个漂亮视频。
- BC：行为克隆，用示范状态和动作训练网络“照着做”。
- PPO：通过环境试错和奖励更新策略的强化学习算法。
- 残差：在基础参考动作上相加的小修正；与“BC后接PPO”不同。
- 重定向：把人手或其他手型的动作转换成目标机械手可执行动作。
- IK：逆运动学，从指尖等目标位置求关节角。
- 消融：去掉或替换一个组成部分，检查它是否贡献了效果。
- 训练种子：控制随机初始化、采样等，换种子相当于独立重新训练。
- 留出测试：不参与训练、调参和选模型的测试样本。
- 置信区间：对效应不确定性的量化，宽区间意味着证据不足。
- 清洁成功：除了完成动作，还通过本轮定义的接触/穿透验收；不代表真机安全认证。
- actor：根据当前观测输出动作的网络；本轮残差组的actor输出小修正。
- critic：训练时估计长期收益的网络，部署时不直接发动作。
- bootstrap：对已有训练种子和初态进行重复抽样，近似估计统计不确定性，不是重新训练新策略。
- p值：在检验的零假设及相关假设成立时，出现当前或更极端差异的概率，不是“方法有效的概率”。
- Holm校正：同时做多项比较时收紧判断标准，降低碰巧挑中显著差异的风险。
- 百分点：例如72%减65%是7个百分点，和相对提高7%不是一回事。

## 能与不能主张的范围

本轮能检验固定方块任务下的样本效率、参考/校正/残差贡献和零再训练鲁棒性。
它不能单独证明跨视频、跨手型、新物体或真机的普遍优势，也不是实时视觉闭环。
视频参考的末姿态本身包含信息；线性轨迹消融不等于对比了充分优化的人工先验。
后续若要主张泛化，需要独立视频与物体的训练/测试分离，以及真实状态估计和硬件验证。
