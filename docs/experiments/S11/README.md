# S11：固定瓶身单手拧盖可行性验证

## 任务选择

选择拧盖作为圆柱抓持后的下一步。圆柱只要求保持接触；拧盖还需要传递扭矩、完成螺纹脱扣、移开瓶盖，并在物体失去机构支撑后继续夹持。

本轮先做小规模验证，验证成功再投入训练。软物体暂不作为这一轮任务：它需要可变形物体、材料参数和形变指标，不能只把刚体的摩擦系数或质量调小。当前本地MuJoCo为3.5.0；其可变形物体建模入口见[官方文档](https://mujoco.readthedocs.io/en/stable/modeling.html#deformable-objects)。

本轮优先测试已有瓶盖模型，不同时重建门和软物体环境。

## 旧实验给出的线索

旧CAP分支使用同源OakInk瓶盖/瓶身，约490.13度转动后脱扣，要求沿瓶轴移开18毫米并末端连续持盖1秒。记录中出现过脱扣但继续靠瓶身支撑、脱扣后掉落，以及手部穿透/高力。

固定底座下，后段重定向的拇指与食指目标平均误差约58和111毫米。这提示需要独立的腕臂移盖能力，而不是只提高旋转奖励。原记录和旧权重不覆盖，来源见[旧开发记录](../../orca_formal_cap_development.md)。

## 本轮验证步骤

1. 保留瓶盖几何、被动螺旋约束、17个手部执行器和原重定向参考；给整手增加独立动态自由基座。
2. 先从原视频接触附近的共同初态测试固定手与整手旋拧。仅通过手与盖的物理接触驱动瓶盖，不对瓶盖施加外力或设置电机。
3. 脱扣后沿轴移开50毫米，检查是否实际带起瓶盖并夹住。完整成功仍要求实际瓶盖位移至少18毫米、拇指与另一指承力、无瓶身/地面支撑和末端连续持盖1秒。
4. 小规模门槛：初始手部穿透不超过1毫米，全程不超过3毫米，单接触法向力峰值不超过30 N；这是本轮仿真筛选标准。超过100 N时提前终止探测。
5. 初步机构测试允许整手连续旋转，作为运动能力上界；若通过，进一步检验有限腕转动与换指/重新抓取，再决定是否开展正式PPO对比。不能把无限腕旋转的上界直接当作真实机械臂完成任务。

与S10一样，基座是理想笛卡尔执行平台。S11额外的实现要求是：螺纹释放只能关闭5条螺纹约束，不能关闭控制手基座的独立约束。

## 开发记录

### P01：只增加整手运动能力

最初接口测试发现mocap索引与目标位姿函数同名，物理运行前失败；已改为`target_id`，4项测试通过，重试单独保存。

同一初态240000，保持视频起手关节目标：固定手最大转动2.39度，无承力接触；移动手最大117.46度，但尚未脱扣。两者完整成功和保持时长均为0；移动手峰值接触力0.49 N、最大手部穿透0.205毫米。

这次改变带来转动，但起手夹持不足。下一轮只改抓握阶段：让手指执行示范前1秒或2秒后保持，其余模型、运动时间与判据保持不变；固定与移动仍配对比较。

命令与结果：

```bash
conda activate aero_rl
python -m unittest discover -s scripts -p 'test_s11*.py'
python scripts/probe_s11_cap.py --name P01_root_motion_retry1 --count 1 --grip-times 0
```

原始记录在`artifacts/orca_benchmark_suite/S11/`，源码是`scripts/s11_cap.py`与`scripts/probe_s11_cap.py`。

### P02：推进示范阶段没有形成夹持

`python scripts/probe_s11_cap.py --name P02_grip_phase --count 2 --grip-times 1 2`

固定/移动各测试两个关节阶段和两个初态，共8次。固定手都没有承力接触；移动手保持第1秒姿态时最多转78.14度，保持第2秒姿态时只有2.39度，均未脱扣。下一步选择接触几何修正，不调整奖励或PPO学习率。

检查原固定模型和新增自由基座模型：同一关节状态下所有原有刚体的位置差为0。原起手的拇指、食指目标指腹到盖碰撞体的最近距离分别约1.22和5.22毫米，说明示范姿态并没有真正夹紧盖子。

### P03：接触感知起手校正

`python scripts/fit_s11_grip.py --name P03_contact_fit --count 2`

使用SciPy有界非线性最小二乘，调整17个关节目标，使拇指和食指指腹靠近瓶盖表面；同时限制手与瓶身/盖的穿透，并对偏离原示范的关节角加小惩罚。目标是补足原参考的接触间隙，不改变瓶盖质量、摩擦和螺纹脱扣规则。

固定手2次均未脱扣；移动手2次均到达约490.76度并脱扣，但最终轴向位移只有8.60毫米，没有合格持盖。移动案例峰值单接触力约1.00 N，最大穿透0.61毫米。下一个变量是整体起手位置。

### P04：允许起手平移

`python scripts/fit_s11_grip.py --name P04_grip_root_translation --count 2 --fit-root`

在P03拟合中增加三个平移变量，各限制在正负15毫米；最优平移约为(-2.95,-0.36,-2.07)毫米。固定手仍未脱扣，移动手2次均脱扣，但最终轴向位移仍只有8.61毫米，合格持盖为0。单纯挪动起手没有解决移盖。下一步只改夹持预紧。

### P05：物理预紧后再转动

`python scripts/fit_s11_grip.py --name P05_contact_preload --count 2 --preload-gain 1`

沿P03关节校正方向再增加一倍控制目标偏移，在前2秒逐渐合拢；手指仍由执行器驱动，不直接写入运行中的关节位置。其余条件与P03一致。

两个移动案例都脱扣，峰值单接触力约5.08 N，全程最大穿透约1.12毫米。以240000为例：

| 时刻 | 物理现象 |
|---|---|
| 1秒 | 拇指与食指都承力，建立夹持 |
| 10秒 | 盖转约314度，保持对向接触 |
| 14秒 | 盖约491度，螺纹约束已释放，但盖与瓶身仍有接触 |
| 15秒 | 手向外移，盖只移出约5.8毫米；仍有瓶身接触 |
| 16秒 | 已失去手指承力接触，盖没有随手继续移出 |
| 24秒 | 盖轴向位移约8.7毫米，仍接触瓶身，完整任务失败 |

固定手也能维持预紧，但不转动便不能开盖。预紧解决了旋拧阶段的弱接触，没有解决脱扣后的移盖。

## 本轮结论与决定

完成了22次开发物理回放，涵盖上述五轮的固定/移动对照；使用的是两个起手关节微扰种子，不是22个独立训练种子。P03至P05的6次移动回放均发生脱扣，但所有回放的完整取盖成功和合格持盖时长均为0。这些是诊断测试，不是正式策略成功率评估，没有训练PPO，也不存在本轮成功策略权重。

目前能做的是靠手盖接触转动并触发脱扣；**尚不能完成取下盖并稳定拿住的整项任务**。按本次任务要求，暂不启动开盖的全套BC/PPO/残差对比。

失败范围已经收窄到“脱扣后取盖”：实测先出现盖与瓶身接触，再发生指间滑脱。下一次值得验证的是盖口/瓶颈碰撞几何是否阻碍直线抽出，以及有限腕转动条件下能否换指重新夹持。两者需要分开验证；现在不能仅凭这组记录断言是摩擦不足或模型碰撞错误。

软物体抓取本轮没有建立材料与形变环境。现有成果仍是刚体抓取；降低质量或摩擦不等于软物体仿真。

五项接口测试覆盖自由基座、被动瓶盖、螺纹释放与基座约束隔离、不瞬移、带位移的重置。演示视频使用P05实际保存状态，显示碰撞手与瓶盖/瓶身外观，已经检查关键帧和完整解码：

本轮没有训练日志中的`first/last/max/best_step`指标，因为没有更新网络；对应的物理检查量是旋转角、脱扣、轴向位移、接触和最终持盖时长。
