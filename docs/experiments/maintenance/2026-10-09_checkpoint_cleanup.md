保留规则：

- 首个、最后一个，以及训练进度约四分之一、二分之一、四分之三的版本。
- 每项评估奖励、诊断指标和回合长度的最高及最低点；没有恰好对应的存档时，保留前后相邻点。
- 在扫描到的代码、文档、配置中引用的检查点编号，采用偏保守的保留方式。
- Git 跟踪的文件、存在符号链接的版本、最近 24 小时有修改的版本。
- 缺少有效评估日志的运行，或只有不超过 5 个检查点的运行，全部保留。

**删除的是冗余中间版本，不意味着这 75 次训练都失败。** 尤其早期日志没有完整抓握时长指标时，不能把奖励值当成功率。极值保留规则也保留了有诊断意义的失败点。

## 2. 为什么完整归档接近 2 GB

归档位置：`deliverables/Orca_S02_S04_Experiments`。

**这不是三个最终权重的压缩包，而是 S02、S04 的实验材料集合。**
归档清单记录复制了 19,281 个文件，共 1,964,864,771 字节，即约 **1.96 GB / 1.83 GiB**。
本次 `du -sh` 显示实际磁盘占用约 **1.9G**。因此“1.7G”不是本次清单核算出的精确值；不同单位、查看时间或统计范围可能导致显示不同。
后加的说明文件不包含在最初复制字节数里。

按目录拆分，以下单位统一为 MiB（1 MiB = 1,048,576 字节）：

| 内容 | 大小 MiB | 保存它的原因 |
|---|---:|---|
| S02/eval | 729.49 | 各测试条件的逐回合评估、轨迹与统计 |
| S04_training_sources | 439.33 | S04 使用的训练来源，包括相关检查点和训练记录 |
| S02/train | 335.42 | S02 的训练权重、日志和相关记录 |
| artifacts | 78.89 | 引用的示范、参考轨迹及其他共享输入 |
| S02/videos | 60.25 | 回放和相关材料，不全是 MP4 |
| S04/eval | 59.61 | S04 逐回合评估与轨迹 |
| shared | 45.98 | 整理后的共享场景与模型资源 |
| deliverables | 45.85 | 依赖的小型交付包资源路径 |
| Aero-Hand | 45.47 | 按原工程路径保留的源码及模型资源 |
| S02/report | 14.23 | 报告与图表 |
| S04/videos | 10.11 | S04 回放及相关材料 |

其他目录占少量空间。共享模型资源存在部分重复，这是为保留不同入口原有的资源路径；不是每一份模型都代表一个不同的手型。

按文件类型看更直观：

| 类型 | 大小 MiB | 含义 |
|---|---:|---|
| .npz | 1,239.19 | 主要是保存的仿真轨迹，也包括参考和示范数组 |
| .pkl | 210.72 | 包含多个种子、多个阶段的权重等序列化文件，不只是三个最终权重 |
| .stl | 138.34 | 手部几何网格等模型资源 |
| .json | 84.54 | 配置、评估统计等 |
| .py | 81.87 | 源码及运行时保存的源码快照，有重复 |
| .png | 46.66 | 图表、图像 |
| .mp4 | 39.22 | 编码后的视频 |
| .csv | 15.02 | 表格和日志 |

归档没有通过特别的压缩步骤把一个大工程“压成 1.7G”。它只复制与这两个实验有关的材料，没有复制整个 Conda 环境、Git 历史或所有历史试验。
原路径别名使用归档内部的符号链接，不会再次复制整棵实验目录，也不依赖归档之外的对应原始目录。

归档审计记录包含 S02 的 77,600 条、S04 的 4,100 条回合记录，并记录了 434 项冻结依赖验证。
本次另行检查归档清单中的全部文件，未发现缺失或大小变化；本次没有重新对全部归档内容计算哈希。

“完整”的范围是 S02/S04 实验文件和它们用到的训练来源及依赖，**不是整个项目历史、完整 S03 矩阵、独立 Conda 环境或任意原始视频到策略的通用系统**。
详见[归档入口](../../../deliverables/Orca_S02_S04_Experiments/README.md)和[实验区别说明](../../../deliverables/Orca_S02_S04_Experiments/EXPERIMENTS_EXPLAINED.md)。

## 3. 抓球目前到了哪里

可以把抓球作为下一项训练任务，工程已经有球体场景和测试接口；但当前证据不能宣称已实现稳定抓球。

- [较早的三路线实验](../../orca_residual_three_way_comparison.md)使用半径 21 mm、质量 35 g 的球体，复用方块视频先验再分别训练，球体三组成功率均为 0%。
- [S03 执行记录](../S03/execution.md)记录了另一版球体零修正参考的 2 回合冒烟测试，均失败。该测试只检查运行与初步效果，不能代替完整球体训练实验。
- 上述版本和条件不同，不能合并成同一张球体 benchmark 表，更不能直接套用 S02/S04 方块成绩。

合理的下一步是先确定球径、质量与抓取判据，再检验球体对应的手物相对位置和包握参考；不能仅把方块几何换成球体而认为原有抓法自动适用。
之后用相同球体条件分别训练纯 PPO、BC 后 PPO 和参考加残差 PPO，评估保持时长、成功率、穿透、接触力及对初始位置扰动的鲁棒性。本次没有启动这项新训练。
