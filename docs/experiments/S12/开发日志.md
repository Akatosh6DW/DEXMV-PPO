## 重要更正：V1 网格作废，V2 重做

渲染核查发现初始表面异常，进一步检查共享面拓扑得到明确证据：12 分段/3 层的实体网格应有 72 个外边界三角面，实际生成了 104 个，其中 16 个编译后表面法向朝向内部。根因是共球/共面的规则点集经通用 Delaunay 后删除零体积单元，邻接单元的面剖分并不一致。总容积和回弹测试不足以检出这种裂缝。

因此下文 P01--P11、M01--M02、D01--D03、T01--T06 全部只作为 V1 开发诊断，**不纳入最终物理性能结论**。已主动停止仍运行的 P11、T04、T05；它们是因发现建模缺陷而中断，不算正常完成或训练退化。

V2 使用全局顶点顺序一致的棱柱阶梯剖分，每个三棱柱分成 3 个四面体。新增检查：内部面恰好被两个单元共享、边界面数正确、表面每条边恰好连接两个三角面、编译后所有表面法向向外。重新生成示范及训练，不复用 V1 权重充当 V2 结果。

下一轮类型：环境/几何。先运行 V2 材料压缩、回弹和抓取，以及同材料的网格/步长检查，再恢复 PPO。

## 批处理一致性

`s12_physics_worker.py` 只导入 NumPy/MuJoCo，不为每个工作进程加载 GPU 网络；进程之间仅通过父进程持有的管道交换完整双精度积分状态。无远程监听、无对象动力学近似。

新增接口测试共 3 项通过：交错初态的完整状态恢复、零残差等于参考、双进程与串行批次逐数组精确一致。材料/拓扑/审计测试另有 4 项通过。训练等价性仍需 T06 的实际更新结果。
