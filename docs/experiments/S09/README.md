目标是在手的可达区域内，面对虎口方向以及随机三维朝向的圆柱，从示范中学习不同抓法。初始由绳子悬吊，随后由手独立抓稳。

用户确认四组包含参考回放，因此正式比较为：

1. 纯PPO：从头学习完整动作。
2. BC后PPO：先用多朝向示范学习完整动作，再用同样在线预算训练。
3. 视频参考＋残差PPO：执行时每一步都是朝向相关参考动作加有界修正量。
4. 参考回放：按物体初始朝向选择参考，不使用PPO修正。

仅BC为中间诊断，不占正式组。对比不是给每个测试朝向单独训练一个模型；目标是每种学习方法的同一策略适应不同朝向。

## 物理与成功判据

- 沿用Orca右手、直径53 mm、高53 mm、质量35 g的圆柱及原碰撞几何，不改变摩擦制造成功。
- 手腕基座固定，保留原17维手部执行器，不凭空增加机械臂。任意朝向指姿态采样域，不承诺固定基座能抓到任意空间位置。
- 使用理想化平衡吊带：单根无质量弹性绳的合力通过圆柱质心，允许圆柱自由旋转。不是端部绑绳，也不是姿态锁定；真实端部悬吊会有额外重力转矩，本轮不混同。
- 绳长0.20 m，刚度100 N/m，阻尼1 N·s/m；仅拉伸时产生非负张力。初始按重量预拉伸，3秒时释放。每5 ms物理子步计算张力，50 ms一个动作。
- 没有托盘接触、物体位置伺服或物体与手的焊接。可视化绳索自身没有隐式弹簧力，力由可审计的显式模型施加。
- 释放后拇指及至少一根对向手指的掌侧末节/近节各承力超过0.02 N，允许掌部辅助，不允许仅靠掌部托住。指腹朝向使用原模型局部法向定义，不凭视觉颜色判断。
- 每个物理子步检查穿透和接触；初态穿透不超过1 mm，释放后不超过3 mm，禁止非手部支撑；高度下降小于15 mm。
- 主指标是40秒回合中连续严格合格30秒且最终仍合格；另报15秒、保持时长、按朝向分层成功率、穿透、峰值接触力和残差幅度。绳子尚承力时不计成功。

## 数据、分割与公平性

从已有DexMV处理后圆柱示范的物体相对手指轨迹重新生成朝向相关参考，不用S08手工几何参考冒充视频输入。已有源文件为`artifacts/orca_cylinder_s02/source/selection96/selected_segment.npz`，原始RGB对应关系仍需如实标注，不声称重新从RGB运行了手部估计器。

朝向随机增强不是新增真人视频。源手型与Orca不同，必须记录重定向、接触校正以及失败样本，报告参考覆盖率，不能删掉困难朝向后声称任意朝向有效。

开发、BC训练、BC验证、最终测试使用不同固定种子；测试朝向不得参与IK候选选择或奖励调参。正式协议、参考和示范哈希冻结后才开展四组比较，至少3个学习种子。参考回放不伪装成3次独立训练。

固定奖励比较完成后，另开训练奖励迭代阶段。每轮只改一个有依据的环境、奖励或PPO参数，使用开发验证集，记录first/last/max/best_step；最终另用未见测试集，不把调参结果混进原始四组表。
