# 冻结学习基础策略，再用PPO学习修正

## 为什么新增这个组

E83/E84说明，直接继续更新完整策略仍可能退化；锁住部分专家虽然保住对应行为，却没有带来整体净收益。本轮改动类型是PPO策略参数化：不再更新基础动作网络，新增独立残差网络。任务、随机朝向、初始位置扰动、物理和R0奖励均不变。

Alakuijala等的[Residual Reinforcement Learning from Demonstrations](https://arxiv.org/html/2106.08050v1)第三节将学习得到的基础策略固定，并将基础动作作为残差策略的输入。这提供了本轮的设计依据；原论文使用视觉特征等设置，本工程使用状态观测，不是其完整复现，也不承诺获得论文成绩。

## 与之前两种方法的区别

```text
完整动作BC后PPO：a = 一个可更新网络(s)
原视频参考残差：q = 校正视频参考(朝向,时间) + PPO修正(s)
本轮学习基础残差：q = 冻结学习策略(s) + PPO修正(s,基础动作)
```

本轮基础是已经经过BC和PPO训练的历史检查点组合，不是新的纯BC反馈网络，也不是重新从RGB提取的视频策略。它继承同一祖先路径1310720在线步及开发选择成本，已有六个完整动作专家，再新增一个残差actor。不能将基础已有成绩或训练预算算作新残差的功劳。

运行仍根据初始姿态选择专家，但基础动作每步使用当前状态。只有残差网络与critic接受优化；基础参数不在优化器参数树内，文件前后校验哈希。critic从组合保留的E78 critic初始化，此选择明确记录，不是假装所有网络都从零开始。

## 实现与关键边界

入口：`scripts/run_s09_learned_base_residual.py`。

- 物理环境保留123维原actor观测和140维critic观测。内部残差actor将17维基础动作拼接到原观测，实际网络输入140维，critic输入不变。
- 原观测中的动作历史仍是完整下发动作，不能改为残差，否则基础网络所见的状态语义会变。
- 残差限幅0.08rad，先在归一化坐标中相加再通过原映射得到关节目标，并保留原0.1rad/步限速。零修正的代数表达保持原基础归一化动作；不能通过正反归一化往返额外引入误差。
- 初始化残差均值严格0，标准差0.03。它对应的物理探索幅度不同于完整动作组，所以不能把比较写成只改变一个网络开关、噪声完全匹配。
- 保存轨迹字段明确命名`learned_base`，不是`video_base`；`requested_residual`是限幅内请求修正，`effective_residual`包含执行器限速影响，不一定在请求界限内。
- 审计绑定基础权重、残差权重、动作组合、完整动作历史与原生MuJoCo重放。原物理容差及成功门槛不放宽。

## E89预案：检验残差更新幅度是否过大

下一改动类型为PPO超参数。E86四段训练日志的KL为0.07071、0.05081、0.05817、0.06013，E88为0.10401、0.05081、0.05859、0.05255。它们描述优化过程的分布变化，不是相对零步的累计距离，也不是物理接触误差。请求修正角度小，不保证相对于std0.03的动作分布变化小。

PPO裁剪并不构成严格的策略距离约束，相关讨论见[Truly Proximal Policy Optimization](https://arxiv.org/abs/1903.07940)和[Implementation Matters](https://arxiv.org/abs/2005.12729)。这提供可检验假说，不证明本实验退化必由KL造成，也不把本轮叫作这些论文算法的复现。

### D40配套诊断预案：不凭预测偏差就断言梯度冲突

使用D34既有32个训练诊断回合及原零残差critic，计算有限回报均方误差对critic参数的梯度，按朝向与起手/释放后分组记录余弦和点积。若某组梯度与全数据梯度点积为负，沿全数据负梯度做无限小普通SGD会在一阶近似下增大该组拟合误差。此诊断0新增交互、0参数更新，不修改E96/E97。源脚本`diagnose_s09_critic_gradient_conflict.py`。

[Yu等，Gradient Surgery for Multi-Task Learning，NeurIPS 2020](https://proceedings.neurips.cc/paper_files/paper/2020/hash/3fe78a8acf5fda99de95303940a2420c-Abstract.html)研究多任务梯度干扰，并提出梯度投影方法。本轮只借鉴测量梯度关系，没有实施PCGrad。这里的MC标签不同于PPO截段/GAE标签，SGD方向也不同于带动量Adam，所以即便负余弦很多，也只能支持局部机制线索，不能当训练崩溃的因果证明。若方向一致，则降低“朝向冲突”的优先级。

## D41预案：核对PPO真正使用的价值目标

判断规则：若MC与GAE下冲突方向明显不同，不再用D40的MC冲突直接指导PPO网络拆分；若GAE下依然存在同朝向的阶段冲突，再将其作为下一项受控干预依据。此前增大gamma、lambda、片段长度均已试过，不能把同样改法当新方法重复。

论文依据：[Schulman等，High-Dimensional Continuous Control Using Generalized Advantage Estimation](https://arxiv.org/abs/1506.02438)通过价值函数与指数加权估计平衡策略梯度的偏差和方差。这里仅核验现有Brax实现的目标，不声称新算法或论文收益可直接迁移到本任务。
