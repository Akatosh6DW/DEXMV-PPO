# S05 独立验证约定

本约定写于T08/T10长训练过程中、正式52000系列初态评估之前。

## 选择模型

- 残差分支使用T08，BC+PPO使用T10。
- 只依据开发初态51000～51003的结果选择训练步。
- 先取严格30秒成功率最高者，再取平均合格保持最长者；并列时取较晚训练步。
- 两个训练分支都排除step=0，防止把参考回放或仅BC冒充在线PPO。
- 记录所选训练步与权重SHA256后，再运行独立评估。
- 仅BC对照取T10的step=0参数。它经过4000次BC更新，没有在线PPO更新。
- 参考对照直接播放同一个校正参考，不加入PPO修正。

## 评估范围

- 同一正常方块任务、相同物理模型、相同参考、同一子步接触判据。
- 每种方法32回合，初态种子52000～52031，物体XY各±2mm扰动。
- 完整40秒仿真；连续合格指腹保持至少30秒，末帧仍有效，无撤托后禁止接触，穿透不超过3mm。
- 全部回合统计，不按是否成功删样本。
- 同时记录最长保持、最终有效性、指腹接触比例、峰值力、最大穿透及残差幅度。
- 正式评估使用`--save-all-trajectories`保存全部32条详细轨迹。曲线默认展示前4条，视频选例不能代替全部32回合统计。首个成功案例可用于展示；如有失败，也保留并标明失败截点。

## 不能由它推出什么

- 只用一个训练种子5101，不是多训练种子论文级结论。
- 32个测试初态成功不等于真实世界100%可靠。
- 没有本次重新训练纯PPO；旧S02/S04的纯PPO不能作为新接触标准、新参考工作区、新求解配置下的公平对照。
- 两个PPO分支在线步数相同，但BC+PPO额外使用离线示范计算，参考构造也有离线搜索成本。
- 只测试正常条件，不声称已经验证大扰动、新物体、真实硬件、圆柱或整个人手运动的精确复现。
- 求解器和参考构造的收益不得计为PPO增益；参考本身成功时，应明确披露。

若根据这批测试结果继续调参，这批初态就必须改标为开发数据，另取新种子评估，不能再称它为独立测试。
