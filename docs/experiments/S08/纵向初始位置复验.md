# 纵向圆柱：只改初始位置的复验（P03）

## “校正参考回放”到底是什么

可以把参考理解成一张动作时间表：0秒手指张开，0.5秒弯到某个角度，1秒再弯一点，最后保持目标角度。回放就是照着这张表控制手指。

“校正”表示这张表事先在仿真中调整过，尽量避开穿透、够不到、接触方向不对等问题；不是执行时临时判断并修正。

- 参考回放：`目标关节角 = reference(t)`，不根据当前物体是否滑动改变参考。
- BC：用示范训练一个网络，由网络根据输入输出动作，不是简单读取这张时间表。
- 残差PPO：`目标关节角 = reference(t) + 有界PPO修正(当前状态)`，再受关节范围、变化速度等约束。

回放也有底层执行器跟踪目标角度的反馈，所以“没有PPO反馈”不等于“没有任何控制器”。它缺少的是根据抓取状态调整策略的高层决策。

**必须区分参考的来源：**S07的校正参考来自DexMV处理后的示范，重定向后再离线仿真校正；S08包覆探索是手工几何目标加逆运动学形成的参考。两者都能回放，但S08不能称为已经完成视频引导的新训练实验。

## 为什么改位置

P02纵向圆柱在手张开的初始状态就与拇指近端、中段碰撞体重叠。无随机扰动时最大重叠约4.85 mm，超过原判据的1 mm上限。只看后面拿稳多久，会把不合理的起手误报成成功。

本次保持P02手部初始角、整条闭合动作、圆柱朝向、质量、摩擦、碰撞模型、支撑撤离时序、成功判据不变。**只改变圆柱的初始XYZ位置**；初始托板随圆柱一起平移，保持接触高度，不额外托住物体。运行中没有物体位置伺服或焊接。

## 如何选择位置，而不是挑成功视频

1. 相对P02纵向初态扫描100个位置：X偏移0/4/8/12/16 mm，Y偏移-8/-4/0/4/8 mm，Z偏移0/4/8/12 mm。
2. 开发种子8301～8304：任一个初态手物穿透超过1 mm，该候选直接排除。
3. 其余候选各跑4个8秒短回合。按最差保持时间、平均保持时间排序，保留前5个。
4. 前5个候选各跑4个40秒开发回合。按成功数、最差保持时间、平均保持时间选定一个位置，写入参考哈希后冻结。
5. 独立验证使用83200～83231共32个新初态。旧位置和新位置在相同随机扰动下都跑一次，保留全部结果。

随机扰动是世界X、Y各均匀±2 mm，手部17个关节初始角叠加标准差0.002 rad的高斯噪声，随后裁剪至关节范围。不随机化圆柱Z、朝向、尺寸、质量、摩擦；不能由此声称任意位置都能抓。

最终选择：**X、Y不变，Z抬高12 mm**。圆柱中心由约`[77.713, 47.349, 225.000] mm`改为`[77.713, 47.349, 237.000] mm`。这是世界坐标，不是屏幕上的左右上下。

## 成功判据没有放宽

仍要求掌面、拇指和至少两根其它手指，在圆柱曲面有合格掌侧承力，各组超过0.02 N；撤托后不能依赖托板/地面，物体高度损失小于15 mm，手物穿透不超过3 mm，初态穿透不超过1 mm。连续合格至少30秒，40秒结束仍合格。

接触力、接触类型、穿透在每个5 ms物理步检查，50 ms控制区间使用最小承力及最大穿透；高度和连续保持计数在50 ms区间末检查。日志从`t=3.00 s`那一格开始累计，因此到40秒可显示37.05秒；这是沿用已有计数口径，物理时间跨度约37秒，不是延长了评估时间。

## 完整结果

| 指标 | P02旧位置，同批32个初态 | P03仅抬高12 mm |
|---|---:|---:|
| 严格成功数 | 0/32 | 26/32 |
| 严格成功率 | 0% | 81.25% |
| 初态手物最大穿透 | 5.828 mm | 0 mm |
| 撤托后最大穿透 | 2.033 mm | 1.876 mm |
| 平均最长合格保持 | 24.51 s，但初态不合格 | 29.90 s |
| 单接触全程峰值法向力 | 153.30 N | 59.65 N |

100个位置中63个通过4个开发初态的穿透筛选，37个被排除；共252个短开发回合、20个长开发回合、64个新初态验证回合。32个新位置回合另外全部确定性重放，保存数组逐项一致；64个旧/新位置回合从轨迹重新计算保持与成功判据，结果一致。每个验证物理步检查状态有限性及MuJoCo告警，未发现异常。

新位置成功回合保持32.55～37.05秒，40秒结束仍有效。32例的95% Wilson区间约64.69%～91.11%，说明81.25%仍有抽样不确定性，不是任意初态下的保证。

6个失败也保留：

| 初态种子 | 评估时长 | 主要失败表现 |
|---:|---:|---|
| 83203 | 40 s | 末尾无合格掌面承力，物体降低17.21 mm |
| 83210 | 40 s | 末尾无合格掌面承力，物体降低18.17 mm |
| 83215 | 7.05 s | 掉落，终止 |
| 83218 | 8.10 s | 掉落，终止 |
| 83223 | 40 s | 手指接触仍在，但无合格掌面承力 |
| 83226 | 40 s | 虽有包覆承力，物体降低24.06 mm，超过15 mm上限 |

“没有落地”不等于满足包覆任务。这里没有把这4条未掉落的失败算作成功，也没有删除失败初态。

关闭全部手部碰撞后，负对照在2.30秒掉落，未形成包覆；模型没有等式约束。59.65 N是全程单个接触的峰值，不是整只手合力，也不是实物可安全承受的认证。

## 能得出什么，不能得出什么

**能得出：**对于这条固定闭合动作，原先纵向“不合格”确实可以通过重新摆放物体显著改善。抬高12 mm消除了本批初态的手物穿透，并产生了多数回合真实承力、撤托后持续保持的包覆。

**不能得出：**PPO变强了、视频引导比纯PPO强、纵向比横向更好、换尺寸/摩擦/任意起始位置都有效。这里没有训练网络；旧位置本来就不合格，因此0%对81.25%是修复初态后的几何可行性对照，不能充当学习算法优劣的证据。横向6/8来自另一批初态，不能直接与26/32排名。

这里的任务是“物体先由托板放在手前，手闭合后托板撤离，手独立抓持”，不是机械臂从桌面搜索、接近、提起物体的完整搬运任务。“抬高12 mm”是改重置位置，并没有给手新增提起动作。

实际含义是：先把物体放在能从张开状态合理接近的位置，原动作就可以抓住很多次；之后才有条件比较“照着参考做”和“PPO根据滑动情况修正”哪种更稳。后续正式三方法比较必须给各方法相同的新初态分布，重新构造包覆示范和训练任务，不能只给残差方法使用更容易的位置。

本次位置可行性复验已完成，没有借题改奖励或继续新一轮PPO长训。若继续，最直接的下一项受控变量是扩大初态范围，量化剩余6个失败对应的接近与滑移问题，再决定是否引入闭环残差。
