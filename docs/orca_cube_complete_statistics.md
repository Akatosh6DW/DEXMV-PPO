## 怎么判成功

目标物体是同源 HIC20 的 53 mm 方块，不混入旧的 36 mm 缩放物体实验。
40 秒回合，3 秒撤掉支撑。主成功要求最长连续有效无支撑保持至少 30 秒，且末帧仍有效。
有效包含拇指与其他手指接触、无禁用接触、高度达标。中途保持够了但最终掉落仍算失败。
此外统计 15 秒且末帧有效、最长保持、末帧有效、建立抓持、接触力和穿透。

五个训练种子为 301-305，每个最终模型测试同一组 64 个未用于调参的初态 25000-25063。
先得到每个训练种子的成功率，再求均值、样本标准差和 bootstrap 95% 区间。
不能把一个模型的 64 回合当成 64 次独立训练。区间只反映固定测试集下的种子不确定性。
五种子区间仍粗糙；全为 0 或 100% 时区间退化，不代表总体概率已确定。

## 主比较结果

名义条件下，每行五模型合计测试 320 回合。下表成功率采用上述 30 秒且末帧有效标准。

| 方法 | 触觉 | 成功 / 320 | 成功率均值 +/- 种子标准差 | 95% 区间 |
| --- | --- | --- | --- | --- |
| BC | 关 | 0 | 0.00% +/- 0.00% | [0.00%, 0.00%] |
| BC | 开 | 0 | 0.00% +/- 0.00% | [0.00%, 0.00%] |
| 纯 PPO | 关 | 320 | 100.00% +/- 0.00% | [100.00%, 100.00%] |
| 纯 PPO | 开 | 319 | 99.69% +/- 0.70% | [99.06%, 100.00%] |
| BC 后 PPO | 关 | 167 | 52.19% +/- 46.74% | [15.31%, 89.06%] |
| BC 后 PPO | 开 | 59 | 18.44% +/- 41.23% | [0.00%, 55.31%] |
| 视频 + 残差 PPO | 关 | 300 | 93.75% +/- 5.41% | [89.38%, 97.81%] |
| 视频 + 残差 PPO | 开 | 303 | 94.69% +/- 3.92% | [91.25%, 97.50%] |

**当前统一配方下：纯 PPO 的名义成功率最高；残差方法可行，但没有超过纯 PPO。**
残差减去纯 PPO 的配对差为 -6.25 / -5.00 个百分点，分别对应关/开触觉。
95% 区间为 [-10.625, -2.1875] / [-7.8125, -2.50] 个百分点，精确双侧符号翻转 p 均为 0.0625。
不能写成 p<0.05 的显著结论；bootstrap 区间与小样本离散检验不是同一个判据。
102 项比较全部公开，但没有多重检验校正，不从次要条件中挑有利项宣称整体优越。

## 视频和 PPO 各自起了什么作用

| 参考 / 方法 | 无触觉成功率 | 有触觉成功率 |
| --- | --- | --- |
| 全视频时序 + 残差 | 93.75% | 94.69% |
| 从共同起手限速到视频末帧 + 残差 | 93.12% | 90.94% |
| 始终固定共同起手 + 残差 | 0.00% | 0.94% |
| BC 后 PPO，主配方 std=0.7 | 52.19% | 18.44% |
| BC 后 PPO，std=0.03 | 10.31% | 25.62% |

全视频相对末帧基底只提高 +0.625 / +3.75 个百分点，差值区间都跨零。
因此不能声称整段视频时序已经被证明不可替代；静态保持任务中，合适的抓握基底本身很重要。
视频、末帧、起手三个零修正控制最终成功均为 0/64。
视频/末帧曾平均保持 14.33/13.83 秒，但最终都不合格，说明当前基底还需要反馈修正。

残差开触觉减去关触觉为 +0.94 个百分点，95% 区间 [-3.13, 4.38]，p=0.75，尚无明确改善证据。
降低 BC 后 PPO 的探索 std 也不是统一改善；两个触觉条件的变化方向相反。
本次 BC 数据为同一源视频的 32 条物理回放，不是成功专家示范，不能用其失败否定 BC 或 DexMV 的一般能力。

## 鲁棒性、负载和学习效率

完整表包含所有八个主条件在 12 个测试场景的结果，不只比较赢家。
测试单次改变质量、摩擦、触觉噪声、横向推力、物体初始位置或朝向；不在测试条件下再次训练。
例如质量 1.5 倍时，纯 PPO 关/开触觉为 97.50%/97.81%，残差为 63.44%/73.75%。
因此不能只凭名义条件的高成功率声称残差具有更强鲁棒性。

位置/朝向扰动可能造成无效初始几何。xy5mm、xy10mm、yaw10deg、yaw20deg 每模型分别有
11、19、1、8 个无效初态，严格分母仍为 64，不删除或重采样。
initial_quality.csv 同时给出有效初态子集成绩，区分摆位不可行与可行初态下的控制失败。
摩擦倍率作用于所有启用物理接触的几何体，质量/惯量倍率只作用于目标物体。

名义残差关/开触觉的逐种子峰值单指力均值为 20.82/21.03 N，纯 PPO 为 43.86/49.67 N。
这个描述性峰值均值较低，不是实物安全证明，也不是整个回合的平均用力。
全部测试最大穿透为约 6.705 mm，来自 s301_guided_off__mass05，失败保留。
方块评分没有将执行中任意一次穿透 >5 mm 自动永久判失败，接触质量必须单独看。
20 Hz 记录不能排除物理子步中的短暂失触或更高力峰。

| 方法 | 无触觉开发 AUC | 有触觉开发 AUC | 开发峰值到末尾平均退化，关/开 |
| --- | --- | --- | --- |
| 纯 PPO | 0.490625 | 0.604688 | 0 / 0 个百分点 |
| BC 后 PPO | 0.668750 | 0.357813 | 45 / 60 个百分点 |
| 视频 + 残差 PPO | 0.178125 | 0.328906 | 0 / 5 个百分点 |

AUC 是开发成功曲线按交互步数归一化后的面积，不是独立测试成绩。当前结果不支持残差学得更快。
过线指标只要求两个连续记录点达到 75%，不保证之后一直成功；未达到标为 NA，不能记成 0 步。
60 次 PPO 训练各 655360 步，总计 39321600 步；20 次 BC 各 2000 次监督更新，另计计算成本。

## 看视频和理解残差

- [残差成功：有触觉、seed301/reset25000](../artifacts/orca_formal/F01_workflow_r2/palm_videos/s301_residual_on__reset25000/stl.mp4)，有效保持 37.05 秒。
- [同一模型失败：reset25041](../artifacts/orca_formal/F01_workflow_r2/palm_videos/s301_residual_on__reset25041/stl.mp4)，曾保持 33.75 秒但最终失败。
- [纯 PPO 成功对照](../artifacts/orca_formal/F01_workflow_r2/palm_videos/s301_ppo_on__reset25000/stl.mp4)。
- [基础动作、修正目标与实际关节角分解](../artifacts/orca_formal/F01/report/control_residual_on_seed301_reset25000.png)。

每步控制是 `限速(限位(视频目标 + 0.15 * clip(PPO输出, -1, 1)))`。
这是视频持续参与的残差架构；BC 后 PPO 则是最终网络独立输出完整动作，不是这个加法结构。
0.15 rad 约 8.6 度，限制的是目标修正，不保证物理关节实际跟踪误差也小于这个值。
执行需要网络权重、参考 NPZ、关节映射和控制逻辑共同保留。

本次使用已有视频手/物体跟踪数据，没有重新运行 RGB 姿态估计。
任务是近抓握初态下撤支撑后的保持，不是从远处接近、桌面拾取、空间搬运或真实硬件验证。
要研究更复杂动作，可继续在方块上做转姿态、换抓握、不同合法摆位等任务，不需要瓶盖实验。

## 术语和表格字段

| 字段 / 术语 | 说明 |
| --- | --- |
| bc | 行为克隆：监督拟合示范动作，不进行 PPO 更新 |
| guided | 先 BC 初始化，再用 PPO 更新同一策略网络 |
| residual | 视频基底每步保留，PPO 只输出有界修正 |
| off / on | 策略的触觉输入关/开，不是关闭物理碰撞；关触觉仍有状态输入 |
| endpoint / initial | 限速到视频末帧 / 固定共同起手的参考消融 |
| smallstd | BC 后 PPO 的低探索标准差对照 |
| nominal | 默认参数下的独立初态测试 |
| SD / 标准差 | 五次训练之间结果的分散程度，不是标准误 |
| CI / 区间 | 按训练种子重采样得到的不确定性范围，不是成功保证 |
| pp / 百分点 | 两个百分数直接相减，如 94%-90%=4 个百分点 |
| paired / 配对 | 对齐同一训练种子比较方法，避免把不相关的结果随意相减 |
| AUC | 学习曲线面积，这里按预算归一化 |
| acquisition | 曾建立有效无支撑抓持，不代表坚持到最后 |
| failure reason | 按固定优先级分类的失败表现，不自动等于唯一原因 |
