## 要检验的结论

1. 相同在线交互预算下，视频相关方法比从零训练 PPO 更容易建立并保持抓握。
2. 在已有校正参考上，执行时残差 PPO 还能提高成功率。
3. 视频中间动作与仿真校正分别贡献多少，不能把两者混为一谈。
4. 在位置、朝向、摩擦、质量和外力变化下，以上结论哪些成立、哪些失效。

这些是假设，不是预定结果。负结果、全部训练种子和最终检查点都要报告。
同一方块的多条件 benchmark 是一个任务族，不等于多个物体、多个视频或真机泛化。
这轮不做开瓶盖，也不修改已冻结的 M01/F01 实验。

## 任务与接口

固定腕座安装位置的 Orca 右手，17 个执行器（含1个可控腕转动关节），方块边长53 mm、默认质量35 g。
起手适当打开食指与拇指部分关节，不是完全张掌，也不是已经完成抓握。
物理步长5 ms，控制步长50 ms，每回合800个控制步，即40 s。
托板从2 s开始下移，3 s完成撤离。

actor（发动作的网络）输入123维，critic（估计长期收益的网络）输入140维。
actor包含关节角/速度、控制历史、方块相对位置/速度/姿态、指尖相对位置、
阶段信息和模拟触觉；残差组额外通道包含参考，纯PPO对应参考通道置零。
输入包含仿真可直接获得的物体状态，不是未经处理的相机图像；部署需状态估计。
模拟触觉存在一个控制周期延迟、噪声及滤波。自碰撞仍未启用，应明确披露。

主任务反馈与视频无关：有效保持奖励15、失败惩罚-50；前3 s额外奖励
`3*接近程度 + 2*拇指接触 + 2*拇指与其他手指成对接触`，整体乘控制步长。
纯PPO输出全关节目标。残差输出`clip(参考角 + 0.08*动作, 关节范围)`；
动作在[-1,1]内，所有方法共享每控制周期0.1 rad的目标变化限制。

视频来源仍是HIC20第30..95帧对应的公开跟踪结果；这轮不重跑RGB姿态识别。
E01做过有限幅度的仿真搜索；40条成功示范来自同一视频的扰动回放，
30条用于BC训练、10条验证，不是40个视频。不能声称视频信息和准备计算免费。

## 预定比较矩阵

训练种子1001..1010；开发初态32000..32007；最终测试初态40000..40199。
新测试集不用于选参考、选超参数、挑检查点或修改任务。
PPO预算每模型163840步，5次开发评估；沿用M01的方法配方，不根据新测试重新调参。
这不是各方法拥有完全相同超参数，也不是本轮重新穷尽调参后的算法排名。

方法：纯PPO、BC后PPO、仅BC、完整残差、线性合拢参考+残差、未校正参考+残差。
BC-only直接使用对应guided训练保存的BC初始化，确保成对。
线性参考保留校正末姿态、相同起手与1.5 s合拢时间，移除视频中间轨迹。
未校正参考只替换动作基底，不改变物体、初始手姿态、奖励、观测维度或预算。
另评估三种参考的零修正，以及完整残差在执行时将修正缩小为一半。
这些消融检验轨迹/校正/修正机制，不足以单独证明视频优于充分优化的人工抓型。

| benchmark | 相对标准任务的唯一变化 | 目的 |
|---|---|---|
| B0 nominal | XY各±2 mm | 重复主结论 |
| B1 position | XY各±6 mm | 更大位置误差 |
| B2 yaw | 初始绕世界Z轴各±10度 | 未见朝向 |
| B3 friction | 接触滑动摩擦系数乘0.6 | 更滑的物体 |
| B4 mass | 方块质量及惯量乘2 | 更重的物体 |
| B5 push | 第10 s施加0.15 N横向力0.2 s，方向按初态种子固定 | 扰动保持/恢复 |

所有策略只在B0训练，其他条件是零再训练的迁移评估。各条件不混在一起算一个大成功率。
如果初态几何门禁发现错误，则在正式测试前修复并记录；不按策略成功率删掉困难初态。

## 指标与统计

原始成功：无支撑，拇指与至少另一指接触，无掌部/托板/地面等禁接触，
方块中心下降不超过10 mm，连续保持至少30 s且40 s末仍有效。
下落55 mm终止。不能拿高总奖励或暂时握住代替成功。

新轮同时记录每个5 ms物理子步的求解接触：最大手物穿透、禁接触、指部峰值法向力。
清洁成功要求原始成功且撤支撑后全程没有禁接触或超过3 mm的手物穿透。
3 mm沿用旧版标准，不根据新成绩调整；它不是硬件安全阈值。
保留原20 Hz状态判据的原始成功指标便于与旧报告对照，不能把两种采样标准混用。

报告成功率、保持时间、接触力、穿透、残差幅度及训练曲线；外力测试额外报告
扰动前有效抓握、扰动后保持和恢复，避免把原本没抓住的回合算作恢复失败的全部解释。
差值先按训练种子计算，再给均值、95%区间和成对检验；多个主要对比做多重比较校正。
10个种子并不保证显著；不能把同一模型200次回放当200次独立训练。
零修正是确定控制器，不复制10份相同结果假装10个独立策略。

最终测试开始前补充的 `S02/statistics_plan.json` 明确：B0五项主要比较使用
Holm-5；全部30项另外报告Holm-30。10种子的双侧精确检验在全局30项
校正下不可能小于0.05，因此不能声称所有扩展条件都有统计显著收益。
扩展测试用于报告效应量、区间和失效边界，逐项95%区间不是同时置信区间。

## 保存与复现

每个运行保存配置、源代码与输入哈希、最终权重、开发曲线、逐回合指标、
固定前若干回合的轨迹。每个benchmark固定训练种子1001和测试初态40000制作
纯PPO/引导/残差/零修正视频，消融也保留对应视频；失败不替换成成功片段。
视频用手心视角，保存STL与碰撞体两版，直接回放状态，不重仿真篡改成绩。
所有命令、运行时间、异常、first/last/max/best_step和下一步写入执行日志。

## 完成标准

不是“残差必须赢”才完成，而是矩阵实际跑完、统计可复算、视频可播放、
源数据与结论一一对应。正式结果出来后逐项标明支持/不支持/证据不足。
当前文件主体为开跑前协议；命令矩阵生成后以S02/protocol.json及其哈希为准。
