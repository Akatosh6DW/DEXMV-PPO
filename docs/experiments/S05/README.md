# S05：纠正食指侧面抓取

## 要解决的问题

用户指出展示视频的抓取姿势奇怪，希望核对人类示范，修正食指侧面接触，并重新训练。目标不是换摄像机，而是让实际承力接触发生在末节指腹区域，同时保持物体不掉落。

本实验独立保存，不覆盖 S02、S04、圆柱 S02 的环境、权重或统计。

阅读入口：[结果与原因说明](结果与原因说明.md)、[独立验证约定](独立验证约定.md)、[完整迭代日志](iteration_log.md)。

## 已核对的证据

- 人类视频：`artifacts/orca_collision_refit/O01_hic53_source_object/source_frames_0_45_95_140.png`。HIC20 中食指末端和拇指在方块两侧夹持。单视角存在遮挡，不能仅凭图像断言每一帧的人类皮肤接触法线。
- 九个已交付展示案例：`artifacts/presentation_clips_20261012/plan.json`。
- 接触诊断原始数据：`artifacts/orca_benchmark_suite/S05/diagnosis/contacts.csv`、`report.json`。
- 重建采样的方块六个展示案例中，食指接触均为末节代理几何，但其法线主要指向局部负 Y，符合侧面接触。圆柱展示同样存在这个现象；失败的 BC+PPO 还出现近节接触。
- 这些是展示案例的诊断，不是全体测试样本的统计。保存状态的 `mj_forward` 重建不等价于原始每个物理子步的完整复现。

## 为什么原来会这样

1. 原成功判据只要求拇指和至少另一根手指接触，没有区分该手指的指腹、侧面、近节。
2. 原始位置重定向主要匹配标记点坐标。即使两个指尖中心位置相似，指腹可能朝向完全不同。
3. 球形/短胶囊碰撞代理的整个表面都可以承力。名字包含 `tip` 不代表实际接触一定在指尖正面。
4. 固定安装姿态、手指长度、关节范围不同，可能使源视频的姿势难以直接复现。PPO 受到原奖励鼓励的是“不掉落”，不保证抓法像人。

所以这不是“视频提供了一个错误动作，PPO 应该自动修好”这么简单；参考生成和训练判据都必须表达我们希望的接触方式。

## 新判据

末节局部坐标中，+Z 沿手指延伸，屈曲关节轴为 -Y，因此 -X 是屈曲侧方向。本实验把它作为指腹朝向的几何定义：

- 接触属于拇指/食指末节，而不是近节或基座。
- 拇指接触点局部 Z ≥ 15 mm，食指 ≥ 24 mm。
- 从手指指向物体的接触法线满足 `-nx >= 0.7` 且 `abs(ny) <= 0.5`。
- 两指合格接触承力均大于 0.02 N；不能同时依靠两指的非合格部位承力超过 0.02 N。
- 撤托后连续保持，仍沿用物体高度、禁止接触、3 mm 穿透限制。
- 训练环境每 5 ms 审计一次，一个 50 ms 控制步内全部子步均合格才计入新保持时间。

这是明确的工程定义，并非声称真实皮肤接触区能够从单目视频被精确识别。开发脚本的稀疏重建数据只能筛候选，最终必须经过环境内子步审计。

## 开发流程与边界

1. 从既有 HIC20 人类跟踪点重新匹配物体相对位置，保留示范的两侧夹持关系。
2. 匹配真实碰撞末端的中心和半径，同时增加指腹朝向约束。
3. 先做逆运动学（IK：从目标接触位置反求关节角度）和原生动力学探测。
4. 曾测试整体安装朝向校准，但主线最终选择保留原安装，允许腕关节参与重定向，并为非目标指节留出净空。物体初始位置仍由参考文件确定，和旧展示不完全相同。
5. 对参考进行有界仿真校正，记录校正量。这属于“视频先验＋仿真优化”，不是纯视频输出，更不是已经训练过 PPO。
6. 通过参考验证后，再进行 PPO 残差训练和 BC+PPO 验证，保存接触数据与视频。

不改物体尺寸，不关掉侧面碰撞，不改变摩擦系数或惯性来伪造“指腹成功”。所有失败候选保留记录。主线显式改变了 MuJoCo 摩擦/法向约束阻抗比 `impratio`：1→2.2，减轻软接触慢滑；它不是摩擦系数，但仍是仿真设置改变，不能把由此获得的改善算作 PPO 的贡献，也不能直接与旧 S02/S04 成功率做算法优劣比较。

编译模型核对：原 O20 与 P20/2.2 的刚体位置/旋转/质量/惯性、碰撞几何位置/旋转/尺寸/类型/掩码/摩擦、关节范围、控制范围及执行器增益均相同；物理步长仍为5ms。

## 当前状态

方块任务已完成重定向修复、残差PPO与BC+PPO各163840步重新训练、独立32初态验证。两训练策略均32/32通过指腹连续30秒及末帧有效标准，实际连续保持37.05秒；仅BC为8/32，参考回放为32/32。因此不能宣称残差在这个已校正参考上提高了成功率。

原模型几何/质量/摩擦系数不变，但参考、工作区和求解器impratio改变；不能与旧S02/S04直接比较算法优劣。一个训练种子、正常方块条件，不代表圆柱或实机。完整数据、图表、短片见 [结果与原因说明](结果与原因说明.md)，失败尝试见 [迭代记录](iteration_log.md)。
