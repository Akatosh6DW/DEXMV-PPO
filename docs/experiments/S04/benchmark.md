# 为什么这样定制基准

[返回目录](README.md)。

## 要检验的主张

**有匹配的视频先验时，两种融合方法可以用更少的在线探索，取得比纯PPO更好的抓握成绩。**

这里的benchmark（基准）就是固定任务、训练预算和打分方式后，比较不同方法的一套题。
本轮有意选择先验适用的题：同一手型、同一方块、接近来源示范的起始相对位置，以及有限的探索预算。
这不是给PPO故意接错接口、少算训练步数或另用更难的物体；三种方法面对同一批测试初态。

S03已完成数据里，在163840步预算下，原始条件、位置扰动、姿态扰动、低摩擦四项，
两种融合方法的平均清洁率都高于PPO；质量加倍条件则都低于PPO。
S04完整保留这五项，并保留长预算表，既集中分析目标收益，也展示适用边界。
“四项胜出、一项失效”只指这五个已列出的条件，不是任意实际任务的抽样比例。

## 五个对照

| 方法 | 视频信息怎么用 | 执行时谁给动作 |
|---|---|---|
| 纯PPO | 不读示范动作序列，不做BC | PPO独立给关节目标 |
| BC后PPO | 先模仿已有示范，再用PPO训练 | 训练后的一个网络给完整动作 |
| 参考加残差PPO | 每步保留来源视频重定向后的参考 | 参考目标加PPO修正，随后限幅 |
| 仅BC | 只做监督模仿，不做在线PPO | 模仿网络给动作 |
| 零修正参考 | 只使用校正后的参考轨迹 | 直接播放参考，不加PPO修正 |

BC（行为克隆）可以理解成先照着示范练习。PPO是通过环境交互和奖励更新策略。
残差是对基础动作的修正量；本项目每关节请求修正不超过0.08rad（约4.58度），
还受关节目标范围和每步最大变化限制。BC后PPO不属于执行时相加的残差结构。

视频不是每一步实时输入RGB图片：已有HIC20跟踪数据经过跨手型重定向和仿真校正，
变成Orca的时间索引关节参考。BC使用D01仿真示范数据，多条轨迹不等于多个独立来源视频。
两种融合方法是此前受控开发选择的完整配方，包含学习率、探索幅度及奖励配置，
并非只改变视频信息一个变量的纯因果消融；这里比较完整方法的实际表现。

## 任务和预算

- Orca固定腕座抓握53mm、35g方块；不是自由移动机械臂从桌面任意位置抓取。
- 初始位置扰动±2mm，使用匹配来源任务的手物相对位置和起手姿态。
- 托板在3秒时撤完，回合40秒；连续有效保持至少30秒且末状态有效，算原始成功。
- 清洁成功额外要求：撤托后每5ms物理子步无禁接触，手物穿透不超过3mm。
- 主要三组各使用相同的163840在线控制步；保留全部十个训练种子21001..21010的对应检查点。
- 新测试使用81000..81099共100个初态，每个学习方法都测相同初态；不依成绩更换种子。
- 仅BC使用十个对应初始化，零参考是一个固定控制器，不伪装成十次独立训练。
- 共41项新评估、4100回合；不重新训练，复用权重而非把旧测试结果当新结果。

三组使用相同观测维度和动力学任务，但残差组有参考通道，纯PPO没有该先验输入。
各组共享来源任务建立的起手姿态，所以纯PPO不是完全脱离示范来源的场景。
BC有4000次监督更新；重定向、参考校正和示范收集的成本也不为零。
因此等在线预算表示**等环境交互步数**，不等于等总开发成本或等全部计算量。
S03后续长训练已经实际花费的成本仍保留，不因取早期检查点而声称这些成本没发生。

## 如何判读

重点比较两项：BC后PPO减纯PPO、残差PPO减纯PPO。
列出均值差、十个训练种子的配对检验以及同时考虑训练种子与共同初态的bootstrap区间。
Holm-2是对这两项比较的多重检验校正；不把1000个回合当成1000次独立训练。
原始成功率和清洁成功率一起给出，不能只挑有利口径。

设计先看过S03结果，新的初态用于检验结论是否只依赖旧的测试位置；
但训练种子和权重没有重新抽取，不能将其称为全新训练上的独立复现。
长预算下PPO可能追上甚至反超，BC后PPO也可能退化。这不否定有限交互条件下的收益，
但意味着结论要写成“提高样本效率”，而不是“融合方法永远更强”。

原始任务、位置、姿态、摩擦条件完整保留，质量加倍作为失效边界保留。
不借此次停止旧队列宣称新物体泛化、强外力恢复或闭环机制已经验证。
模拟中的“清洁”也不代表真机安全：当前未启用手指间自碰撞检查，硬件载荷仍需单独验证。
