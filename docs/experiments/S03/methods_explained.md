# S03 在比较什么

[返回目录](README.md)。这是方法说明，不是尚未完成的正式结果。

## 与之前反复看日志调PPO的关系

之前的Aero迭代是工程开发：训练、看日志、诊断失败、改设置、再训练。
它不自动变成一种新的强化学习算法；最后执行动作的仍可只是PPO。
旧工程还改过碰撞模型和方块/支撑位置，不能把旧手型的保持时间直接当成当前Orca的成功率。

S03迁移的是这种开发过程，而不是直接搬旧权重：三条路线各给四轮、每轮两个训练种子，
先建立原配方，再依次检查探索幅度、学习率、接近奖励。每次从头训练，只用开发初态选配方。
候选更差就不保留，但保留它的日志和计算成本。若没有候选优于原配方，调优结果就仍是原配方，
不能为了让“强基线”名副其实而在看过正式成绩后追加搜索。

## 六种对照

| 对照 | 训练时 | 执行时 |
|---|---|---|
| 固定PPO | 原配方，仅从环境反馈学习 | PPO独立给动作 |
| 调优PPO | 用等预算开发选出的配方，仅从环境反馈学习 | PPO独立给动作 |
| 仅BC | 从既有D01示范学习状态到动作的对应关系 | 模仿网络独立给动作 |
| BC后PPO | 先模仿，再用环境反馈改进网络 | 最终网络独立给动作 |
| 零修正参考 | 无在线策略训练 | 播放重定向并校正的参考 |
| 参考加残差PPO | 学习对参考的有限修正 | 每步将参考与状态反馈修正相加 |

BC是行为克隆，可以理解为“照着示范学操作”。PPO是用交互结果更新策略的强化学习算法。
残差指“相对基础动作的增量”，不是简单地先做BC再PPO，也不是把两个网络结果随意平均。
本任务参考与PPO修正量以关节目标角度组合，单关节请求修正上限0.08rad，约4.58度，
还受执行器范围和每步最大目标变化限制；PPO并非可以无限改写参考。

这里的视频引导并非部署时实时看RGB图像的视觉网络：使用已有来源视频的跟踪数据，
经过重定向与仿真校正，得到时间索引的关节参考。策略读取仿真状态与触觉等接口。
视频来源仍是一条HIC20示范；D01的多条仿真示范不能被说成多个独立来源视频。

## 为什么还要固定回放修正量

假如残差PPO学到的是“始终把食指再合一点”，即使成绩提高，也不能说明它会临场救回失稳物体。
因此先在无外力环境录下它的修正序列，再在相同受扰动初态下比较：

1. 闭环：每一步读当前状态，重新计算修正。
2. 回放：不看当前状态，执行之前录下的修正。

两者共用参考、物理模型、初态、外力与执行器限制。无外力有效轨迹必须一致，施力前也必须一致。
源回合终止后，录制序列剩余修正置零，避免把源失败后的诊断动作当成有效示范。
闭环若更好才支持反馈有益；若两者接近，只能说本次扰动下尚未验证反馈增益，不能删掉该结果。
这里消融的是策略层根据当前观测重新计算修正的反馈。两组底层都保留MuJoCo关节位置伺服，
因此“固定回放”不等于电机完全开环，也不是把所有层级的反馈控制全部关闭。

## 成功与统计怎么读

- 回合40秒，托板在第3秒撤完；连续有效保持至少30秒且结束时仍有效，才算任务成功。
- 清洁成功：在上述条件外，撤托后每5ms物理子步都不得有禁接触，手物穿透不得超过3mm。
- 全程穿透合格：额外检查撤托前的穿透，仅作补充指标，不偷偷替换主评分。
- 训练种子：控制初始化和采样随机性的编号；十个种子相当于十次独立训练尝试。
- 测试初态：同一模型面对的不同起始条件；不能把200回合说成200次独立训练。
- 置信区间：用训练种子和共同初态两个维度重新抽样，估计成绩差值的不确定性。
- Holm校正：同时检验多项主假设时，控制因反复比较而误报优势的风险。
- AUC：成功率随训练步数曲线下面积的归一化值，奖励“更早学会且保持住”，不只看最后一次。
- 右删失：预算结束仍未达到阈值的模型，记作未达到，不删除、不虚构到达时间。

主要推断只有预先指定的三项，其他预算、扰动、形状对比全部报告，但不能看到某项好看后
把它临时升为主要结论。显著性不通过不代表方法一样强，也不能靠不断追加种子直到通过。

## 公平性与适用范围

各调优分支使用相同开发训练次数和在线步数，但这不等于整个系统总成本相同。
BC另有监督更新，参考另有视频处理、重定向、仿真校正和示范收集；准备成本单列。
总进程秒包含评测、编译、等待和BC，多个并发进程秒相加不等于墙钟时间或GPU计算时间。
无法核实的人力或大模型费用标为未知，不填零。

长方体和球体是只在方块训练后直接测试，不给新示范、不重新优化参考。
它们检验跨形状迁移，不检验跨来源视频泛化；物体局部形状、惯量和支撑高度需显式变更。
手型、控制器和传感接口保持不变，模型也没有新增形状类别输入。
各组共享由来源任务建立的手物相对位置和起手姿态；纯PPO不接收参考动作序列，
但整个基准场景并非与视频完全无关。演员网络维度相同，残差组的参考角度通道有值，
纯PPO对应通道置零，这正是被比较的先验输入差别，并非所有观测数值完全相同。
仍然是固定腕座的仿真任务，不是任意位置六自由度抓取，也没有通过真机安全认证。
当前碰撞掩码没有启用手指之间的自碰撞检查；“清洁成功”约束的是手物接触和物体禁接触，
不能因此声称手指之间没有相互穿入，也不能直接当成真机可执行的证明。
