# 视频引导是否加速 PPO：论文对照、设计审计与重做实验

日期：2026-10-04。旧 R08 结果保留；本文件记录独立的新实验，不追改旧成绩。
当前状态：论文审计、D01、P01、C01 五种子确认训练、E01 独立测试及 330 份轨迹复核完成。

## 先回答你的质疑

你记得的“PPO 要经过大模型反复改奖励才成功”有本地记录支持。这与“最终固定好的
环境中，某些纯 PPO 训练也能成功”不矛盾。前者包含找到可训练任务的工程成本，
后者只统计任务已经固定以后的策略训练步数。以前的解释没有充分区分这两个问题。

还要区分两个项目内的任务：你打开的 `grasp_cube_v2_force.py` 是 Aero 手任务；
R08 比较用的是主目录 `scripts/orca_benchmark_env.py` 中的 Orca 任务。手、动作、
几何和奖励都不相同，不能用后者的结果反推前者无需调参。

更具体地说，Aero 文件的 `_get_diagnostics` 在 `hold_success` 中要求
`three_contact > 0`（三根主要手指）；Orca 基准的 `stable` 要求拇指加至少另一根手指。
本轮三方法内部使用相同的 Orca 判据，但它不是原 Aero 三主指任务的复现。

本地可查证的历史：

- [Aero 奖励代码](../Aero-Hand/sim_rl/mujoco_playground/mujoco_playground/_src/manipulation/aero_hand/grasp_cube_v2_force.py)
  包含靠近、三指接触、夹持力、持续抓持、姿态保持等手工项，以及 R78/C20/C149 等迭代注释。
- [Aero C124-C157 总结](../Aero-Hand/v2_iteration_docs/cube_iteration_value_summary_20260428.md)
  记载奖励减法、碰撞几何、物体摆位、学习率等调整。该段最显著的改进来自几何对齐，
  不能把整个历史都归结为奖励修改，也不能仅凭注释还原完整大模型调用成本。
- [Orca 开发日志](orca_30s_experiment.md) 包含几何可达性搜索、先验终点校准、探索噪声、
  BC 约束权重等开发过程。R08 的简单环境也不是没有工程先验的原始任务。

因此，新实验不能只问“哪个最终分高”，还要问：**示范能否减少探索成本，以及对
几何/接触引导奖励的依赖？** 这轮可以检验这两项；完整“节省多少大模型奖励搜索成本”
需要额外的等搜索预算实验，不能由本轮结果直接声称已证明。

## 三种方法与原始论文

### 1. 纯 PPO：固定奖励，自己探索

[PPO 原论文](https://arxiv.org/pdf/1707.06347) 第 6.1 节在 7 个 MuJoCo 连续控制任务上，
每个配置训练 100 万步、每任务 3 个随机种子，比较裁剪/KL 等更新方法，统计回合回报。
它测试的是更新算法，不是“完全不设计奖励也能学会任意抓握”。
官方实现：[OpenAI Baselines](https://github.com/openai/baselines)。

对应本项目：模型每步输出完整关节目标，不读示范。这里“纯”表示没有示范数据，
不是没有设计过的奖励、摆位和控制器。

### 2. BC 初始化再 RL：示范先教会方向

[DAPG 原论文](https://arxiv.org/html/1709.10087v2) 用 Adroit 做搬运、转笔、开门、锤钉。
每任务 25 条成功示范，先 BC，再自然策略梯度和逐渐衰减的示范项；不是 PPO。
论文比较稀疏/塑形奖励，按 100 条轨迹计成功率，并测试质量、尺寸变化。
其核心动机明确包括减轻奖励设计和探索负担。
项目：[论文主页](https://sites.google.com/view/deeprl-dexterous-manipulation)，
实现：[MJRL](https://github.com/aravindr93/mjrl)。

对应本项目：BC + PPO 是借鉴这种训练思路，不是复现 DAPG。
旧 BC 组还有固定权重 1000 的示范 MSE，不能等同“只做 BC 初始化”，也不是论文的衰减项。
新实验将第二组明确设为 **BC 初始化 + PPO，后续示范损失为零**，隔离初始化的作用。
若以后测试持续示范正则，应作为另一组，不能混用名称。

### 3. 残差 RL：基础动作与修正量每步相加

[Residual RL for Robot Control](https://arxiv.org/html/1812.03201v2) 用方块装配任务比较
基础控制器、纯 RL、基础控制器加残差，并测试摆放偏差和控制噪声。
其仿真曲线使用 10 个种子及均值置信区间，底层是 TD3，而非 PPO。
项目：[Residual RL](https://residualrl.github.io/)，所用框架：[RLkit](https://github.com/rail-berkeley/rlkit)。

[Residual Policy Learning](https://arxiv.org/html/1812.06298v1) 在 Fetch 操作任务中研究
基础策略加残差；把残差末层初始化为零，并讨论先固定 actor 训练 critic 的预热。
其原因是好基础策略可能被不准确的价值估计破坏。
项目/代码：[RPL](https://github.com/k-r-allen/residual-policy-learning)。

对应本项目：基础参考来自视频重定向，PPO 只能在每个执行器正负 0.08 rad 内修正。
这是对这些思想的 PPO 适配，不是原论文复现。critic 预热在 PPO 中是否有效仍待单独验证。

### 最直接的 PPO 对照：ResiP

[From Imitation to Refinement / ResiP](https://arxiv.org/html/2407.16677v4) 比较 BC、
BC 后直接 PPO 微调（PPO-C）、冻结 BC 后逐步残差 PPO，以及整段残差的消融。
任务是装配/插入等，使用每任务 50 条示范，并区分初始随机化强弱。
各方法独立调参、方法内跨任务保持参数一致；附录训练上限达 5 亿环境步，折扣 0.999。
这不是本工程 65 万步试验的同预算复现。
[项目](https://residual-assembly.github.io/) / [官方代码](https://github.com/ankile/robust-rearrangement)。

对本项目的启发是：比较时应同时保留“直接微调”和“冻结基础策略加残差”，并给方法
同等的调参机会，而不是把相同参数误当作唯一公平标准。本轮仍只是有限噪声搜索，
没有穷尽学习率、critic 训练、折扣或 KL 约束；不能据此宣称哪种方法的最佳能力上限。

还有结构差异：ResiP 的基础 BC 模型会根据状态规划动作段；本项目的基础参考只是按时间
读取的一条动作轨迹，1.5 秒后保持末帧。它确实是动作残差，但不是同等能力的基础策略。
当前结果不能代表“多视频训练的状态反馈基础策略 + 残差 PPO”的能力上限。

另一个贴近灵巧手的对照是 [Residual RL from Demonstrations](https://arxiv.org/html/2106.08050v1)：
它比较 BC、直接 RL 微调、残差和从零 RL，区分图像/完整状态、稀疏/密集奖励，并研究不同
基础策略水平。底层为 DMPO，不是 PPO。[项目](https://sites.google.com/view/rrlfd/)。
这也提示我们：基础策略质量、观测条件和奖励设计必须明示，不能只给三条没说明条件的曲线。

### 4. 你说的大模型改奖励：另一个优化层

[Eureka](https://arxiv.org/html/2310.12931v2) 是“大模型生成奖励、训练策略、读取反馈、
再修改奖励”的循环。论文把奖励生成与策略学习分开，最终奖励各训练 5 个 PPO 种子，
以统一任务指标评测，并控制参与取最大值的检查点数量。
官方项目：[Eureka](https://eureka-research.github.io/)，[代码](https://github.com/eureka-research/Eureka)。

对应你的经历：外层在寻找奖励函数，内层 PPO 在固定奖励下更新策略。
只统计最后一次内层训练，会漏掉前面的试错成本。示范准备和重定向校准同样不能免费忽略。

### 5. DexMV 在哪里

[DexMV](https://arxiv.org/abs/2108.05877) 将人类视频中的手/物体估计与机器人重定向、
示范学习连接起来。官方仿真工程：[dexmv-sim](https://github.com/yzqin/dexmv-sim)。
它不自动意味着执行时使用“基础动作 + PPO 修正”。本项目目前只复用现有 HIC20 跟踪和
重定向产物，没有本轮重跑 RGB 感知，也没有本轮训练 DexMV 内部策略。

现有 Orca 参考还包含几何终点校准，BC 数据是同一视频参考回放筛出的 4 条仿真变体，
不是 4 段独立视频。本轮比较的是这套组合先验的作用，不能隔离“视频相对几何控制器”
的独立贡献；要回答后一个问题，需额外的几何先验组或视频内容消融。

## 为什么“有引导应该更快”合理，但不是保证

先区分“存在好解”和“学习一定快”。对于执行时的确定性残差控制器，若零修正可表示，
基础控制器满足限位/限速，则输出零就能复现基础动作。因此这个控制器集合中，至少存在
一个不差于基础控制器的解。但这个存在性结论不保证有限样本 PPO 会找到它，也没有比较
PPO 从零学习所需的步数。训练采用有噪声的动作分布时，零均值甚至不等于零修正执行。

用人话说：从乱试所有手指动作，变成在一个可用抓握附近试小改动，确实有理由更省样本。
这是一个值得检验的假设。但成立需要：

1. 示范和当前任务匹配，映射后能接触到物体，而不是仅外形相似。
2. 探索不会一开始就把已有抓握打散。
3. 奖励确实鼓励目标行为，价值估计和优化不会把策略推向歧途。
4. 修正范围内存在更好的控制解。如果需大幅改姿态而残差只允许小幅调整，就可能够不到。

先验的高起点也是真实收益，不能把它抹掉；但它是“系统更早可用”，不等于
“PPO 更新本身改进更多”。两项应同时报告。基础策略已接近满分时，学习增量小还可能是
天花板效应，不能仅凭基线扣除后的增量判断哪组更有用。

## 旧设计的具体问题

| 问题 | 证据或状态 | 这轮处理 |
| --- | --- | --- |
| 将不同手/任务的结论混讲 | Aero 原任务不等于 Orca 基准 | 明确任务边界，不互相替代 |
| 抓握成功口径不同 | Aero 诊断要求三主指；Orca 要拇指加另一指 | 两者不横向比较成功率；本轮内部判据冻结 |
| 没有单独测奖励引导成本 | 旧任务只有一个塑形奖励 | 两种奖励与三种方法交叉比较 |
| BC 组定义混杂 | 旧组固定示范权重 1000 | 新组去掉持续示范项 |
| 高起点混入“收敛快” | 旧 BC/残差许多最优模型是第 0 步 | 单列初始性能、AUC、学习增量、末尾性能 |
| 只看确定性评测 | 训练采样的噪声可能损伤先验 | D01 已实际测随机回放 |
| 相同标准差不等于相同物理扰动 | 全动作与 0.08 rad 残差缩放不同 | 各组等预算搜索高低标准差，并公开两档结果 |
| 相同 PPO 参数被过度等同于公平 | ResiP 对直接微调与残差分别调参 | 同等搜索机会；明确本轮只搜索噪声，不代表充分调优 |
| 把时间轨迹当成完整的视频策略 | 当前基础动作只由时间决定 | 明示仅检验轨迹先验；不冒充状态反馈 BC 基础策略的复现 |
| 一条方块先验拿去测试球体 | 球体失败包含示范迁移失配 | 主实验先用匹配方块；旧迁移失败仍保留 |
| 选择与评测数量少 | 旧验证 8 回合、3 个训练种子 | 新验证 16 回合、确认 5 个训练种子、测试新初始状态 |
| 回报漏记掉落终止帧 | 旧 evaluator 先更新 alive 再统计 reward | 新脚本保留终止帧奖励，主成功定义不变 |
| 结果对接触数值敏感 | 零动作重复仍有成绩波动 | 报告重复波动，不把 1 个回合差异作定论 |

没有证据的事项不写成已查明原因：随机 critic、折扣时间尺度、动作可达范围均是后续
假设。已检查 Brax：`num_resets_per_eval=0` 时跨训练阶段保留环境状态，**没有**证据支持
“每次评估把回合截到约 32 秒”的解释。

## D01：已完成的噪声诊断

固定基础轨迹、未训练的零均值残差网络、32 个相同初始状态（4000-4031）。
每个决策时刻使用新的随机采样键。测试不更新网络。

| 初始标准差 | 确定性零修正成功率 | 随机采样成功率 | 存活期间修正 RMS |
| --- | ---: | ---: | ---: |
| 0.7 | 56.25% | 0% | 0.041589 rad |
| 0.1 | 59.375% | 12.5% | 0.007916 rad |
| 0.03 | 53.125% | 53.125% | 0.002396 rad |

RMS 是平方均值再开根，用来描述典型扰动幅度。确定性控制均为零修正，但物理接触
计算仍有复测波动；三次确定性回放不是三个独立训练种子。
**结论：大噪声确实在这个任务中破坏先验执行。尚不能由此声称降低噪声提高了 PPO 收敛。**
原始数据：[D01](../artifacts/orca_guidance_recheck/D01_noise/metrics.csv)。

## 新实验的冻结规则

这是围绕现有失败证据设计的新实验，不是从未接触过任务的盲测；要披露已有开发历史。

任务范围：Orca 17 个执行器（腕关节 1、手指 16），固定安装基座；36 mm 方块、35 g，
初始位置只在 XY 正负 2 mm 内变化。托台先支撑方块，约 3 秒后撤走；评测合拢与保持。
没有机械臂搜索、远距离接近、从桌面拾取并搬运，也没有相机感知误差。这些共同的摆位和
状态输入已经降低了探索难度，纯 PPO 在该任务能学会并不奇怪。
本轮是局部抓持的机制测试，不能替代论文中的多阶段装配或复杂视频引导评测。

### 三个学习组

- pure：从零均值动作头、随机隐藏层与价值网络开始，不读示范。
- bc：同种子的对应网络，额外做 2000 次 BC 更新，然后只用 PPO。
- residual：同种子的对应网络，零均值修正头，执行视频参考加有界修正。

### 两种奖励

- shaped：完整保留旧奖励，包括靠近、拇指接触、对向接触、居中、有效抓持、非法接触和掉落项。
- hold_only：只保留 `(15 * 有效抓持 - 50 * 终止) * dt`，去掉几何/接触塑形项。

hold_only 在有效抓住后每步给分，**不是仅在回合末给分的稀疏奖励**，也不等于没有人工
定义成功条件。它检验对接近过程塑形的依赖。真正终点稀疏奖励需要另一轮协议，不能偷换名称。
物理模型、初始分布、动作限幅、撤台时间、30 秒成功条件不随奖励变化。

### 开发与确认

1. P01：训练种子 91；每组标准差候选 `{0.03, 0.7}`；两种奖励，共 12 次短训练。
   每次 163840 步、3 次验证，验证初始状态 4100-4115。所有候选完整保留。
2. 每种方法按两奖励平均 AUC 选择一个标准差，并列选 0.7；不能按正式测试成绩选参数。
   每组搜索花费均为 4 次短训练，即 655360 个环境步，BC 的额外监督训练单独计算。
3. C01：冻结选定参数，用训练种子 10-14，三方法乘两奖励，共 30 次从头训练。
   每次 655360 步、9 次验证，验证初始状态 5000-5015。运行中不根据结果更改任务或奖励。
   这些训练种子与 P01 的 91、R08 的 0-2 不重叠；但 10 在更早的 O 系列开发中出现过，
   因此不声称整个项目历史上从未见过这些编号。连续选取 10-14，没有按旧成绩筛选种子。
4. 测试初始状态 6000-6031，与开发/验证/示范均不重叠。测试每组初始和末尾策略，
   必须比较 PPO 前后的同组表现；先不按最佳验证点择优展示。
5. 不使用球体失败替代同任务示范效益结论；也不因主实验选择方块而删除旧球体失败证据。

### 评价与停止

- 主性能：30 秒连续有效抓持且 40 秒末帧仍有效，沿用旧独立物理计分。
- 样本效率：全部成功率曲线、归一化 AUC、连续两次达到 75% 所需步数。
- 初始已达标明确标记；未达标用“预算内未达到”，不虚构收敛步数。
- 学习增量：末尾减初始、AUC 减初始，并与原始分数同时解释。
- 稳定性：全部训练种子、非法接触/掉落、末尾连续 30 秒比例、非零残差幅度。
- 成本：PPO 步数、BC 时间、等预算搜索；历史视频采集/校准成本不能从最终训练计时恢复。
- 达成任务的停止条件是完成此协议并如实分析，不是一直换实验直到引导赢。

按训练种子而非回放帧做不确定性分析；5 个种子也不足以证明普遍优势。
这遵循 [Statistical Precipice](https://arxiv.org/html/2108.13264v2) 强调的多次独立运行与
区间估计原则，但单任务小样本区间仍可能不可靠，不能冒充其多任务大基准结论。

## 读论文时的术语

- Actor：输出动作的网络。残差模式中，它输出修正量，而不是完整动作。
- Critic：估计“当前状态以后还能拿多少分”的网络，为动作网络的更新提供依据。
- BC：行为克隆，用示范中的状态和动作做监督学习，不靠自行试错的奖励训练。
- Reward shaping：奖励塑形，除了最终是否成功，再给靠近、接触等过程提示。
- On-policy：主要用当前策略新采集的数据更新；这里的 PPO 属于这一类。
- Off-policy：能够复用其他或旧策略的数据；论文里的 TD3/DMPO 与 PPO 不是同一种算法。
- Ablation：消融，控制其他条件，只去掉或改变一个部件，以检查它的作用。
- KL 约束：限制新策略偏离旧策略的程度；不是残差动作幅度限制，两者不要混淆。
- Seed：随机种子，固定一次网络初始化和采样的编号；多个回合不等于多个训练种子。
- AUC：学习曲线下面积，归一化后是训练期间的平均成功水平，包含初始优势。

例如“BC 有高初始分，但 Critic 还没学好”就相当于：手已经知道一个大致可行的动作，
但负责评价动作长期后果的模块还不可靠。继续强化学习可能改善，也可能暂时把它改坏。
是否由此导致本项目退化，需要控制 critic 训练的单独实验；本轮没有假装已经验证。

## 对你的方案意味着什么

这次纠正后的结论不是“视频没有用”，也不是“有视频肯定收敛更快”：

1. 本任务中视频组合先验让系统更早出现可用抓持，训练曲线前半段明显优于从零探索。
2. 简化奖励后出现了残差改善先验的实例和正向组均值；整体高可靠性和最终优势尚未证明。
3. 你之前用大模型反复改奖励/几何才得到 Aero 好结果，与以上两点没有矛盾。
   当前 Orca 的物体已放在可达位置、判据也不同，不能拿它替原任务宣布“不用设计奖励”。
4. 对你想做的系统，最接近的论文路线是 ResiP：先学一个能根据状态给出基础动作的模型，
   冻结它，再让 PPO 每步修正。当前仅按时间播放一条参考轨迹，是较弱的基础策略。

若进入下一阶段正式性能研究，应另立协议，而不是根据本次测试继续反复挑赢家：

- **隔离视频贡献：**视频重定向基础策略、仅几何基础控制器、无先验三类都保留；
  增加多条视频和基础策略质量分档，避免把校准的贡献全部归给视频。
- **奖励设计成本：**固定任务/几何/成功条件，对无示范与有示范分配相同外层搜索次数和
  总仿真预算，记录失败尝试、大模型调用量、人工时；视频准备成本也必须计入。
- **纯算法样本效率：**开发集分别调直接微调和残差的噪声、学习率、更新次数；冻结参数后
  在新训练种子上重跑。critic 预热、长期折扣、基础动作可达范围分别做单变量检验。
- **真实任务复杂度：**更大初始误差、扰动恢复和固定瓶身拧盖等任务应单列，不替换已冻结
  的方块数据。加入新视频/物体测试后，才讨论跨对象泛化。

以上是下一阶段研究设计，不是本轮已经执行或验证的结果。本轮按冻结协议收尾，保留所有
正负结果，不继续换任务或筛种子来强行得到“引导必胜”。
