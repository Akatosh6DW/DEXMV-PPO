# S09 BC+PPO 修复迭代（2026-10-15）

## 范围和判据

用户授权自主迭代修复 BC+PPO，不设置人为训练预算；仍受硬件、磁盘和实验有效性约束。
本文件记录新开发实验，不修改冻结的 S09 R0/R1 数据、代码、模型和成功判据。
第一阶段固定旧示范定位训练问题；这不冒充从新视频重新提取。
后续新视频/新示范实验必须单独标明来源，不能以旋转旧轨迹代替新视频。

主要指标仍为随机朝向、释放后严格连续合格30秒且最终合格的成功率；同时检查穿透、峰值力、非手支撑和释放后绳力。
阶段目标：BC闭环可靠性改善，接入PPO后不再系统性退化，并在未参与调参的场景上超过同批参考回放。
用户随后明确目标为“BC+PPO明显超过旧版4.17%，且尽可能高”；超过参考回放是探索目标，不是用户规定的硬阈值。
不把小开发集成功率当最终性能，不在已查看过的测试集上挑选模型。

开发集：110000--110031（连续随机SO(3)）；短探测使用前16例。
最终保留集在候选冻结后才执行：120000--120127；方向诊断另外分配。
旧模型仅作诊断对照；额外训练成本如实累计，不宣称与163840步旧实验等预算。

## I01：降低接续PPO的探索噪声

- 假设：BC先验较脆弱，0.3的tanh前策略标准差会扰乱已有接触；降低至0.03有助于保持。
- 唯一配方改变：初始标准差0.3 -> 0.03。BC更新4000、种子9101、PPO学习率3e-5、奖励/环境均不变。
- 与同配置0.3分支使用相同新开发集配对，短训练40960在线步。
- 从同种子初始化并重新BC，不从旧最终PPO权重继续。
- 输出位于 artifacts/orca_benchmark_suite/S09/bc_repair/。
- Smoke：两个分支均完成BC、确定性闭环step0和PPO更新，输出有限值。
- 完整短探测：低噪声success first=6.25%, last=0%, max=6.25%, best_step=0；hold first=3.744s,last=2.272s,max=3.744s,best_step=0。
- 原噪声对照success first=6.25%,last=0%,max=6.25%,best_step=0；hold first=3.744s,last=0,max=3.744s,best_step=0。
- 低噪声最终最大释放后穿透24.199mm、峰值295.07N；对照9.605mm、98.20N。均不能算修好，低噪声也未带来干净接触。
- 结论：仅降低探索噪声不足，两个分支的BC起点本身仅1/16成功；不把0.03作为已验证有效的主线。
- 下一轮类别：训练超参数/采样配方。优先检查闭合阶段权重，同时独立检查示范约束。
- 命令入口：scripts/run_s09_job.py；共同参数 --input artifacts/orca_benchmark_suite/S09/inputs --method guided --dataset artifacts/orca_benchmark_suite/S09/demonstrations/trajectories.npz --seed 9101 --learning-rate .00003 --steps 40960 --evals 3 --eval-count 16 --eval-start 110000；分支分别 --std .03/.3 和独立输出目录I01_low_noise/I01_control_noise。
