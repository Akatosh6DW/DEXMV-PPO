## 方块完整结果

以下来自全部 513 项评估的 `F01/report/statistics.json`，不是此前 99 项的临时快照。

触觉“关”仍可使用关节和物体状态，不等于盲控。BC 后 PPO 在文件中命名 `guided`。

| BC | 开 | 0 | 0.0% +/- 0.0% | [0.0%, 0.0%] | 5.39 N |

“成功数 / 320”是便于直观理解的合计，不把 320 回合当作 320 个独立训练种子做检验。
峰值载荷不是平均用力，也不是力矩；每个种子先在全部测试回合/有效时间/手指上取最大值，再对五种子平均。

**主要结论：本配方下，残差架构可以稳定完成方块保持，但没有超过纯 PPO 的成功率。**
残差相对纯 PPO 的成功率配对差为关触觉 -6.25 个百分点、开触觉 -5.00 个百分点；
对应种子 bootstrap 区间为 [-10.63, -2.19] 和 [-7.81, -2.50] 个百分点。
五对样本精确双侧符号翻转检验均为 p=0.0625，不报告 p<0.05 的显著结论。
残差的上述载荷均值约低 52.5%/57.7%，是描述性结果，不是硬件安全证明。
BC/BC 后 PPO 使用的是单视频失败回放示范，不能用该表否定成功专家示范、BC 或 DexMV 的一般能力。

在名义条件中，15 秒且末帧有效、30 秒且末帧有效、末帧有效三个比例恰好相同；
因此原先“超过 15 秒”的方块要求已有更严格的 30 秒证据，但不是每回合都成功。
残差关/开触觉的平均最长保持为 36.88/36.84 秒，各种子最大穿透的均值为 1.65/1.66 mm。
这不是全过程最大穿透的上界，也不代表轨迹每一步都无穿透。

### 学习过程和失败

开发曲线归一化 AUC 是训练期间成功率曲线面积除以训练步数，越大表示该预算内更早/更常成功，
不是独立测试成绩。关/开触觉的五种子平均分别为：纯 PPO 0.491/0.605，
BC 后 PPO 0.669/0.358，残差 0.178/0.329。残差在本轮没有学习效率优势。
BC 后 PPO 关/开触觉的开发峰值到最终平均退化为 45/60 个百分点；
“早期学得快”与“最终表现稳定”是两件事，不用最佳检查点掩盖这种退化。
[开发曲线](../artifacts/orca_formal/F01/report/development_curves.png) 展示五种子均值与标准差，
逐种子的过线步数、删失、拟合时间和退化见 statistics.json 的 `learning`。

名义条件失败分类（每条件 320 回合，按固定优先级互斥归类）：

- BC 关/开触觉：各 320 回合在建立过有效保持后终止。
- 纯 PPO 关/开触觉：分别 0/1 回合在建立保持后终止。
- BC 后 PPO 关触觉：44 回合高度无效、22 回合未建立有效无支撑保持、87 回合建立后终止。
- BC 后 PPO 开触觉：5 回合高度无效、256 回合建立后终止。
- 残差关触觉：10 回合建立后终止、1 回合高度无效、9 回合接触无效。
- 残差开触觉：9 回合建立后终止、8 回合接触无效。

“终止”不自动等于掉落，接触无效也不一定意味着方块已经离开手。
全部 513 项的最大穿透仍为 s301_guided_off__mass05 的 6.705 mm；相应失败与物理局限没有被剔除。

## 实际链路

```text
源 RGB 视频及其已发布手/物体跟踪标注
    -> 同源物体网格、尺寸、坐标系和帧号核对
    -> 手部关节点转到物体坐标系
    -> 映射到 Orca 的可控制关节，并处理关节限位/接触几何
    -> 按仿真控制周期得到视频关节目标序列 q_video(t)
    -> 真实接触物理回放，记录观察和动作供 BC 使用
    -> 在同一仿真任务中训练纯 PPO、BC、BC 后 PPO、残差 PPO
    -> 固定最终检查点，在独立初态和扰动条件上评估
```

方块采用 HIC20 对应的 53 mm 方块及已有 DexMV 重定向关联数据；不再把旧小方块/瓶子参考混用。
拧盖采用 OakInk2 对应瓶身和瓶盖，使用已发布人体关节点直接映射到 Orca，没有 Adroit 中转。
这两条本次都没有重新运行 RGB 姿态估计，也不是在本轮重新训练 DexMV 内部的 TRPO/DAPG。
发布的跟踪结果可能有误差；RGB 对齐看起来正确，不代表已经测得精确三维真值。

物品“对上”包含身份、形状、尺寸、物体坐标系、与手的相对位姿和时间对齐，不只是都叫 cube。
质量、摩擦和电机参数仍是仿真假设，不是由视频准确恢复。方块贴纸和可转动内部层没有建模。
方块按 35 g 建模；拧盖瓶盖按 15 g 建模，使用 44 mm 瓶盖、约 62 x 120 mm 瓶身。
拧盖保留约 2.035 mm 初始内部网格重叠：啮合时过滤瓶盖与瓶身接触，解除后恢复，
手与物体接触始终开启。瓶盖没有独立电机，解析约束产生的是机构反力，不是学习策略之外的取盖控制。
这些近似不应因“同源物体”而被理解为实测高精度数字孪生，详见
[冻结拧盖协议](orca_formal_cap_protocol.md)。

## 最终每一步是谁决定

残差分支执行的是：

```text
PPO 修正 = 0.15 * clip(PPO(当前观察), -1, 1)
期望关节目标 = clip(视频当前目标 + PPO 修正, 关节范围)
实际下发目标 = 限速(期望关节目标, 每控制步最多 0.1 rad)
```

大动作每步仍来自视频，PPO 每步根据当前状态微调。限位/限速也属于最终控制器，
所以不能把网络原始输出、期望目标、下发目标、物理关节实际角度混为一谈。
后者还受惯性、摩擦、重力、碰撞、电机限制影响，视频目标到达不代表物体被抓住。
特别注意：0.15 rad 限制的是控制目标上的修正，不是实际关节相对视频姿态的最大偏差。
若接触阻挡或执行器饱和，真实关节角可以偏离目标很多；这需要检查目标跟踪，不能靠动作公式保证。

目前视频基底是按时间播放的目标序列，不是在线阅读新视频的视觉网络，也不是任意物体通用策略。
执行残差策略需要同时保留 PPO 权重、参考 NPZ、关节映射、时间/阶段管理、观察处理和限幅限速。
只有权重文件，不能完整复现该残差控制器。DexMV 旧环境不需要和 PPO 环境同时运行。

[正式策略控制分解图](../artifacts/orca_formal/F01/report/control_residual_on_seed301_reset25000.png)
对应上面的固定残差成功例：灰虚线是视频参考，蓝线是实际下发目标，绿线是物理关节角。
下图显示 PPO 修正始终小于 0.15 rad；该例最大请求修正约 0.13191 rad，最大关节目标跟踪误差约 0.11262 rad。
图中选了四个关节便于阅读，保存的 JSON 与逐步控制审计覆盖 17 路控制。
这证明该例确实执行了“视频基底 + PPO 修正”，不等于它比其他算法更好，也不代表实际关节严格贴合目标。

## 几种结合方式

| 方法 | 示范怎么用 | 执行时动作 | 本次是否正式比较 |
| --- | --- | --- | --- |
| 纯 PPO | 没有在线示范动作 | PPO 直接输出完整目标 | 是；但共享视频推导的环境摆位/共同初态 |
| 只用示范起手 | 只改变 reset | 后续 PPO 完整控制 | 没有单独声称这个条件与完全无视频环境的差值 |
| BC | 用示范观察/动作做监督拟合 | BC 网络完整输出 | 是，不进行 PPO 更新 |
| BC 后 PPO | BC 先训练，PPO 再修改同一网络 | 最终网络完整输出 | 是，不是残差 |
| 视频轨迹 + 残差 PPO | 每步视频目标持续参与 | 基础目标 + 有界修正 | 是，用户要求的主架构 |
| PPO + demo loss | 训练损失中加入模仿项 | 通常仍是单一策略完整输出 | 不是本次正式主表条件 |
| DAPG/TRPO | 示范项辅助策略梯度更新 | 通常是单一策略输出 | 不是本次正式主表条件，也不能称为残差 |
| BC 基础网络 + 残差 PPO | BC 随状态输出基底，另一个网络修正 | 两个网络持续共同控制 | 候选扩展，本次未实现为正式条件 |

“先 BC，再 PPO”和“每步基础动作加 PPO”区别在于示范是否在执行时仍有独立控制通道。
前者可能忘掉示范，也可能自由探索出更好的动作；后者保留视频结构，但坏基底超出修正范围时会限制性能。
残差并不自动比纯 PPO 强，必须检查多个种子、统一测试与失败情况。
方块任务在建立抓持后主要要求持续保持，并不要求不断改变目标姿态。因此即使残差抓持成功，
也不能单凭它证明整段视频时序不可替代；必须结合末帧/固定起手参考和零修正对照。
同源拧盖任务另外考察动态操作，但其结果也受固定底座、重定向和近似机构限制。

## PPO 在学什么

仿真器根据下发的关节目标推进物理，产生新的关节/物体状态和接触信号。
策略用自己采到的轨迹学习，不是只对视频帧背答案。
方块的主要目标是撤掉支撑后持续有效保持；拧盖同时有转动进展、接触、脱离/持盖等信号。
PPO 优化的是得到奖励的动作概率，不会凭空创造机械手缺少的自由度。

BC 则把“示范情况下应该输出什么动作”当监督答案。当前示范来自同一视频的物理回放，
不是成功专家。BC 的训练损失很低，也可能一旦自己执行产生偏差后越走越偏。
不同随机初态的 32 条回放仍只对应一个源视频，不能说成 32 位示范者或 32 个视频。

## 公平比较与指标

方块为 5 训练种子，四方法乘触觉开关；再做参考模式和探索 std 敏感性实验。
所有 PPO 条件固定 655360 步、统一主配方，不使用测试结果挑最好检查点。
BC 与 BC 后 PPO 的对应权重逐项配对；BC 拟合时间和模拟交互预算分开报告。

主方块成功要求：至少 30 秒连续有效无支撑保持，且末帧仍有效。
有效包括拇指与其他手指接触、没有禁用接触，以及高度满足门槛。
同时报告 15 秒、最长保持、末帧留存、接触力、几何穿透、获得抓持的时间和失败阶段。
峰值力先按每根手指传感区域累加各接触点法向载荷，再取手指/有效时间/回合上的最大值，
不是五指总和，也不是单个电机输出力；拧盖时该载荷还可能包含手指与瓶身的接触。
本轮轨迹按 20 Hz 控制周期保存；连续保持指这些控制采样点连续有效，并未逐个 2 ms 物理子步
保存接触历史。因此不能宣称已排除所有采样间短暂接触中断，报告的峰值力也不是所有物理子步
上的瞬时最大值。微小快照穿透不能替代载荷/硬件安全验证。
“还在手里但滑低了”“靠掌部支撑”“从来没建立有效抓持”“终止了”不能都简单写成掉落。

拧盖要求完整解除约 490 度螺旋约束、沿瓶轴移开至少 18 mm、无外部支撑，
最后连续有效持盖至少 1 秒；单纯转过 90 度或脱离后掉落不算成功。
拧盖还有全回合失格规则：初始手部穿透超过 3 mm，或执行中任一步发生禁用接触/手部穿透超过
5 mm，该回合后续即使看起来夹住瓶盖也不计成功。这比方块的逐时刻有效接触规则更严格。
该任务使用近似解析螺旋机构，不是实测精细螺纹齿接触，内部重叠等局限见冻结协议。
最大/最终转角可能包含解除约束后的自由运动，不等于仍在啮合的螺纹圈数。
视频在解除约束后标记 `thread=RELEASED`，此时不再把螺旋关系偏差显示成仍然有效的约束误差。

每个最终模型测试 64 个独立初态；统计单位是五个训练种子，不是把 64 初态当成 64 次独立训练。
方块位置/朝向扰动也可能造成无效初始几何。按照测试前冻结的补充约定，初始物体接触穿透
超过 3 mm 的回合单独标记，严格总成功率计失败，同时报告有效初态子集成绩；不重采样删除。
必须把初态无效率与有效初态下的控制失败分开解读，不能把二者合称算法不鲁棒。
报告均值、标准差、按种子 bootstrap 区间和配对差值。五种子仍少，零宽区间不代表绝对可靠。
双侧精确符号翻转检验五对样本最小 p=0.0625，不能由此编造 p<0.05 的优势。

学习效率用开发曲线 AUC 和过线步数描述，另列峰值到最终的退化。
历史字段 `sustained75_step` 只表示两个连续记录点达到 75%，不表示直到最后都保持 75%。
相同 std 也不意味着相同物理探索幅度：残差只能动 +/-0.15 rad，纯 PPO 具有完整关节范围。

## 创新应如何表述

基础控制器加学习修正不是本项目发明；残差机器人控制已有公开工作。
见 [Residual Reinforcement Learning for Robot Control](https://arxiv.org/abs/1812.03201)。
视频手/物体姿态到机器人示范再学习的路线也已有 DexMV。
见 [DexMV 原论文](https://arxiv.org/abs/2108.05877)。

本项目可被证据支持的贡献方向是：面向目标手的同源手-物体映射、碰撞代理核查、
执行时视频目标与有界修正的集成、触觉开关与多种结合方式的配对实验，以及可追溯的失败审计。
是否构成论文级新方法，需要对已有方法作更完整比较，不能只凭“DexMV + PPO”这个名字下结论。
工程链路能通、单个策略成功、统计上更好、真实硬件可用，是四个不同层级。

## 自由度与性能限制

本轮正式协议冻结后不因某方法输而调参。

拧盖重定向还有一个直接量化的限制。CAP10 的 report.json 中 `[423,1548)` 是误差统计区间，
不是 NPZ 轨迹截断：NPZ 仍保留源帧 239-1760，环境从接触锚点 423 开始读到 1760，
对应 11.142 秒参考，插值/限速后供 20 秒回合使用，末段保持最后目标。
不能把低于 10 mm 的阶段性拟合数字误当成整段动作都能精确复现。

| 参考阶段 | 采样帧数 | 拇指/食指平均拟合误差 | 拇指/食指 p95 误差 | 两者都不超过 10 mm 的比例 |
| --- | --- | --- | --- | --- |
| 旋拧统计区间，源帧 423-1544 | 141 | 2.32 / 8.39 mm | 4.40 / 14.49 mm | 63.1% |
| 后段，源帧 1552-1760 | 27 | 58.44 / 110.67 mm | 96.24 / 169.43 mm | 14.8% |

上述数字直接从冻结 NPZ 的 errors_m 与 source_frame_id 分段计算。
误差是机器人拟合指垫位置相对重定向目标的距离，不是 RGB 姿态识别精度，也不是仿真时的动态跟踪误差。
固定底座无法直接复制人体手臂平移，当前参考后段的可达性确实很差；
这支持先检查参考与工作空间，而不是把取盖失败全归因于 PPO 算法。
但它也不能证明唯一原因或证明任何固定手都不可能取盖：完成 18 mm 移离并不要求逐点复制全部人体轨迹，
还需区分可行的接触/移离路径、奖励设计、执行器饱和与模型近似。

当前方块任务从视频推导的近距离共同起手开始，先有支撑、3 秒后撤支撑，
考察建立并保持无支撑抓握。它不是从桌面远处自主接近、抬起并搬运的完整操作任务。
固定底座没有机械臂运输自由度；不能用“保持 37 秒”的视频冒充已经验证桌面拾取或空间搬运。

后续任务设计应分别检查，而不是直接把所有难度堆在一个总奖励里：

| 新任务/阶段 | 应单独计分的指标 | 当前还缺什么 |
| --- | --- | --- |
| 位置变化下建立抓握 | 合法初态比例、无支撑建立率、建立时间、最终保持 | 可行 reset 与状态反馈，不把初始穿透当控制失败 |
| 方块转姿态再保持 | 目标角误差、到达时间、无掉落完成率、载荷 | 多阶段/多姿态视频与接触事件阶段管理 |
| 抓起并搬运 | 离桌高度、目标位置误差、无外部支撑搬运成功率 | 腕部/机械臂工作空间及相应控制接口 |
| 完整拧盖 | 解除约束、轴向移离、无瓶身支撑、连续持盖分别统计 | 参考动作可达性、脱离后运输、重抓和机构验证 |

这些是下一版独立任务的设计建议，不是本轮已经完成的实验。

一个已检查的开发案例：拧盖 s401_residual 最终模型回合 0，拇指 CMC 末帧目标约 +0.535 rad，
实际约 -0.625 rad，误差约 1.159 rad，模型执行器输出已达到配置限幅。
残差目标仍严格位于 +/-0.15 rad 内，说明“网络接口正确”与“物理姿态能够跟随”是两回事。
证据见 [拧盖开发记录](orca_formal_cap_development.md) 的控制分解图与原始轨迹路径。
这是失败诊断，不是五种子正式性能结论；也不能据此断言只有电机问题或直接提高力矩。

同一现象也出现在独立测试，而不只在开发初态：
[正式拧盖控制分解图](../artifacts/orca_formal/CAP_F01/report/control_residual_seed401_reset28500.png)
固定为 seed401/reset28500。最大请求/实际目标修正均为 0.135709 rad，仍小于 0.15 rad；
但实际关节对下发目标的最大跟踪差为 1.193722 rad。
末帧拇指 CMC 目标 +0.534543 rad、实际 -0.624368 rad；图中约 10 秒以后两条曲线明显分离。
该例 7.75 秒解除约束，最终轴向移离约 10.18 mm、无有效持盖，且仍接触瓶身；
这个模型的全部 64 名义初态都归为解除后仍受支撑，0/64 成功。
它是固定案例解释，不代替五训练种子的比较；图的 JSON 绑定原模型、正式轨迹和绘图源码哈希。

下一版可单独测试：

- 先检查任务在关节范围、指尖工作空间、腕关节行程上是否可行，再区分重定向误差与控制误差。
- 优化接触点/指垫法线，而不只追人体骨端位置；同时限制穿透、速度和电机负载。
- 分开验收旋拧与移离阶段的可达性；若人体后段超出工作空间，应映射为任务等效、机器人可达的移离路径，或单独引入腕/机械臂控制，不能直接丢弃后段再声称完整复现。
- 用触觉接触事件管理视频阶段，使参考可以等待、重抓，而不只按固定秒数播放。
- 用多个同任务/同物体示范学习随状态变化的基础策略，再叠加小残差，减少开环轨迹偏移。
- 若必须增加腕/手臂自由度，作为新的硬件/任务条件单独实验，不和旧固定底座结果混合。
- 扩充物品需要新物体几何、姿态及接触可行性检查；质量/摩擦随机化不等于已经学会抓任意形状。

硬件部署还需要标定电机/传动、传感器、物体状态估计、延迟、限力保护和真实安全验证。
当前仿真峰值力和成功率不能直接当实物能力或安全保证。
独立扰动测试也已发现明显接触缺陷：s301_guided_off__mass05 最大穿透约 6.705 mm，
约 98.6% 的 active 保存状态超过 5 mm，严格成功为 0/64。
该失败保留在原统计内；对应诊断视频和哈希见执行日志。方块与拧盖的失格规则不同：
方块没有把全过程每次超过 5 mm 穿透都自动改判失败，而是另行报告接触质量。
因此评分审计通过只证明实现符合冻结定义，不证明整个过程具有可信的接触物理或硬件可行性。
当前触觉通道把每指法向载荷截断到 5 N 后归一化，加入噪声、滤波与延迟；
因此“有触觉”不代表 actor 获得无限量程的原始力，更不代表已经实现限力控制。
大于量程的不同载荷可能产生相同的饱和输入，而保存的原始力仍可能很高。
未来可单独比较量程/对数压缩、载荷惩罚与硬件限力保护，本轮不能事后修改这些条件。

拧盖还存在历史信息不完整的问题：`invalid_ever` 记录回合此前是否已失格，`hold_steps`
记录连续有效持盖时间，但当前 actor/critic 观察没有直接包含这两个量。
因此相同的当前可见姿态可能对应不同的奖励资格，不能把现有输入称为完整马尔可夫状态。
这是可在下一版比较的状态设计限制，不是本轮修改观察维度或解释全部失败的依据。

## 术语速查

| 术语 | 通俗说明 |
| --- | --- |
| PPO | 根据自己尝试得到的奖励，小幅更新动作策略的一种强化学习算法 |
| TRPO | 另一种限制策略更新幅度的强化学习算法，也能通过物理交互学习 |
| BC | 行为克隆，用示范动作做监督学习，不等于已经运行 PPO |
| DAPG | 用示范辅助策略梯度训练的思路，不由名称保证执行时有加法残差 |
| Prior / 先验 | 训练或控制之前已经提供的信息，本项目主要是视频推导的动作参考 |
| Residual / 残差 | 对基础动作额外增加的小修正，本项目在每一步显式相加 |
| Tracking Error / 跟踪误差 | 下发目标角与物理实际角的差，不等于 PPO 输出的残差 |
| CMC | 腕掌关节；这里是模型中拇指根部对应关节 |
| MCP | 掌指关节；这里是模型中手指与手掌相接处的关节 |
| rad / 弧度 | 角度单位；0.15 rad 约为 8.6 度，这里限制的是关节控制目标修正 |
| Retarget / 重定向 | 把人手或另一只手的动作转换为目标机械手能够表达的动作 |
| IK / 逆运动学 | 从期望指尖位置反求关节角，不保证接触动力学能成功 |
| Collision proxy / 碰撞代理 | 物理计算使用的简化几何，和屏幕上的 STL 外观是两回事 |
| Actor / Critic | Actor 出动作；Critic 在训练时评估状态或动作的价值 |
| Checkpoint / 检查点 | 某个训练时刻保存的参数；正式比较固定用最后一个 |
| Optimizer State / 优化器状态 | 优化算法积累的动量等训练记忆，与策略权重不同；只有权重不能保证精确续训 |
| Seed / 随机种子 | 控制随机数来源；训练种子和测试初态种子要分开 |
| Ablation / 消融 | 只改变一个组成部分，看它对结果有何影响 |
| std | 探索分布的标准差，不直接等于关节角变化范围 |
| Bootstrap 区间 | 对训练种子的结果重采样得到的不确定性区间，不是成功概率保证 |
| p95 / 第 95 百分位 | 描述误差分布较大一端的数值，不是 95% 成功率 |
| AUC / 曲线面积 | 本文将开发成功率曲线面积除以训练步数，描述该预算内平均开发表现 |
| 名义条件 | 默认测试参数，不额外施加本轮质量/摩擦等扰动，但仍保留规定的初态随机性 |
| 螺旋约束解除 | 仿真不再把瓶盖旋转与轴向位移按螺距关联，不等于已经移开并持住瓶盖 |
| Domain randomization | 改变质量、摩擦等模拟条件；本轮独立扰动测试不是对测试条件再训练 |

### 本轮结论

1. 执行时“视频关节目标 + PPO 有界修正”确实实现，并在同源 53 mm 方块上通过多种子抓持测试。
2. 名义方块中纯 PPO 成功率更高；残差的峰值载荷描述性均值较低，但不能据此宣称更安全。
3. 完整时序相对末帧基底、有触觉相对无触觉，尚无明确优势证据；不能把整段视频不可替代当成结论。
4. 同源拧盖比较完整执行但主任务全失败。参考后段可达性、动态目标跟踪、支撑与接触质量是有证据的限制，非唯一因果定论。
5. 本轮不是任意新视频的端到端 RGB 感知验证，不是桌面远距离拾取/运输验证，不是实物部署或通用抓取验证。
