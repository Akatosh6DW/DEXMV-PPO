# S06：让圆柱抓法更接近示范

本轮单独研究圆柱，不覆盖圆柱S02的原始对比实验，也不把方块S05的成功率当作圆柱成绩。

## 你问的“样本是怎么夹圆柱的”

当前圆柱样本来自DexMV官方处理后的番茄罐序列96，使用其中182～271帧。它已经是Adroit机械手的关节轨迹，不是我们重新识别的原始人手视频。原始RGB与这个序列的对应尚未核实，所以不能声称已经看清真人每根手指的皮肤接触。

从已有轨迹重建出来看，食指、中指等手指沿罐体侧面弯曲，拇指在相对的一侧，不是只用两个指尖碰一下；整体更像多指围住罐体。

![处理后源示范的四个时刻和两个视角](../../../artifacts/orca_benchmark_suite/S06/source_audit/source_contact_sheet.jpg)

但源重建不是完美专家：它包含明显穿模，小指最深约41.6mm，其他手指也有穿透。图中的几何相交不能当成人手真实接触力。旧桥接只使用拇指、食指的位置，忽略了中指关系，又没有明确要求手指哪一面朝物体。

## 本轮要改变什么

在Orca上保留源样本里“拇指对着食指和中指”的三指关系，让这三个手指末节朝掌心的一面围住圆柱。无名指在源样本中较远，小指的严重交叉不照抄。这是受机械手能力和碰撞约束限制的适配，不是完整复刻五指姿势。

流程为：

```text
已有Adroit关节轨迹
  -> 计算相对罐体的三指位置
  -> 把源罐体约70x104mm的尺寸关系缩放到53x53mm圆柱
  -> 用统一坐标变换映射，求Orca关节角，同时限制指面朝向
  -> 小范围仿真校正，排除穿模和靠掌部支撑
  -> 参考回放筛出合格示范
  -> 分别训练BC+PPO、参考+残差PPO
  -> 冻结模型后用新初态验证，并导出手心视频
```

前面的逆运动学和参考校正不是PPO训练。它们生成可执行参考，后面才有真正的神经网络训练。

## 两种训练没有混淆

- **BC+PPO**：先学习“这个状态下应当输出什么关节目标”，再通过奖励训练同一个网络。执行时网络直接决定完整动作。
- **参考+残差PPO**：每次都执行 `关节目标 = 参考角度 + PPO的小修正`，再做关节限幅和变化速度限制。这里修正请求最多每关节±0.08rad，约±4.58度。不是只摆一个起手。

PPO看到的是关节、物体相对状态和仿真触觉等，不是在线重新观看RGB视频。

## 什么才算夹住

沿用固定基座、开始有托板、随后撤托的任务，不是从桌面主动捡起搬运。腕关节仍可控。

三根目标手指均需通过末节合格区域真实承力，每指超过0.02N；排除这三指其他部位超过0.02N的支撑。不能靠掌部、托板或穿透维持物体。40秒回合中连续合格至少30秒，最后仍有效，且物体高度下降不超过10mm、撤托后穿透不超过3mm。

指腹区域是工程定义：末节靠前部分，接触方向朝屈曲侧，不是“名字里有tip就算”。它不是从视频自动测出的真实皮肤区域。相似性还要看三指相对位置和朝向误差，不能只凭成功率说“更像样本”。
