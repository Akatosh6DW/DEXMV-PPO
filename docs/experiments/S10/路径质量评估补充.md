# S10 路径质量评估补充

原冻结评估保留了释放后穿透、峰值力等原S09指标。新增整手接近过程后，还需要报告释放前的碰撞质量，不能只看最后抓住没有。

在学习策略的最终测试开始前，增加一个只扩展统计量的评估入口：`scripts/run_s10_quality_job.py`。它调用同一份冻结 `run_s10_job.py`，不改环境、动作、物理积分、随机种子或成功判据，只在评估结束时从同一轨迹增加：

- 全回合最大穿透；
- 接近阶段和释放后的峰值接触力；
- 20Hz控制帧处动态手基座与位姿目标的最大位置误差（不宣称覆盖每个物理子步）；
- 由20Hz基座位置采样计算的平移路程；
- 原严格成功且全回合穿透不超过3毫米的附加成功率。

原始主成功率仍保留，不用新指标覆盖。每次运行快照包含这个附加统计脚本。

`scripts/run_s10_ready_evaluations.py` 仅在对应的冻结末步权重完成后评估；仅BC使用训练前step0。提前完成的测试不用于改动正在运行的训练配方或挑选权重。所有原冻结源码哈希在每次执行前检查。

严格零残差对照已单独启动，随后以 `reference_exact_quality_s0` 重复同一零策略、同一初态并补齐路径字段，必须核对两次评估的原有字段一致。不会把重复评估当成新的独立样本。
