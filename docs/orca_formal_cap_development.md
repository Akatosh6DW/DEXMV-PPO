# 同源视频拧盖：正式比较前的开发验证

这是正式实验的复杂任务分支，不属于方块主表，也不是最终实验结论。
视频路线使用 OakInk2 已发布的 RGB 同步动作标注和人体关节点，直接重定向到 Orca；
没有重新运行原始 RGB 姿态估计，也没有训练 DexMV 的 Adroit 策略。
源序列、关节点与前期 IK（逆运动学：由手指位置求关节角）检查见
[执行日志](orca_formal_execution_log.md)。

## 物品和机械机构

视频中的瓶身和瓶盖使用对应的原始网格，未改变尺寸。瓶盖约直径 44 mm、高 18.5 mm。
原视频左手持瓶，实验使用固定夹具代替左手；右手由 Orca 执行。
固定底座不能跟随原视频的人手大范围移动，重定向误差和后段不可达轨迹保留并披露。

碰撞代理是物理引擎计算接触时使用的简化形状，不是渲染贴图：

- CAP12：瓶盖用 CoACD 分解为 32 个凸体，保留中空区域；达到数量上限后未满足所有分解误差目标。
- CAP15：瓶身体素分解仍有毫米级外形偏差，未选为当前主模型。
- CAP17c：瓶身沿高度切片后做凸包，颈部切片间距 2 mm，共 20 个凸体。
  源表面到代理表面的采样距离 p95 为 0.423 mm；暴露侧面反向距离 p95 为 0.355 mm。
  瓶身内部仍填实，顶面/内部的全表面距离误差较大，不能把侧面精度称为整个模型的精度。

当前 CAP21 采用被动螺旋约束：瓶盖没有电机，只有手的 17 个关节接受动作。
转动时高度按螺距上升，约 490 度后解除约束。螺距约 2.86 mm/圈来自源动作拟合，
不是实测螺纹参数。瓶盖质量 15 g、摩擦等也是仿真假设。
源标注存在约 7 度的安装倾斜和数毫米横向偏差，安装位姿已明确校正为同轴，网格未缩放。

**重要局限：啮合期间用解析螺旋约束代替瓶盖与瓶身之间的网格接触，解除后恢复接触。**
手与物体接触始终保留。原网格安装时仍有约 2.035 mm 的几何重叠，不能因为过滤了该接触
就声称几何问题已经消失。这是机械机构近似，不是精确螺纹齿啮合仿真或实物验证。

## CAP23-CAP24：训练接口门槛

CPU、GPU 分别通过相同检查：

- 触觉关闭/开启/再次关闭，400 步相同动作下的物理状态、奖励、力信号完全相同。
- 仅 actor（实际出动作的网络）的触觉输入被遮蔽；critic（训练时估计价值的网络）保持一致。
- 视频基础动作加 PPO 修正量，修正限制为 +/-0.15 rad，每步控制变化最多 0.1 rad。
- 正弦非零动作测试的最大手部穿透约 1.384 mm；这不是所有动作的安全证明。
- 四个并行环境运行七步，以三步回合强制发生两次自动重置，状态和终止标记正常。
- 原生 MuJoCo 完整积分状态以整数位串显式保存；恢复时重建啮合接触设置，避免并行回合串状态。

`test_oakink_thread.py` 与 `test_oakink_cap_native.py` 合计 7 项测试通过，覆盖机构对照、
状态恢复、批量与独立调用一致、外力注入拒绝，以及不能将中途成功或终止后成功算最终成功。

## 正式训练期间的失败诊断，不作为独立测试

CAP_F01 的 s401_pure 在 step=409600 开发监测中，16/16 回合曾解除螺旋约束，
但完整成功率仍为 0%，最长有效持盖均为 0 秒，所有回合随后因瓶盖触地终止。
该检查点单指法向接触力峰值约 201.98 N，手部最大穿透约 2.921 mm。
这属于当前近似模型中的策略失败，不能把脱离率 100% 写成任务成功率 100%。
该作业尚在训练，409600 不是正式最终检查点，不用它替换冻结的最后检查点。

新增 `oakink_cap_failure_diagnostics.py` 只描述失败，不修改评分；它同时保留触地、禁用接触、
超限穿透和接触状态等标记，避免单一类别掩盖重叠问题。回合终止后的模拟状态不再计入诊断。
单元测试包含终止后伪成功、伪禁用接触和极大力，确认这些后续状态不污染有效回合统计。
诊断结果保存在 `CAP_F01/s401_pure/step_000409600/failure_diagnostics.json`。

回合 0 在 2.15 秒脱离、6.40 秒触地终止，单独保存了 315 度侧掌视频，路径为同目录
`failure_video/stl.mp4` 和 `collision.mp4`。已查看 3.05 秒和 6.40 秒 STL 图像：
前者瓶盖仍靠近瓶口、有效持盖为零；后者瓶口裸露、瓶盖离开当前抓持区域。
触地结论来自保存的物理接触标记，画面没有把画外瓶盖位置当成可见事实。
这一视频只解释中途失败，不混入最终检查点的正式视频组。
下一步继续原配方；不得因这批中途负结果更改成功门槛或调参使某方法获得优势。

本记录的力口径统一为：先累加每根手指传感区域各接触点的法向载荷，再在手指、有效时间和
监测回合上取最大值，不是五指载荷相加。该信号包含手指与瓶身等其他物体的接触，不只包含瓶盖。
以上数值未变化，只修正之前“手指法向力合计”可能造成的歧义。
