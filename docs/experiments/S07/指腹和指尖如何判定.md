# 圆柱：指腹和指尖怎么决定

## 先用人话说明

“指尖”和“指腹”不是两根不同的手指。**指尖是手指最前面那一节/区域；指腹是这一区域朝掌心、适合按住物体的一面。** 当前圆柱要的是“末节指腹抓持”，不是用末节侧面、指背或关节缝卡住物体。

这里有三件不同的事：

1. 视频提供抓法参考：哪些手指靠近物体、相对位置和闭合过程。
2. 我们在机械手模型上定义合格接触区域，让仿真能检查它。
3. PPO通过奖励学习动作；最终由真实接触位置、方向和力判断是否满足要求。

所以不是“视频一来，系统就自动知道哪块是指腹”，也不是“PPO自己决定什么叫指腹”。

## 实际代码如何检查

实现见 [cylinder_contacts](../../../scripts/orca_s06_env.py)。圆柱几何沿用名称 `cube`，但S06/S07加载的实际形状是直径53 mm、高53 mm的圆柱；变量名不代表仍在抓方块。

对圆柱与拇指、食指、中指的每一个真实碰撞接触，执行以下检查：

| 检查 | 当前规则 | 通俗解释 |
|---|---|---|
| 接触所属部件 | 名称属于该指的 `tip_` 几何 | 必须接触末节，不能用掌部或近端冒充 |
| 接触点位置 | 换到末节局部坐标，拇指 `z >= 0.015 m`，食/中指 `z >= 0.024 m` | 接触点在各自末节的远端区域，不是关节根部 |
| 面的方向 | 指向物体的单位接触法向满足 `-nx >= 0.7`、`abs(ny) <= 0.5` | 朝向该模型定义的指腹侧，排除主要从侧面/背面挤压 |
| 实际承力 | 每指合格区域累计法向力 `> 0.02 N` | 不是只靠近或视觉重叠，而是真的在压住物体 |
| 非合格承力 | 三个指定手指各自的非合格区域不能累计承力 `> 0.02 N` | 不能一边稍微碰到指腹，一边主要靠侧面卡住 |

局部坐标会跟着手指旋转；不是世界坐标里的固定方向。15/24 mm从对应末节模型坐标原点测量，不是离圆柱的距离，也不是真人手指长度。不同手型不能直接照搬这些阈值。

`-nx >= 0.7`大致表示法向与末节负X方向夹角不超过45.6度；还有额外的侧向约束，因此不是一个无限制的45.6度圆锥。指腹是一个允许一定接触角度的区域，而不是数学上的一个点。

注意两种几何名称的作用不同：接触分类检查该指所有符合条件的 `tip_` 碰撞几何；`PAD_NAMES` 中选出的三个代理中心用于接近奖励和几何误差统计，**不是只有这三个中心点碰到物体才算成功**。

## “拿稳”比单次碰到还严格

- 拇指、食指、中指必须同时合格；其它两指仍有物理碰撞，不是删掉它们来过关。
- 每50 ms控制一次，但中间10个5 ms物理子步都检查，避免只在录像帧上看似接触。
- 撤托后不能依赖禁止部位承力，物体不能明显下滑，穿透深度不能超过3 mm。
- 完整成功要求至少连续30秒合格，40秒评估结束仍合格，且撤托后的有效区间未出现禁止接触或超限穿透。

“视频里拿住了”不一定满足这个严格定义。失败可能是中指瞬间失去接触、改成侧面承力、物体下滑，也可能是真的掉了。因此展示视频和逐回合指标需要一起看。

## 这些规则是谁定的，准确吗

**这是针对当前Orca模型的工程判据，不是人体解剖学真值。** 它依赖模型局部轴、末节碰撞代理和阈值与外观网格之间的对齐。碰撞代理拟合不准，接触判定也可能偏差；好看的STL外观不会自动改善物理精度。

当前用几何和方向判据排除了以前明显的指侧抓法，但不能因此宣称接触精度已经达到硬件级。进一步验证可做：显示局部轴与真实接触点/法向、对照STL和碰撞体、改变区域和力阈值做敏感性测试，最终再用实物接触传感或标定验证。S07没有把这些尚未完成的检验当成已完成结果。

旧圆柱S02的宽松抓持结果和S06/S07三指指腹结果不是同一标准，不应放进一个成功率里。参数、奖励和来源详见 [奖励函数与样本来源](奖励函数与样本来源.md)。
